title: Супровідні файли

---

Супровідний файл (sidecar) це невеликий файл поруч з аудіо. Їх читають Audiobookshelf та інші програвачі. ABM записує такі:

| Файл | Вміст | Перемикач |
|---|---|---|
| `metadata.json` | Власний файл метаданих Audiobookshelf, плюс блок `abm`, який позначає його як файл ABM. Audiobookshelf читає його раніше за все інше | Немає, записується завжди |
| `cover.jpg` | Обкладинка книжки. Не записується, якщо в теці вже є `cover.*` | cover.jpg |
| `.opf` | Метадані у форматі OPF. Назва береться з першого аудіофайлу книжки (наприклад, `Dune.opf`), або `title.opf`, якщо в книжки немає аудіо | title.opf |
| `desc.txt` | Опис, без HTML. Пропускається, якщо опису немає | desc.txt |
| `reader.txt` | Диктори. Пропускається, якщо їх немає | reader.txt |

Разом зі структурою тек це саме ті файли, з яких Audiobookshelf бере подробиці книжки, тож він бачить ту саму книжку, що й ABM.

## Коли вони записуються

`metadata.json` записується щоразу, коли книжку додають, імпортують або оновлюють.

Решта чотири мають кожен свій перемикач у **Settings > Metadata > Files to Create**, і всі вони за замовчуванням увімкнені. Записуються вони лише тоді, коли ввімкнено ще й відповідний тригер: **Create on Book Add** (вимкнено), **Create on Import** (увімкнено, охоплює завантаження, Library Import і завантаження з Audible) та **Create on Refresh** (вимкнено). **Overwrite Existing** вимкнено, тож файл, який уже є, лишається. Поки теки книжки немає, нічого не записується.

**Write to Directories** у діалозі редагування теж записує ці чотири, для однієї книжки або для вибраних серій і авторів. Дивись [Налаштування метаданих](/uk/settings/metadata/).

## Обкладинка особлива

Обкладинка, яку ти вибрав сам, заблокована. Дивись [Блокування обкладинки](/uk/metadata/cover-lock/).

## Під час імпорту

Імпорт також переносить наявні не-аудіо файли книжки, і цим керує **Media Management > Importing**. Коли в джерелі є `.opf`, файл опису чи файл диктора, ABM бере щонайбільше по одному кожного виду й називає їх `desc.txt` та `reader.txt`. Якщо файл призначення вже існує, його не чіпають, а нова обкладинка ніколи не записується поверх наявного `cover.*`.

## Жорсткі посилання

Імпорт через жорсткі посилання не чіпає оригінал. Коли ABM записує будь-який із цих файлів, він створює новий файл, а не редагує наявний, тож джерело, з якого ти імпортував, зберігає свій вміст.

## Підводні камені

- `metadata.json` обробляє ABM, якщо в ньому є власний блок ABM. `metadata.json` від іншого інструмента підпорядковується перемикачу файлів з інформацією про книжку (Book info files).
- У теці, спільній для кількох книжок, до книжки належать лише файли, названі за її аудіо.
- Видалення книжки прибирає її супровідні файли, якщо вони названі за файлами цієї книжки.
