---
title: Супровідні файли
description: Файли обкладинки, OPF, опису, диктора та cue, які ABM записує поруч із книгою.
---

Супровідний файл (sidecar) це невеликий файл поруч з аудіо. Його читають Audiobookshelf та інші плеєри. ABM може записувати такі:

| Файл | Вміст |
|---|---|
| `cover.jpg` | Обкладинка книги |
| `.opf` | Метадані у форматі OPF, придатні для Audiobookshelf. Названий за першим аудіофайлом книги (наприклад, `Dune.opf`), або `title.opf`, якщо в книги немає аудіо |
| `desc.txt` | Опис |
| `reader.txt` | Диктор |
| `.cue` | Розділи з Libex (з'явиться в наступному релізі) |

## Коли їх записують

У **Settings > Metadata** опції **Create on Book Add**, **Create on Import** і **Create on Refresh** обирають, коли саме. Типово їх записує лише імпорт. **Overwrite Existing** вимкнено, тож файл, що вже є, залишається. Їх також можна записати з діалогу редагування, для однієї книги або вибірки серій та авторів. Див. [Налаштування метаданих](/uk/settings/metadata/).

## Обкладинка особлива

Обкладинку, яку ти обрав сам, заблоковано. Див. [Блокування обкладинки](/uk/metadata/cover-lock/).

## Під час імпорту

Імпорт також переносить наявні неаудіофайли книги, за правилами **Media Management > Importing**. Коли джерело має `.opf`, опис або файл диктора, ABM бере щонайбільше по одному кожного й називає їх `desc.txt` та `reader.txt`. Призначення, що вже існує, не чіпається, а нова обкладинка ніколи не записується поверх наявного `cover.*`.

## Жорсткі посилання

Імпорт із жорстким посиланням не змінює оригінал. Коли ABM записує будь-який із цих файлів, він створює новий файл замість редагування на місці, тож джерело, з якого ти імпортував, зберігає свій вміст.

## Підводні камені

- `metadata.json` обробляє ABM, якщо він містить власний блок ABM. `metadata.json` іншого інструмента підпорядковується перемикачу Book info files.
- У теці, спільній для кількох книг, цій книзі належать лише файли, названі за її аудіо.
- Видалення книги прибирає її супровідні файли, якщо вони названі за файлами цієї книги.
