Супровідний файл (sidecar) це невеликий файл поруч з аудіо. Його читають Audiobookshelf та інші плеєри. ABM записує такі:

| Файл | Вміст | Перемикач |
|---|---|---|
| `metadata.json` | Власний файл метаданих Audiobookshelf, плюс блок `abm`, який позначає його як файл ABM. Audiobookshelf читає його раніше за все інше | Немає, записується завжди |
| `cover.jpg` | Обкладинка книги. Не записується, якщо в теці вже є `cover.*` | cover.jpg |
| `.opf` | Метадані у форматі OPF. Названий за першим аудіофайлом книги (наприклад, `Dune.opf`), або `title.opf`, якщо в книги немає аудіо | title.opf |
| `desc.txt` | Опис без HTML. Пропускається, якщо опису немає | desc.txt |
| `reader.txt` | Диктори. Пропускається, якщо їх немає | reader.txt |

Разом зі структурою тек це ті файли, з яких Audiobookshelf бере дані книги, тож він бачить ту саму книгу, що й ABM.

## Коли їх записують

`metadata.json` записується щоразу, коли книгу додають, імпортують чи оновлюють.

Решта чотири мають власні перемикачі в **Settings > Metadata > Files to Create**, типово всі ввімкнені. Їх записують лише тоді, коли ввімкнено й відповідний тригер: **Create on Book Add** (вимкнено), **Create on Import** (увімкнено, охоплює завантаження, Library Import і завантаження з Audible) та **Create on Refresh** (вимкнено). **Overwrite Existing** вимкнено, тож файл, що вже є, залишається. Нічого не записується, доки тека книги не існує.

**Write to Directories** у діалозі редагування теж записує ці чотири, для однієї книги або вибірки серій та авторів. Див. [Налаштування метаданих](/uk/settings/metadata/).

## Обкладинка особлива

Обкладинку, яку ти обрав сам, заблоковано. Див. [Блокування обкладинки](/uk/metadata/cover-lock/).

## Під час імпорту

Імпорт також переносить наявні неаудіофайли книги, за правилами **Media Management > Importing**. Коли джерело має `.opf`, опис або файл диктора, ABM бере щонайбільше по одному кожного й називає їх `desc.txt` та `reader.txt`. Призначення, що вже існує, не чіпається, а нова обкладинка ніколи не записується поверх наявного `cover.*`.

## Жорсткі посилання

Імпорт із жорстким посиланням не змінює оригінал. Коли ABM записує будь-який із цих файлів, він створює новий файл замість редагування на місці, тож джерело, з якого ти імпортував, зберігає свій вміст.

## Підводні камені

- `metadata.json` обробляє ABM, якщо він містить власний блок ABM. `metadata.json` іншого інструмента підпорядковується перемикачу Book info files.
- У теці, спільній для кількох книг, цій книзі належать лише файли, названі за її аудіо.
- Видалення книги прибирає її супровідні файли, якщо вони названі за файлами цієї книги.
