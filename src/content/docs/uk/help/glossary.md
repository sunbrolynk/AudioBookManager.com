title: Глосарій
description: Терміни для нових користувачів і тих, хто прийшов з arr.
---

**ASIN**: десятисимвольний ідентифікатор книги в Audible. ABM ідентифікує книги за ним.

**Auto tag** (автотег): правило, що застосовує теги до книг, які відповідають умовам.

**Blocklist**: релізи, які ABM більше не захоплюватиме.

**Connect**: сторінка Settings для сповіщень і з'єднань з медіасерверами. Так само називається і в Sonarr.

**Cover lock** (блокування обкладинки): обкладинка, яку ти обрав і яку оновлення не замінять.

**Cutoff** (поріг): у профілі якості це «Upgrade Until»: якість, на якій ABM припиняє шукати краще.

**Delay profile** (профіль затримки): очікування перед захопленням, окремо для кожного протоколу.

**Discover**: каталоги Audible для перегляду.

**Hardlink** (жорстке посилання): друге ім'я того самого файлу на тій самій файловій системі. Без додаткового місця.

**Import Workbench**: справжня назва сторінки Library Import. Сканування, зіставлення, додавання.

**Indexer** (індексатор): сайт, на якому ABM шукає релізи.

**Ladder** (драбина): впорядкований список форматів у профілі якості.

**Libex**: сервіс метаданих, у якого ABM запитує дані про книги.

**Monitored / Unmonitored**: чи діє ABM щодо книги.

**M4B**: однофайловий формат аудіокниги з розділами.

**Quality profile / release profile**: див. [Профілі](/uk/settings/profiles/).

**Remote path mapping** (віддалене зіставлення шляхів): перекладає шлях, який бачить твій клієнт завантаження, у шлях, який бачить ABM.

**Root folder** (коренева тека): каталог, у якому ABM зберігає книги.

**Sidecar** (супровідний файл): невеликий файл поруч з аудіо: обкладинка, OPF, опис, диктор, cue.

**Step-up password** (повторне підтвердження паролем): повторний запит пароля перед чутливою зміною.

**Wanted**: відстежувана книга без файлів.

## Якщо ти знаєш Sonarr

Епізод це книга. Series це і серія із Sonarr, і каталог книг. Якість це формат плюс один чи багато файлів. Custom formats стають профілями релізів. Activity, Wanted, Calendar і System працюють так само.
