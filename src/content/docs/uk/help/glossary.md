title: Глосарій
description: Терміни для нових користувачів і для тих, хто прийшов з arr-застосунків.
---

**ASIN**: десятисимвольний ідентифікатор книжки в Audible. ABM розпізнає книжки саме за ним.

**Автотег (Auto tag)**: правило, яке ставить теги на книжки, що відповідають умовам.

**Чорний список (Blocklist)**: релізи, які ABM більше не захоплюватиме.

**Connect**: сторінка налаштувань для сповіщень і зв'язку з медіасерверами. У Sonarr вона називається так само.

**Блокування обкладинки (Cover lock)**: обкладинка, яку ти вибрав і яку оновлення не замінять.

**Поріг (Cutoff)**: у профілі якості це "Upgrade Until", тобто якість, на якій ABM перестає шукати кращу.

**Профіль затримки (Delay profile)**: очікування перед захопленням, окремо для кожного протоколу.

**Discover**: каталоги Audible, які можна переглядати.

**Жорстке посилання (Hardlink)**: друга назва того самого файлу на тій самій файловій системі. Додаткового місця не займає.

**Import Workbench**: назва сторінки, що стоїть за Library Import. Сканування, зіставлення, додавання.

**Індексатор (Indexer)**: сайт, на якому ABM шукає релізи.

**Драбина (Ladder)**: упорядкований список форматів у профілі якості.

**Libex**: сервіс метаданих, у якого ABM запитує дані про книжки.

**Monitored / Unmonitored**: чи щось робить ABM із книжкою (відстежується вона чи ні).

**M4B**: формат аудіокнижки одним файлом із розділами.

**Профіль якості / профіль релізів**: дивись [Профілі](/uk/settings/profiles/).

**Зіставлення віддалених шляхів (Remote path mapping)**: перетворює шлях, який бачить твій клієнт завантажень, на шлях, який бачить ABM.

**Коренева тека (Root folder)**: тека, у якій ABM зберігає книжки.

**Супровідний файл (Sidecar)**: невеликий файл поруч з аудіо: обкладинка, OPF, опис, диктор, cue.

**Повторне підтвердження паролем (Step-up password)**: ABM знову просить пароль перед важливою зміною.

**Wanted (бажана)**: відстежувана книжка без файлів.

## Якщо ти знаєш Sonarr

Епізод тут це книжка. Серія означає і серію в розумінні Sonarr, і каталог книжок. Якість це формат плюс один файл чи кілька. Власні формати стали профілями релізів. Activity, Wanted, Calendar і System працюють так само.
