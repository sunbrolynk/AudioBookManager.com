Якщо ти користувався Sonarr, Radarr чи Readarr, більшість речей в ABM знайдеш там, де й очікуєш.

## Те саме

Wanted (Missing, Cutoff Unmet), Activity (Queue, History, Blocklist), Calendar зі стрічкою iCal, індексатори з RSS, автоматичний та інтерактивний пошук, профілі якості з порогом та оновленнями, профілі затримки й релізів, теги, Connect, віддалені зіставлення шляхів, кошик, резервні копії, Tasks і Status.

## Що відрізняється

| В arr-застосунках | В ABM |
|---|---|
| Якості на основі роздільної здатності | Драбина аудіоформатів, один файл чи багато |
| Custom formats | Профілі релізів із Must Contain, Must Not Contain, Preferred |
| Елемент це епізод, фільм чи книга | Книга, де серії та позиції відстежуються як каталоги |
| Метадані з власного сервісу | Libex, з блокуванням обкладинок, записом супровідних файлів і тегів |
| Одна тека завантажень | Те саме, плюс Library Import для наявних колекцій |
| Без конвертації медіа | Черга конвертацій: конвертація, об'єднання, розбиття, розділи |
| Формати іменування | ABM сам обирає назви тек. Rename Files є у списках |
| Списки імпорту багатьох видів | MAM і RSS |

## Чого немає в ABM

Flood не є клієнтом. Custom formats відсутні. Підтримка книг із Readarr сюди не входить. ABM лише для аудіокниг.

## Перехід

Імпортера з Readarr немає. Вкажи ABM свою наявну теку аудіокниг через [Імпорт бібліотеки](/uk/library-import/) і дивись [Перенесення бібліотеки](/uk/guides/moving-a-library-in/).
