ABM має REST API за адресою `/api`. Інтерактивний довідник розташований за `/api/docs` (Swagger) і `/api/redoc`, а схема за `/api/openapi.json`. Задай `DOCS_ENABLED=false`, щоб прибрати всі три. Сторінки документації завантажують ресурси з CDN, тож повністю відображаються лише за наявності інтернету.

## Автентифікація

- **Ключ API**: надішли `X-Api-Key: <key>` або `?apikey=<key>`. Знайти чи перегенерувати його можна в **Settings > General > Security**. Див. [Безпека](/uk/settings/security/).
- **Bearer token**, отриманий під час входу.
- Облікові дані, які ти подаєш, мають перевагу над обходом входу, тож запит із ключем з LAN рахується запитом API.

## Домовленості

- Помилки повертаються як `{"detail": ...}`.
- Секрети ніколи не повертаються. Відповідь каже лише, чи секрет задано.
- Браузерний запит, що змінює стан, потребує, щоб origin збігався. Скрипти з ключем звільнені.
- Тіла запитів обмежено 10 MiB (`MAX_REQUEST_BODY_BYTES`). Відновлення з резервної копії та завантаження обкладинки мають більші ліміти. Перевищення дає HTTP 413.
- Помилки валідації ніколи не повторюють надіслане тобою.

## Збої метаданих

Маршрут, що залежить від джерела метаданих, відповідає 503 (`metadata_unavailable`), 503 з `Retry-After: 30` (`metadata_declined`) або 502 (`metadata_rejected`) у полі `code` тіла. Деякі маршрути пошуку під час збою все ж повертають порожній результат.

Якщо ти знаєш Sonarr: API не сумісне з v3. Prowlarr може синхронізувати індексатори в ABM через своє підключення Prowlarr.
