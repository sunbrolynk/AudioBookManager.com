База даних це файл SQLite у `/config`, тож окремий сервіс бази даних налаштовувати не треба.

**Тобі знадобиться:**

- Docker із Compose
- Тека для твоєї бібліотеки аудіокнижок
- Тека, у яку твій клієнт завантажень кладе завершені завантаження
- Тека для власних даних ABM

## Встановлення

<Steps>

1. **Створи compose-файл.** Збережи це як `docker-compose.yml`:

   ```yaml
   services:
     audiobook-manager:
       image: ghcr.io/sunbrolynk/audiobook-manager:latest
       container_name: audiobook-manager
       restart: unless-stopped
       ports:
         - "${PORT:-5173}:5173"
       environment:
         TIMEZONE: ${TIMEZONE:-UTC}
         LOCAL_NETWORKS: ${LOCAL_NETWORKS:-}
         TRUSTED_PROXIES: ${TRUSTED_PROXIES:-}
       volumes:
         - /path/to/library:/audiobooks
         - /path/to/downloads:/downloads
         - /path/to/config:/config
   ```

2. **Вкажи свої теки.** Заміни ліву частину кожного тому на справжню теку на своїй машині. Праву частину не чіпай.

   | Шлях на хості | Шлях у контейнері | Що там лежить |
   |---|---|---|
   | `/path/to/library` | `/audiobooks` | Твоя бібліотека аудіокнижок. Обов'язково. |
   | `/path/to/downloads` | `/downloads` | Куди клієнт завантажень кладе завершені завантаження. Обов'язково. |
   | `/path/to/config` | `/config` | База даних SQLite, резервні копії, журнали, кошики та згенерований секрет застосунку. Бережи її. |

3. **Запусти.** Виконай це в теці з compose-файлом:

   ```bash
   docker compose up -d
   ```

4. **Відкрий.** Перейди на `http://your-server:5173`. Під час першого відвідування ABM проведе тебе через налаштування логіна.

</Steps>

<Aside type="tip" title="Завантаження в іншому контейнері?">
Якщо клієнт завантажень працює у власному контейнері, його тека завантажень має бути тією самою текою, яку ABM бачить як `/downloads`. Якщо шляхи різні, додай зіставлення віддаленого шляху в **Settings > Download Clients**.
</Aside>

## Перший запуск

Задай свій часовий пояс через `TIMEZONE` у compose-файлі. Потім у **Settings** додай кореневу теку в **Media Management**, індексатор в **Indexers** і клієнт завантажень у **Download Clients**. Про змінні середовища та зворотні проксі йдеться в розділі [Конфігурація](/uk/configuration/).

## Збірка з вихідного коду

Щоб зібрати образ самому, склонуй репозиторій, заміни рядок `image:` на `build: .` і виконай:

```bash
docker compose up -d --build
```

## Оновлення

Стягни новий образ і перествори контейнер. На сторінці [Оновлення](/uk/updates/) видно, що змінилося в кожному випуску.

<Aside type="caution" title="ABM у стадії альфа">
Перед оновленням зроби резервну копію `/config` і спершу пробіжись очима по примітках до оновлення.
</Aside>

## Щось не так?

- **Сторінка не відкривається.** Перевір прокидання порту в compose-файлі, потім виконай `docker logs audiobook-manager`.
- **Зміни з мого домену відхиляються.** ABM відхиляє зміни з адреси, за якою його не відкривали. Спершу налаштуй проксі, щоб він передавав оригінальний заголовок `Host`. Якщо цього не досить, додай свій домен у **CORS Allowed Domains** у **Settings > General** (це розширений параметр, тож увімкни **Show Advanced**) і перезапусти ABM. Дивись [Усунення несправностей](/uk/troubleshooting/).
- **Завантаження завершуються, але не імпортуються.** Перевір відповідність тек із підказки вище.
