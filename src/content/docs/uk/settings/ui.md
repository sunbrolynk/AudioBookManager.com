title: UI
description: Календар, формати дат, тема й параметри кольору.
---

**Settings > UI** стосується лише відображення.

| Налаштування | Варіанти |
|---|---|
| First Day of Week | Sunday або Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` або `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Чотири розкладки, з днем тижня чи без |
| Time Format | 12-годинний або 24-годинний |
| Show Relative Dates | Today і Yesterday замість дат |
| Theme | Auto (за твоєю ОС), Light або Dark |
| Enable Color-Impaired Mode | Змінює кольорове кодування, щоб статуси легше розрізнялися |

Типові значення закладено в застосунок. Ці налаштування спільні для всіх, хто користується екземпляром.
