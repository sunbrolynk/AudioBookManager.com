title: Інтерфейс
description: Календар, формати дат, тема та кольори.
---

**Settings > UI** стосується лише відображення.

| Параметр | Варіанти |
|---|---|
| First Day of Week | Неділя або понеділок |
| Week Column Header | `Tue 3/25`, `Tue 25/3` або `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Чотири варіанти, з днем тижня або без нього |
| Time Format | 12-годинний або 24-годинний |
| Show Relative Dates | «Сьогодні» та «Вчора» замість дат |
| Theme | Auto (як у твоїй ОС), Light або Dark |
| Enable Color-Impaired Mode | Змінює кольорове кодування, щоб статуси було легше розрізнити |

Значення за замовчуванням задані в застосунку. Ці налаштування спільні для всіх, хто користується екземпляром.
