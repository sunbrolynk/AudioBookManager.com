**Settings > Connect** надсилає події в інші місця. Назва Connect така сама, як у Sonarr.

## Агенти

**Агенти сповіщень**: Discord, Slack, Telegram, Pushover, Pushbullet, Simplepush, ntfy, Gotify, Notifiarr, Email, SendGrid, Webhook та Apprise. **Медіасервери**: Jellyfin і Emby. **Інше**: Custom Script. Audiobookshelf не є агентом Connect.

## Події

Кожне підключення обирає, які події його запускають.

On Grab, On Import, On Upgrade, On Conversion, On Health Issue, On Health Restored, On Task Failed, On Application Update, On Grab Failed, On Import Failed, On Download Failed, On Conversion Failed, On Import List Synced, On Import List New Items, On Audible Download Done, On Audible Download Failed.

## Для кожного підключення

| Поле | Дія |
|---|---|
| Name, Enable | Назва та вмикання/вимикання |
| Include covers | Додавати обкладинку книги, коли агент це вміє |
| Tags | Спрацьовувати лише для елементів із відповідним тегом |
| Conditions | Правила, об'єднані через AND, за полями на зразок автора чи розміру. Хибно сформована умова вважається виконаною, тож сповіщення не глушиться |
| Priority | Там, де агент це підтримує |

**Test** надсилає тестове повідомлення. **Test All** перевіряє кожне підключення.

## Власні повідомлення

Власне повідомлення переписує текст події. Обери **Format**, **Cover** (Auto бере обкладинку книги, None або Custom URL), напиши **Title** і тіло та клацни змінну, щоб вставити її. Типовий шаблон кожної події це відправна точка. Попередній перегляд показує результат, а тест можна надіслати через підключення.

## Підводні камені

- Секрети, як-от токени, зберігаються зашифрованими. Під час редагування їхні поля порожні, а якщо залишити їх порожніми, збережене значення не зміниться. Зміна призначення вимагає ввести їх знову.
- Сповіщення про збій завдання через недоступність метаданих надходить один раз за весь період недоступності, а не на кожен збій, і запланований запуск його ніколи не надсилає.
- Заголовки Webhook це об'єкт JSON, що зберігається як секрет.
