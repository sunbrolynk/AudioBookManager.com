**Settings > Connect** надсилає події в інші місця. Називається Connect, як у Sonarr.

## Агенти

**Агенти сповіщень**: Discord, Slack, Telegram, Pushover, Pushbullet, Simplepush, ntfy, Gotify, Notifiarr, Email, SendGrid, Webhook та Apprise. **Медіасервери**: Jellyfin та Emby. **Інше**: Custom Script. Audiobookshelf не є агентом Connect.

## Події

Кожне з'єднання саме вибирає, які події його запускають.

On Grab, On Import, On Upgrade, On Conversion, On Health Issue, On Health Restored, On Task Failed, On Application Update, On Grab Failed, On Import Failed, On Download Failed, On Conversion Failed, On Import List Synced, On Import List New Items, On Audible Download Done, On Audible Download Failed.

## Для кожного з'єднання

| Поле | Що робить |
|---|---|
| Name, Enable | Назва та ввімкнено/вимкнено |
| Include covers | Додає обкладинку книжки, якщо агент це вміє |
| Tags | Спрацьовує лише для елементів із відповідним тегом |
| Conditions | Правила, об'єднані через І, за полями на кшталт автора чи розміру. Неправильно задана умова пропускає подію, а не глушить сповіщення |
| Priority | Там, де агент це підтримує |

**Test** надсилає тестове повідомлення. **Test All** перевіряє всі з'єднання.

## Власні повідомлення

Власне повідомлення переписує текст для події. Вибери **Format**, **Cover** (Auto бере обкладинку книжки, None або Custom URL), напиши **Title** і текст, а змінну вставляй клацанням на неї. Типовий шаблон кожної події це лише відправна точка. Попередній перегляд показує результат, а тестове повідомлення можна надіслати через з'єднання.

## Підводні камені

- Секрети, як-от токени, зберігаються зашифрованими, під час редагування поле порожнє, а якщо його так і залишити, секрет зберігається. Щоб змінити адресата, їх треба ввести знову.
- Сповіщення про невдале завдання через збій метаданих надходить один раз за збій, а не за кожну помилку, а запланований запуск ніколи його не надсилає.
- Заголовки Webhook задаються як об'єкт JSON і зберігаються як секрет.
