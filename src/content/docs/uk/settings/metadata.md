**Settings > Metadata** визначає, що ABM записує в теку книжки та в її файли. Як ці файли використовуються, описано на сторінці [Супровідні файли](/uk/using/sidecars/).

## Джерело (Source)

**Metadata Source** — це Built-in (типово), Hosted (libexdb.com) або Self-hosted, якому потрібна **Server URL**. **Test** робить справжній запит до вибраного джерела без збереження, **Status** каже, чи воно готове, а **Connection** показує маршрут, яким виходять запити, із посиланням на **Settings > Network**. Перемикання діє одразу для всіх запитів. Дивись [Вибір джерела метаданих](/uk/metadata/choosing-a-source/).

## Створення файлів метаданих

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Create on Book Add | вимкнено | Записує файли, коли книжку додають як бажану |
| Create on Import | увімкнено | Записує файли, коли аудіокнижку імпортують |
| Create on Refresh | вимкнено | Створює або оновлює файли під час оновлення метаданих |
| Overwrite Existing | вимкнено | Замінює файли, які вже є в теці |

Які файли створювати: `cover.jpg` (увімкнено), `title.opf` (увімкнено, сумісний з Audiobookshelf), `desc.txt` (увімкнено) та `reader.txt` (увімкнено).

## Запис тегів в аудіофайли

Використовує ffmpeg, щоб записувати теги просто в аудіо.

| Параметр | За замовчуванням |
|---|---|
| Write Audio Tags | вимкнено |
| Write Tags on Import | увімкнено, щойно ввімкнено запис тегів |
| Write Tags on Refresh | вимкнено |

Поля тегів, усі за замовчуванням увімкнені: Title, Artist (автор), Album Artist (автор), Album (назва/серія), Genre, Year, Comment (опис), Narrator (Composer) та Cover Art.

## Локальне сховище (Local Storage)

З джерелом Built-in з'являються розділи **Local Storage** і **Storage Backups**. Це попередній перегляд, вони ще не підключені. Дивись [Твої метадані під твоїм контролем](/uk/metadata/control/).

## Підводні камені

- Запис тегів змінює аудіофайли. Audiobookshelf побачить їх як змінені.
- Якщо під час запису тегів не вдається отримати метадані чи обкладинку, виклик повертає попередження, а не завершується помилкою.
- Коли обкладинку не вдалося вбудувати, бо підключення її відхилило, сторінка книги та діалог редагування показують попередження замість звичайного успіху.
