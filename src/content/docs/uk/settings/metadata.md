---
title: Метадані
description: Які супровідні файли й аудіотеги записує ABM і коли.
---

**Settings > Metadata** визначає, що ABM записує в теку книги та її файли. Як використовуються ці файли, описано в [Супровідних файлах](/uk/using/sidecars/).

## Створення файлів метаданих

| Налаштування | Типово | Дія |
|---|---|---|
| Create on Book Add | off | Записувати файли, коли книгу додано як шукану |
| Create on Import | on | Записувати файли, коли аудіокнигу імпортовано |
| Create on Refresh | off | Створювати чи оновлювати файли під час оновлення метаданих |
| Overwrite Existing | off | Замінювати файли, що вже є в теці |

Файли для створення: `cover.jpg` (on), `title.opf` (on, сумісний з Audiobookshelf), `desc.txt` (on) і `reader.txt` (on).

## Запис тегів в аудіофайли

Використовує ffmpeg для запису тегів у саме аудіо.

| Налаштування | Типово |
|---|---|
| Write Audio Tags | off |
| Write Tags on Import | on, коли запис тегів увімкнено |
| Write Tags on Refresh | off |

Поля тегів, усі типово ввімкнені: Title, Artist (Author), Album Artist (Author), Album (Title/Series), Genre, Year, Comment (Description), Narrator (Composer) та Cover Art.

## З'явиться в наступному релізі

Сторінку буде впорядковано в розділи, і вона отримає розділ **Source** з вибором **Metadata Source**, **Test** та **Status**. Див. [Вибір джерела метаданих](/uk/metadata/choosing-a-source/).

Також з'явиться розділ **Local Metadata Library** (опціональний, показаний як попередній перегляд, що ще не підключений) із завантаженням бібліотеки як SQLite та власними запланованими резервними копіями. Копії повторюють опції резервного копіювання з General і типово виконуються щотижня о 04:00 і зберігаються 28 днів.

## Підводні камені

- Запис тегів змінює аудіофайли. Audiobookshelf побачить їх як змінені.
- Якщо під час запису тегів метадані чи обкладинку отримати не вдалося, виклик повертає попередження замість помилки.
