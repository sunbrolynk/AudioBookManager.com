**Settings > Profiles** це одна сторінка з трьома розділами. Вони відповідають на три різні питання про реліз.

## Профілі якості

Профіль якості це драбина форматів: найгірший унизу, найкращий нагорі. Щабель це формат (M4B, M4A, MP3, FLAC, OGG, Opus, AAC, WMA) одним файлом або кількома. Щаблі можна групувати, щоб вони мали однаковий ранг, а будь-який щабель можна вимкнути.

| Параметр | Що означає |
|---|---|
| Upgrades Allowed | Якщо вимкнено, ABM не замінюватиме книжку, коли вона вже є |
| Upgrade Until | Поріг. Коли цієї якості досягнуто, ABM перестає покращувати |
| Grab off-ladder formats | Захопити формат, якого немає в списку, замість пропустити книжку |
| Default profile | Профіль, який використовується, коли не підходить нічого конкретнішого |

Один профіль є типовим. Книжка бере по черзі: власний профіль, профіль основної серії, профіль основного автора, а потім типовий. Профіль, який використовується, видалити не можна.

Нова копія замінює наявну, лише якщо профіль дозволяє покращення, новий щабель є на драбині й увімкнений, книжка нижче за свій поріг, а новий щабель стоїть строго вище.

Якщо ти знаєш Sonarr: це профіль якості, де якості це аудіоформати й розкладка файлів, а не роздільність. Власних форматів немає. Схожі задачі закривають [профілі релізів](#профілі-релізів).

Рівнів за бітрейтом чи розміром немає: якість це лише формат і розкладка файлів. Для релізу ABM бере формат з індексатора або з назви, а розкладку вгадує з назви (M4B без номерів частин чи доріжок вважається одним файлом), і потім перевіряє ще раз, коли файли імпортовано. **Preferred Quality** у [налаштуваннях Audible](/uk/settings/audible/) це інше: якість, у якій приходять завантаження з Audible.

## Профілі затримки

Профіль затримки притримує реліз перед захопленням, щоб дати час з'явитися кращому.

| Параметр | Що означає |
|---|---|
| Enable Usenet / Enable Torrent | Дозволити захоплення через цей протокол |
| Usenet Delay / Torrent Delay | Скільки хвилин чекати перед захопленням релізу цього протоколу |
| Preferred Protocol | Якому протоколу віддавати перевагу, коли обидва знайшли збіг |
| Bypass if Highest Quality | Пропустити затримку, коли реліз уже досягає порогу профілю |
| Tags | Профіль діє лише для елементів із відповідним тегом |

Профілі затримки показано таблицею, як у Sonarr.

## Профілі релізів

Профіль релізів додає правила поверх якості.

| Поле | Що означає |
|---|---|
| Enable Profile | Увімкнено чи вимкнено |
| Must Contain | Реліз має містити хоча б один термін (без урахування регістру) |
| Must Not Contain | Реліз із будь-яким із цих термінів відхиляється |
| Preferred | Терміни, які підвищують або знижують оцінку релізу. Пиши `/regex/`, щоб використати регулярний вираз |
| Narration language | Обмежити мовою озвучення |
| Indexer | Застосовувати до одного індексатора або до будь-якого |
| Tags | Застосовувати лише до елементів із відповідним тегом |

Профілі релізів показано таблицею.

## Підводні камені

- Профілі ніколи не видаляють файли. Вони вирішують, що захоплювати і що вважати покращенням.
- Теги на профілі затримки чи релізів обмежують його книжками, які мають один із цих тегів.
