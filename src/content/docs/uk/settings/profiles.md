**Settings > Profiles** це одна сторінка з трьома розділами. Вони відповідають на три різні запитання про реліз.

## Quality profiles

Профіль якості це драбина форматів, від найгіршого внизу до найкращого вгорі. Щабель це формат (M4B, M4A, MP3, FLAC, OGG, Opus, AAC, WMA) в одній із двох форм: один файл чи багато файлів. Щаблі можна групувати, щоб вони мали однаковий ранг, а щабель можна вимкнути.

| Налаштування | Значення |
|---|---|
| Upgrades Allowed | Якщо вимкнено, ABM не замінюватиме книгу, щойно вона в нього є |
| Upgrade Until | Поріг. Щойно цю якість досягнуто, ABM припиняє оновлювати |
| Grab off-ladder formats | Захоплювати формат, якого немає в списку, замість того щоб пропустити книгу |
| Default profile | Профіль, що використовується, коли не діє нічого конкретнішого |

Один профіль є типовим. Книга використовує, за порядком, власний профіль, профіль основної серії, профіль основного автора, потім типовий. Профіль, що використовується, не можна видалити.

Нова копія замінює наявну, лише якщо профіль дозволяє оновлення, новий щабель є на драбині й увімкнений, книга нижче свого порога, а новий щабель стоїть строго вище.

Якщо ти знаєш Sonarr: це профіль якості, де якості це аудіоформати й розташування файлів, а не роздільна здатність. Власних форматів (custom formats) не існує. [Профілі релізів](#release-profiles) охоплюють схожу територію.

## Delay profiles

Профіль затримки утримує реліз перед захопленням, щоб дати час з'явитися кращому релізу.

| Налаштування | Значення |
|---|---|
| Enable Usenet / Enable Torrent | Дозволити захоплення з цього протоколу |
| Usenet Delay / Torrent Delay | Хвилин очікування перед захопленням релізу цього протоколу |
| Preferred Protocol | Якому протоколу надавати перевагу, коли обидва знаходять збіг |
| Bypass if Highest Quality | Пропустити затримку, коли реліз уже відповідає порогу профілю |
| Tags | Профіль застосовується лише до елементів із відповідним тегом |

Профілі затримки показано таблицею, як у Sonarr.

## Release profiles

Профіль релізу додає правила поверх якості.

| Поле | Значення |
|---|---|
| Enable Profile | Увімкнено чи вимкнено |
| Must Contain | Реліз має містити хоча б один термін (без урахування регістру) |
| Must Not Contain | Реліз з будь-яким із цих термінів відхиляється |
| Preferred | Терміни, що підвищують чи знижують оцінку релізу. Напиши `/regex/`, щоб використати регулярний вираз |
| Narration language | Обмежити мовою |
| Indexer | Застосувати до одного індексатора або до будь-якого |
| Tags | Застосовувати лише до елементів із відповідним тегом |

Профілі релізів показано таблицею.

## Підводні камені

- Профілі ніколи не видаляють файли. Вони визначають, що захоплювати і що вважається оновленням.
- Теги на профілі затримки чи релізу обмежують його книгами, що несуть один із цих тегів.
