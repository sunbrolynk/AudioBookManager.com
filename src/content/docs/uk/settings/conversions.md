**Settings > Conversions** задає типові значення для [Конвертацій](/uk/using/conversions/). Будь-яке завдання може їх перевизначити.

## Загальне

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Enable Conversions | увімкнено | Коли вимкнено, створення, масове додавання в чергу чи повторення конвертації відхиляються з HTTP 409, завдання, що вже в черзі, завершується помилкою з повідомленням про це, а **Auto-Reformat on Import** нічого не ставить у чергу |
| Conversion Folder | порожньо | Робоча тека. Якщо порожньо, використовується системна тимчасова тека |
| Concurrent Conversions | 2 | Від 1 до 4. Тримай це значення, помножене на **Threads Per Job**, не вище за кількість ядер. Сторінка попереджає, коли воно вище |
| Threads Per Job | Auto | Потоки FFmpeg на завдання, в розширеному вигляді. Auto залишає два ядра для ABM, а решту ділить між завданнями, що виконуються одночасно, тож 8 ядер і 2 одночасні завдання дають по 3 потоки. Або обери фіксовану кількість |
| Process Priority | Normal | Low залишає решту системи чутливою. High закінчує швидше |

## Типова якість аудіо

| Параметр | За замовчуванням |
|---|---|
| Default Output Format | M4B (також MP3, M4A, FLAC, Opus) |
| Default Bitrate | 128 kbps (64, 96, 128, 192, 256 або Copy, щоб не перекодовувати) |
| Default Sample Rate | Auto не передає частоти й залишає вибір FFmpeg. Або 22050, 44100 чи 48000 Hz, що передискретизує. Opus приймає лише певні частоти, тож 22050 стає 24000, а 44100 стає 48000 (журнал про це каже) |
| Default Channels | Auto зберігає розкладку каналів джерела. Mono змішує в один канал для менших файлів. Stereo примусово робить два |

Обидва списки частоти й каналів приймають лише те, що пропонує сторінка. Некоректне збережене значення завантажується як Auto.

## Параметри кодеків

| Формат | Кодер | Параметри |
|---|---|---|
| M4B, M4A | AAC | AAC Profile (типово AAC-LC) і AAC VBR, якість від 1 до 5. Бітрейт діє, коли VBR вимкнено. AAC-LC єдиний профіль, бо кодувальник не вміє HE-AAC. Збережений профіль HE завантажується як AAC-LC |
| MP3 | LAME | Якість VBR від 0 до 9 (за замовчуванням 4) і Joint Stereo (увімкнено). Бітрейт діє, коли VBR вимкнено |
| Opus | libopus | Змінний бітрейт (увімкнено) і Application: Audio (за замовчуванням), VoIP або Low Delay |
| FLAC | FLAC | Рівень стиснення від 0 до 12 (за замовчуванням 5). Бітрейт ігнорується |

Бітрейт **Copy** пропускає перекодування й усі параметри кодеків.

## Робота з розділами

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Default Chapter Behavior | Auto | Зберегти, якщо розділи є, створити, якщо немає. Інші варіанти: лише зберігати, завжди створювати, без розділів |
| Chapter Naming Format | `Chapter {n}` | Назви для розділів, які ABM доводиться створювати самому. `{n}` це номер, а `{title}` назва файлу-джерела. Назви розділів із файлів або з Libex зберігаються |
| Silence Detection | вимкнено | Для файлу без розділів ABM створює розділи в найдовших паузах аудіо. Це використовують Split Chapters та Ensure Chapters на одному файлі, коли Libex не має розділів. Якщо вимкнено, поділ такого файлу завершується помилкою |
| Target Chapter Length | 600 s | Показується, коли Silence Detection увімкнено, від 60 с. Кожен розділ закінчується в найдовшій паузі в межах половини цієї довжини з кожного боку, або на цій довжині, якщо паузи немає. Короткий хвіст приєднується до останнього розділу, а розділи покривають увесь файл |
| Chapter Image Handling | Keep in file | Або прибрати, або витягти в теку |

## Робота з метаданими

| Параметр | За замовчуванням |
|---|---|
| Preserve Metadata | All metadata |
| Embed Cover Art | увімкнено (лише JPEG, для Audiobookshelf) |
| Cover Art Max Size | 1000x1000 |

## Керування файлами

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Enable Recycle Bin | увімкнено | Оригінали потрапляють у кошик, а не видаляються |
| Recycle Bin Path | порожньо | Якщо порожньо, використовується `/config/recycle/conversions` |
| Retention Period | 7 днів | Старші елементи видаляє завдання очищення кошика. 0 зберігає їх назавжди |
| Auto-Empty When Bin Is Large | вимкнено | Вмикає поріг нижче |
| Auto-Empty Threshold | 10 GB | Після конвертації, якщо кошик містить більше за це, найстаріші елементи видаляються |
| Delete Original | вимкнено | Типове значення для кожного завдання, можна перевизначити |
| Update Library Paths | увімкнено | Записи книжок слідують за конвертованими файлами |
| Auto-Reformat on Import | вимкнено | Конвертує щойно імпортовані книжки в іншому форматі за типовими значеннями вище |
| Backup Original Metadata | вимкнено | Перед конвертацією записує файл JSON у теку `.metadata_backup` усередині теки книжки. У ньому перелічено назву, формат і розмір кожного вихідного файлу, а також теги й розділи, вбудовані в нього |

## Розширені параметри FFmpeg

FFmpeg Path (якщо порожньо, шукається в PATH), Custom FFmpeg Arguments (додаються до кожної команди; неправильні аргументи ламають конвертації), Logging Level (за замовчуванням error) і Keep FFmpeg Logs (вимкнено).
