**Settings > Media Management** визначає, де лежать книжки і як файли потрапляють усередину. Параметри, позначені як розширені, з'являються з **Show Advanced**.

## Кореневі теки (Root Folders)

Коренева тека це тека, у якій ABM керує книжками. Додай її через **Add Root Folder**: відкриється оглядач тек, у якому шлях можна й ввести. ABM також може показати незіставлені теки в корені та імпортувати їх. Під час додавання кореня перевіряються вільне місце й підтримка жорстких посилань. Коли видаляєш корінь, ABM питає, що робити: **Remove from ABM only** (за замовчуванням) забуває книжки в ньому й лишає файли, а **Delete the books and their files** назавжди видаляє все за цим шляхом, оминаючи кошик. Якщо в корені є книжки, для підтвердження доведеться дещо ввести.

Типова коренева тека це та, куди потрапляють нові книжки, і та, від якої залежить, чи пропонуються жорсткі посилання для Library Import.

## Теки (Folders)

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Create Empty Book Folders | вимкнено | Створює відсутні теки книжок під час додавання, зміни кореневої теки та сканування диска. Ігнорується, поки ввімкнено **Delete empty folders**, щоб тека не створювалася лише для того, щоб її видалили. |
| Delete empty folders | вимкнено | Видаляє порожні теки книжок під час сканування диска та коли видаляються файли книжок |

## Імпорт (Importing)

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Skip Free Space Check | вимкнено | Для випадків, коли ABM не може визначити вільне місце в корені |
| Minimum Free Space | 100 (MB) | Імпорт, після якого лишилося б менше, відхиляється |
| Use Hardlinks instead of Copy | увімкнено | Для завершених завантажень: жорстке посилання замість копії, щоб роздача не подвоювала зайняте місце. Потрібен той самий том. |
| Library Import | Copy | Типовий варіант для [Імпорту бібліотеки](/uk/library-import/): копіювати, жорстке посилання або перемістити. Жорстке посилання сіре, доки типовий корінь не перевірено і доки він його не підтримує. |
| Import Extra Files | увімкнено | Головний перемикач для перенесення не-аудіо файлів. Стосується Library Import, Manual Import і завершених завантажень |
| Extra File Extensions (розширений) | порожньо | Ще типи файлів, які переносяться разом із книжкою під власними назвами, наприклад `srt, lrc`. З крапкою чи без, через кому або пробіл. Заборонені типи, як-от виконувані файли й недокачані завантаження, зберегти не можна. Неактивний, поки вимкнено **Import Extra Files** |
| Preferred Cover (розширений) | Matched | Обкладинка зіставленого видання або найкраще зображення з теки, коли є обидві |

**Import Extra Files** переносить разом з аудіо інші файли книжки. П'ять перемикачів вибирають, які види файлів переносяться, а файл, що підпадає під **Extra File Extensions**, переноситься, навіть якщо його вид вимкнено:

| Перемикач | За замовчуванням | Що охоплює |
|---|---|---|
| Cover art | увімкнено | Обкладинка плюс скани задньої обкладинки та буклета |
| Book info files | увімкнено | metadata.json, .opf, .nfo, desc.txt, reader.txt |
| PDFs and companion docs | вимкнено | PDF, що йдуть разом із книжкою |
| Chapters, transcripts and playlists | увімкнено | .cue, списки розділів, субтитри, тексти, плейлисти. Назви файлів усередині них переписуються під перейменоване аудіо. |
| Audible originals and ebooks | вимкнено | .aax/.aaxc, ваучери, epub і подібне |

Недокачані файли та виконувані файли ніколи не імпортуються. Власний `metadata.json` ABM завжди обробляє сам ABM.

Жорстке посилання тут не те саме, що **Use Hardlinks instead of Copy**. Той параметр для завантажень. Типовий варіант Library Import це лише те, що заздалегідь вибрано в діалозі Add to Library.

## Керування файлами (File Management)

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Unmonitor Deleted Books | вимкнено | Книжка, видалена з диска, перестає відстежуватися |
| Change File Date | None | Змінює дати файлів під час імпорту та повторного сканування |
| Enable Recycling Bin | увімкнено | Видалені файли книжок переносяться в кошик, а не видаляються |
| Recycling Bin | порожньо | Де кошик. Якщо порожньо, використовується типовий шлях ABM (`/config/recycle/media`) |
| Recycling Bin Cleanup | 7 (днів) | 0 вимикає автоматичне очищення |
| Library Scan Interval | 24 | Скільки годин між автоматичними скануваннями |
| Watch for Changes | увімкнено | Сканувати, коли файли додаються, видаляються чи змінюються |
| Cover Cache Workers | 4 | Скільки обкладинок завантажується одночасно під час кешування зображень, від 1 до 16 |

## Покращення якості (Quality Upgrades)

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Automatic Upgrade Search | увімкнено | Час від часу шукає кращі релізи завантажених книжок, якість яких ще нижча за поріг. Копія замінює твою, лише якщо це справжнє покращення. |
| Upgrade Search Interval | 24 (години) | Як часто запускається |

## Права доступу (Permissions, розширені)

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Set Permissions | вимкнено | Виконувати chmod під час імпорту та перейменування |
| chmod Folder | 755 | Вісімковий режим для тек і файлів, для файлів без бітів виконання |
| chown Group | порожньо | Назва групи або gid. На віддалених файлових системах використовуй gid |

## Підводні камені

- Якщо кошик увімкнено, але його тека недоступна, видалення, яким він потрібен, завершуються помилкою, а не видаляють файли назавжди.
- Жорсткі посилання працюють лише в межах однієї файлової системи. Файли, на які не можна зробити посилання, копіюються, ніколи не переміщуються, і враховуються в результаті імпорту.

## Book Naming

Book Naming визначає, як я називаю файли й теки. Воно зберігається єдиним Save на сторінці разом з рештою Media Management. У ньому є Rename Books, Replace Illegal Characters, Colon Replacement (з власним варіантом) і формати для Standard Book, Author Folder, Series Folder, Standalone Folder та Book Folder. Кожен формат показує живий приклад, а список токенів показує всі токени, які можна використати.

Library, Series і Authors також мають дію **Organize** для вибраних книг, як і сторінка окремої книги. Спершу вона відкриває попередній перегляд кожної зміни, і нічого не переміщується, доки ти не підтвердиш. Тоді Organize переміщує й перейменовує: переносить теку кожної книги туди, куди її ставлять налаштування іменування, і перейменовує її файли. Він працює як завдання, за яким можна стежити, яке можна скасувати і яке після перезапуску можна відновити з місця зупинки. Одночасно працює лише один Organize. Скасувати не можна, тож уважно перегляньте попередній перегляд. Масове перейменування лишається в Library, Series та Authors як **Rename Files**.

Попередній перегляд показує лише книги, які змінилися б. Познач **Show all selected books**, щоб побачити й решту. Він завантажується сторінками, тож користуйся **Load more**, щоб іти далі у великому виборі. Заголовок перегляду рахує, скільки книг зміниться і скільки буде пропущено.

На сторінці книги, тека якої лежить не там, де її поставили б налаштування іменування, про це сказано, показано теку, куди вона потрапила б, і є кнопка Organize.

Коли нова тека книги опинилася б усередині теки, у якій вона зараз, Organize створює там підтеку й переносить до неї лише власні файли книги: аудіо, а також обкладинку, розділи та інші супровідні файли, які я для неї зберігаю. Усе інше в теці лишається, де було. Попередній перегляд пише "Moves into a subfolder" і перелічує, що лишається, а вікно результату перелічує файли, залишені на місці. Якщо переміщення зривається посередині, уже переміщені файли повертаються. Перенесення теки книги у підтеку самої себе з вікна редагування працює так само.

Library Import дотримується тих самих налаштувань іменування, зокрема коли додає книгу, що вже лежить у кореневій теці, або переносить файли в книгу, яку я вже маю. Коли Rename Books вимкнено, кожен файл зберігає ім'я, з яким прийшов. Файл, ім'я якого зіткнулося б з іншим файлом у пакеті або з тим, що вже є в теці книги (регістр не враховується), натомість отримує ім'я з формату, а імпорт позначає, для яких файлів це зробив. Коли Rename Books увімкнено, файли, що отримали б однакове ім'я, нумеруються за позицією, тож Manual Import ніколи жодного не пропускає.

Типове розташування: `Author/Series/Vol 01 - 2004 - Title [ASIN]/Title - (2004) - (MP3).mp3`. Окрема книга не має теки серії та тому: `Author/2004 - Title [ASIN]/Title - (2004) - (MP3).mp3`. Книга серії без позиції теж починається з року. Невідомий рік пропускається і ніколи не пишеться як `(Unknown)`.

Якщо ти знаєш Sonarr: це Media Management із Sonarr разом із форматами іменування.
