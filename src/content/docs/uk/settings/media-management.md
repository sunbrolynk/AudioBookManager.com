**Settings > Media Management** керує тим, де лежать книги й як у них потрапляють файли. Налаштування, позначені як розширені, з'являються з **Show Advanced**.

## Root Folders

Коренева тека це каталог, у якому ABM керує книгами. Додай її через **Add Root Folder**, що відкриває оглядач тек із полем для введення шляху. ABM також може перелічити незіставлені теки під коренем та імпортувати їх. Вільне місце й підтримка жорстких посилань кореня перевіряються під час додавання. Під час видалення кореня ABM питає, що робити: **Remove from ABM only** (типово) забуває книги під ним і лишає файли, а **Delete the books and their files** назавжди видаляє все під цим шляхом, оминаючи кошик. Якщо в корені є книги, треба ввести підтвердження.

Коренева тека за замовчуванням це та, куди потрапляють нові книги і яка вирішує, чи пропонується hardlink для Library Import.

## Folders

| Налаштування | Типово | Дія |
|---|---|---|
| Create Empty Book Folders | off | Створює відсутні теки книг під час додавання, зміни кореневої теки та сканування диска. Ігнорується, поки ввімкнено **Delete empty folders**, щоб тека не створювалася лише для того, щоб її видалили. |
| Delete empty folders | off | Видаляє порожні теки книг під час сканування диска й коли видаляються файли книги |

## Importing

| Налаштування | Типово | Дія |
|---|---|---|
| Skip Free Space Check | off | На випадок, коли ABM не може визначити вільне місце на корені |
| Minimum Free Space | 100 (МБ) | Імпорт, після якого лишилося б менше, відхиляється |
| Use Hardlinks instead of Copy | on | Для завершених завантажень: жорстке посилання замість копії, щоб роздавання не подвоювало місце. Потрібен той самий том. |
| Library Import | Copy | Типове значення для [Library Import](/uk/library-import/): copy, hardlink або move. Hardlink неактивний, доки типовий корінь не перевірено і він його не підтримує. |
| Import Extra Files | on | Головний перемикач перенесення неаудіофайлів. Стосується Library Import, Manual Import і завершених завантажень |
| Extra File Extensions (advanced) | порожньо | Додаткові типи файлів, які переносяться під власними назвами, наприклад `srt, lrc`. З крапкою чи без, через кому або пробіл. Заблоковані типи, як-от виконувані файли й незавершені завантаження, зберегти не можна. Недоступно, поки **Import Extra Files** вимкнено |
| Preferred Cover (advanced) | Matched | Обкладинка зіставленого видання або найкраще зображення теки, коли є обидва |

**Import Extra Files** переносить разом з аудіо інші файли книги. П'ять перемикачів обирають, які саме, а файл, що відповідає **Extra File Extensions**, переноситься навіть тоді, коли його вид вимкнено:

| Перемикач | Типово | Охоплює |
|---|---|---|
| Cover art | on | Обкладинку, а також скани задньої обкладинки та буклета |
| Book info files | on | metadata.json, .opf, .nfo, desc.txt, reader.txt |
| PDFs and companion docs | off | PDF, що постачаються з книгою |
| Chapters, transcripts and playlists | on | .cue, списки розділів, субтитри, тексти пісень, плейлісти. Імена файлів у них переписуються на перейменоване аудіо. |
| Audible originals and ebooks | off | .aax/.aaxc, ваучери, epub і подібне |

Часткові завантаження та виконувані файли ніколи не імпортуються. Власний `metadata.json` ABM завжди обробляє сам ABM.

Hardlink це не те саме, що **Use Hardlinks instead of Copy**. Той стосується завантажень. Типове значення Library Import лише визначає, що діалог Add to Library вибирає наперед.

## File Management

| Налаштування | Типово | Дія |
|---|---|---|
| Unmonitor Deleted Books | off | Книга, видалена з диска, перестає відстежуватися |
| Change File Date | None | Змінює дати файлів під час імпорту та повторного сканування |
| Enable Recycling Bin | on | Видалені файли книг переміщуються в кошик замість остаточного видалення |
| Recycling Bin | порожньо | Де кошик. Порожнє значення використовує типове для ABM (`/config/recycle/media`) |
| Recycling Bin Cleanup | 7 (днів) | 0 вимикає автоматичне очищення |
| Library Scan Interval | 0 (off) | Годин між автоматичними скануваннями |
| Watch for Changes | off | Сканувати, коли файли додаються, видаляються чи змінюються |
| Cover Cache Workers | 4 | Скільки обкладинок завантажується одночасно під час кешування ілюстрацій, від 1 до 16 |

## Quality Upgrades

| Налаштування | Типово | Дія |
|---|---|---|
| Automatic Upgrade Search | on | Періодично шукає кращі релізи завантажених книг, які ще не досягли порога. Копія замінює твою, лише якщо це справжнє покращення. |
| Upgrade Search Interval | 24 (годин) | Як часто це виконується |

## Permissions (advanced)

| Налаштування | Типово | Дія |
|---|---|---|
| Set Permissions | off | Виконувати chmod під час імпорту та перейменування |
| chmod Folder | 755 | Вісімковий режим для тек і файлів, без бітів виконання для файлів |
| chown Group | порожньо | Ім'я групи або gid. На віддалених файлових системах використовуй gid |

## Підводні камені

- Якщо кошик увімкнено, але його теки немає, видалення, яким він потрібен, завершуються помилкою замість остаточного видалення.
- Жорсткі посилання працюють лише в межах однієї файлової системи. Файли, які не можна зв'язати, копіюються, ніколи не переміщуються, і враховуються в результаті імпорту.

Якщо ти знаєш Sonarr: це Media Management із Sonarr без форматів іменування. Назви тек обирає ABM. Масове перейменування розташовано в Library, Series і Authors як **Rename Files**.
