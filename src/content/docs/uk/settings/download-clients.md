---

**Settings > Download Clients** підключає програму, що виконує завантаження.

## Підтримувані клієнти

Deluge, qBittorrent, Transmission, rTorrent, SABnzbd, NZBGet і Blackhole (тека спостереження). Це повний перелік.

## Поля

Які поля показано, залежить від клієнта.

| Поле | Дія |
|---|---|
| Name | Назва |
| Host, Port, URL Base | Де слухає клієнт |
| Use SSL, Verify TLS certificate | HTTPS і чи перевіряється сертифікат |
| Username, Password, API Key | Облікові дані. Збережений секрет ніколи не показується |
| Category | Категорія чи мітка, яку ABM ставить на свої завантаження, наприклад `audiobooks` |
| Watch Folder, Directory | Blackhole: куди класти файли й де з'являються готові |
| Client Priority | Який клієнт перемагає, коли підходить кілька |
| Remove from Client, Also Delete Files, Remove Failed | Що ABM вилучає з клієнта після імпорту чи збою |
| Queue Page Remove Action | Що робить вилучення рядка на сторінці Queue: прибрати лише з ABM, видалити з клієнта зі збереженням файлів або видалити разом із файлами |

**Test** перевіряє підключення. Вимкнений клієнт не є несправним. Клієнт, що збоїть, перевіряється повторно з наростаючою затримкою.

## Обробка завершених завантажень

| Налаштування | Типово | Дія |
|---|---|---|
| Enable | on | Автоматично імпортувати завершені завантаження |
| Redownload Failed | on | Занести невдалий реліз у blocklist і шукати знову |
| Redownload Failed from Interactive Search | on | Те саме для релізів, обраних вручну |

Чи імпорт робить жорсткі посилання, чи копіює, визначає **Use Hardlinks instead of Copy** у [Керування медіафайлами](/uk/settings/media-management/). Якщо тека клієнта має інший шлях, ніж бачить ABM, додай віддалене зіставлення шляхів.

## Віддалені зіставлення шляхів

Коли клієнт повідомляє `/downloads/audiobooks`, а ABM бачить це як `/data/audiobooks`, додай зіставлення.

| Поле | Дія |
|---|---|
| Host | Хост клієнта, для якого створено зіставлення |
| Remote Path | Шлях, як його повідомляє клієнт |
| Local Path | Та сама тека, як її бачить ABM |

## Підводні камені

- Підтека, яку неможливо прочитати, у завершеному завантаженні повністю зупиняє імпорт цього завантаження. З клієнта нічого не вилучається, і спроба повторюється пізніше.
- Docker: за можливості монтуй теку завантажень за однаковим шляхом в обох контейнерах. Зіставлення це запасний варіант.
