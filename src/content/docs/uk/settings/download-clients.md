---

**Settings > Download Clients** підключає програму, яка займається завантаженням.

## Підтримувані клієнти

Deluge, qBittorrent, Transmission, rTorrent, SABnzbd, NZBGet і Blackhole (тека спостереження). Це повний список.

## Поля

Які поля видно, залежить від клієнта.

| Поле | Що робить |
|---|---|
| Name | Назва |
| Host, Port, URL Base | Де слухає клієнт |
| Use SSL, Verify TLS certificate | HTTPS і чи перевіряється сертифікат |
| Username, Password, API Key | Облікові дані. Збережений секрет ніколи не показується |
| Category | Категорія чи мітка, яку ABM ставить на свої завантаження, наприклад `audiobooks` |
| Watch Folder, Directory | Для Blackhole: куди класти файли і де з'являються завершені |
| Client Priority | Який клієнт перемагає, коли підходять кілька |
| Remove from Client, Also Delete Files, Remove Failed | Що ABM прибирає з клієнта після імпорту чи збою |
| Queue Page Remove Action | Що робить прибирання рядка на сторінці Queue: лише прибрати з ABM, прибрати з клієнта й залишити файли або прибрати й видалити файли |

**Test** перевіряє з'єднання. Вимкнений клієнт не вважається несправним. До клієнта, що не відповідає, ABM повертається з дедалі довшими паузами.

## Обробка завершених завантажень

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| Enable | увімкнено | Автоматично імпортувати завершені завантаження |
| Redownload Failed | увімкнено | Додати невдалий реліз у чорний список і шукати знову |
| Redownload Failed from Interactive Search | увімкнено | Те саме для релізів, які ти вибрав вручну |

Чи імпорт робить жорсткі посилання, чи копіює, визначає **Use Hardlinks instead of Copy** у [Керуванні медіа](/uk/settings/media-management/). Якщо тека клієнта має не той шлях, який бачить ABM, додай зіставлення віддаленого шляху.

## Зіставлення віддалених шляхів

Коли клієнт повідомляє `/downloads/audiobooks`, а ABM бачить це як `/data/audiobooks`, додай зіставлення.

| Поле | Що робить |
|---|---|
| Host | Хост клієнта, для якого це зіставлення |
| Remote Path | Шлях так, як його повідомляє клієнт |
| Local Path | Та сама тека так, як її бачить ABM |

## Підводні камені

- Якщо в завершеному завантаженні є підтека, яку не можна прочитати, імпорт цього завантаження повністю зупиняється. З клієнта нічого не прибирається, і пізніше буде нова спроба.
- Docker: коли можеш, монтуй теку завантажень за тим самим шляхом в обох контейнерах. Зіставлення це запасний варіант.
