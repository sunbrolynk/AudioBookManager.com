title: 記錄檔
description: 記錄檔、記錄等級、保留期限和輪替。
---

**System > Log Files** 會列出 ABM 的文字記錄檔。打開一個就能閱讀、下載或刪除，也可以一次全部清除。記錄檔會隨著操作執行而出現。

- 任務和轉換會寫自己的記錄檔。Tasks 頁面上每一個都有連結。
- 主要記錄檔是 `app.log`。它會在啟動時、至少每小時一次，以及達到 10 MiB 時輪替。舊檔案會依 **Log File Retention**（預設 30 天）保留。
- 另外有一個安全性記錄檔，每次登入嘗試寫一行，給 fail2ban 之類的工具使用。
- 記錄等級在 **Settings > General > Logging** 設定。

## 怎麼看問題

從失敗任務的記錄按鈕開始看。它會顯示那個操作從開始那一行到結束區塊的內容。文字裡的密鑰會被遮蔽，但要公開貼記錄檔之前，還是先檢查一下。

## 要注意的地方

- SQL Logging 和 Debug 等級非常冗長。用完記得關掉。
- 刪除記錄檔後，連到它的活動紀錄還會留著，會顯示「Log no longer kept」。
