---
title: 書庫匯入
description: 用匯入工作台（Import Workbench）把現有收藏帶進 ABM。
---

書庫匯入會掃描一個有聲書資料夾，把每個資料夾對上中繼資料，然後把書加進你的書庫。**Library > Library Import** 會開啟「Import audiobooks you already have」，讓你挑一個資料夾來掃描。掃描開始後，ABM 會切換到配對頁面，標題是 **Match Audiobooks**，你在那裡檢查配對結果並加入書。

## 流程

1. 掃描資料夾。每個有音訊的資料夾都會變成一列。
2. 檢查比對結果，把需要修正的修好。
3. 選取那些列，加進書庫。

每個選項都只是選擇性地覆寫 Media Management 裡的預設值。單純掃描再加入，永遠不會超過兩下。

## 看懂清單

- 摘要會顯示找到幾個資料夾、對上了幾個。可以依 All、Matched、Needs attention、Unmatched、In library 或 Failed lookup 篩選清單。篩選條件會記在頁面網址裡。
- 每一列會顯示封面、書名、作者和系列，以及比對的把握有多大（用百分比表示，例如「95% match」）。資料夾詳細資料裡有 **Find a match** 或 **Change match** 可以手動搜尋。
- 如果檔案裡沒有 ASIN 或播放長度可以確認版本，資料夾詳細資料會告訴你。
- **Rescan** 會抓到掃描後才新增的資料夾，並保留你做過的選擇。

在註解或簡介裡找到的 ASIN 只是提示。只有在書名也跟資料夾名稱吻合時，才算是對上。只有專用的 ASIN 標籤可以單獨算數。

## 合併、分割和加入

- 把其實是同一本書、只是分散在不同資料夾的列合併起來。之後可以在資料夾詳細資料裡再分開。
- 無法加入時，按鈕上方會顯示原因，例如「Select at least one folder」或「2 selected rows still need a decision」。
- 任何會移除或取代檔案的動作，都會先問你。
- 離開頁面時，你還沒完成的編輯會被儲存。

## 複製、移動或硬連結

**Settings > Media Management > Importing** 設定書庫匯入的預設方式：複製（預設）、移動或硬連結。每次匯入都可以另外選。

硬連結的書不會多佔磁碟空間，原本的檔案也會留在原地。硬連結需要預設根資料夾支援，而且要先檢查過。不然這個選項會變成灰色，並顯示原因。無法建立連結的檔案（例如在另一顆硬碟上的）會改用複製，絕對不會被移動。匯入完成時會告訴你有幾個是用複製的。

## 額外檔案

**Import Extra Files**（預設開啟）會把書的封面、筆記和其他非音訊檔案一起帶過來。它同時適用於書庫匯入、手動匯入和下載完成的檔案。打開 **Show Advanced** 後，**Preferred Cover** 可以選擇用對上的 Audible 封面（預設）或資料夾自己的封面。

## 很長的值

被刪節號截斷的朗讀者、書名或路徑，點一下就會完整展開，再點一次就收起來。用滑鼠的話，游標停在上面也會顯示完整內容。用鍵盤的話，把焦點移過去，再按 Enter 或空白鍵。

## 匯入以外的處理方式

一列也可以用 **keep library**（拒絕一本書庫裡已經有的書的副本）或 **remove empty**（拒絕一個沒有音訊、但還放著圖片和附屬檔案的資料夾）來處理。這些只會清掉那一列擁有的東西。任何有音訊的東西都會被拒絕刪除。有設定資源回收筒的話，檔案會進回收筒，任務記錄也會列出每一個被移除的路徑。

## 每個資料夾的封面和額外檔案

檢查面板會把資料夾自己的封面和對上版本的封面並排顯示，各自標出像素尺寸。點一下就能換成另一個。下面的 **Extra files** 會列出其他所有檔案，並依照它們所對應的 Media Management 開關名稱分組。如果某個選擇跟設定不一樣，會用一個圓點標出來；**Apply this cover and these file choices to the N other selected** 可以把一個資料夾的選擇套用到其他選取的資料夾。如果某一列是把檔案加到書庫裡已經有的書，就不會有選擇器。
