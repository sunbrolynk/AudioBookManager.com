---
title: 書庫匯入
description: 用匯入工作台（Import Workbench）把現有收藏帶進 ABM。
---

書庫匯入會掃描一個有聲書資料夾，把每個資料夾對上中繼資料，然後把書加進你的書庫。**Library > Library Import** 會開啟「Import audiobooks you already have」，讓你挑一個資料夾來掃描。掃描開始後，ABM 會切換到配對頁面，標題是 **Match Audiobooks**，你在那裡檢查配對結果並加入書。

## 流程

1. 掃描資料夾。每個有音訊的資料夾都會變成一列。
2. 檢查比對結果，把需要修正的修好。
3. 勾選你要的列，然後把它們加進書庫，或是刪除。

每個選項都只是選擇性地覆寫 Media Management 裡的預設值。

## 什麼時候會確認對應

只有檔案本身能佐證時，掃描才會確認一個對應：

- 用檔案自己標籤裡的 ASIN 找到了這本書，或者
- 這本書的長度和檔案相差不超過三分鐘，而且它在系列裡的序號或書名和檔案對得上。

作者或系列序號和檔案矛盾的書會被排除。如果檔案同樣符合兩本不同的書或兩個不同的錄音版本，哪個都不會確認。

只有這本書的每個檔案都能讀取時，才會計算檔案的長度。只要有一個無法測量，這一列就沒有長度：這時只有它的 ASIN 能確認配對，否則這本書會在 **Needs a look** 等待。

一本書有兩種格式時，每種格式各自成一列，分別測量。分成不同格式分段的書，如果有自己的資料夾，就是一列，各分段的長度會加起來。包含一本書兩種格式的已完成下載會當成一份副本測量；如果兩份副本的長度相差超過三分鐘，就沒有可用來配對的長度。

依長度只會接受英文版，或條目沒有標示語言的版本。其他語言的版本只有在檔案自己的 ASIN 找到它時才會被接受。來自[本機儲存](/zh-tw/settings/metadata/)而不是即時查詢的書，沒有你確認絕不會被接受。

一列的某個查詢失敗時，只接受 ASIN 配對。只靠搜尋作者找到的書，只有長度和檔案相符時才會被建議，所以沒有條目的書會顯示 **Unmatched**，而不是建議這位作者的另一本書。

其他對應仍然會作為建議提供，但這一列算在 **Needs a look** 裡，一開始不勾選，**Select All** 也會跳過它，直到你確認這個對應或選了別的。確認對應到你書庫裡已有的書時，這一列算在 **In library** 裡。 建議是書庫中書籍的 **Needs a look** 列，要等你確認該配對後才會提出關於書庫的問題。在那之前，勾選它會被當成還需要決定的列而擋住 Add。

一本書分成好幾個零散檔案，和別的書放在同一個資料夾裡（例如作者資料夾，或你掃描的資料夾），會合成一列，包含所有部分。書號或卷號不同的檔案仍然是各自的列。 分段依格式分組：旁邊的整本書檔案自成一列，檔名裡的位元率（例如 `128kbps`）不算分段編號。

同一本書的兩種格式（例如 `Book.mp3` 和 `Book.m4b`），不論檔案是直接放在你掃描的資料夾裡，還是放在這本書自己的資料夾裡，都是不同的列。每一列只匯入、移除和測量自己的檔案。同名的封面、cue 或其他非音訊檔案，在這本書只有一種格式時會跟著書的檔案走，有兩種格式時則留在原處。即使在同一次匯入中一份副本被移進書庫、另一份被移除，也是如此。

寫成 `Title: Series, Book 2` 這種格式的標籤，會被拆開讀成書名、系列和序號。

寫成範圍的系列位置（例如 `1-3`）和其中任何位置都相符。用其他方式寫的兩個數字（例如 `1, 3`）視為沒有位置。

超過 500 個字元的標題、專輯、系列、系列序號、演出者、專輯演出者、作曲者或朗讀者標籤會被忽略。

Library Import 頁面上的 **Recent Import Sessions** 會顯示每次掃描有多少列已對應（包括書庫裡已有的書），以及多少列待處理（包括還等你選對應的列）。

## 看懂清單

- 摘要會顯示找到幾個資料夾、有幾個已經就緒。頂端列有 **Sort** (Folder name, Status, Title, Author, Series, Files) 和 **Filter** (Ready, Needs a look, No audio, Unmatched, In library, Lookup failed, Needs a decision, Looking up, Deleted on add)。每個篩選都會顯示數量，而這些數量和摘要對得起來。你確認過的配對叫做 Ready。排序和篩選會記在這台裝置上。它們不會留在頁面網址裡，所以帶有 `?sort=` 或 `?filter=` 的連結不會把它們帶過去。
- 每一列會顯示封面、書名、作者和系列，以及比對的把握有多大（用百分比表示，例如「95% match」）。資料夾詳細資料裡有 **Find a match** 或 **Change match** 可以手動搜尋。搜尋會列出 Libex 找到的每一本書。
- 如果檔案裡沒有 ASIN 或播放長度可以確認版本，資料夾詳細資料會告訴你。
- **Rescan** 會抓到掃描後才新增的資料夾，並保留你做過的選擇。

在註解或簡介裡找到的 ASIN 只是提示。只有在書名也跟資料夾名稱吻合時，才算是對上。只有專用的 ASIN 標籤可以單獨算數。

## 合併、分割和加入

- 把其實是同一本書、只是分散在不同資料夾的列合併起來。之後可以在資料夾詳細資料裡再分開。 合併後那一列的配對只是建議：它算在 **Needs a look**，在你確認或另選之前維持未勾選。只有每個部分都有長度時，它的長度才是各部分的總和；只有所有部分給出同一個 ASIN 時，它才保留 ASIN。由檔名相同的兩種格式合併成的書只算一次，取較長那種格式的長度；如果兩者相差超過三分鐘，或合併的某一列已經包含兩種格式，就沒有長度。在你合併或分割某列之後才完成的查詢，也只是建議。
- 列詳細資料中的 **Confirm match** 會勾選 **Needs a look** 列，**Undo confirmation** 會連同勾選一起取消。
- 無法加入時，按鈕上方會顯示原因，例如「Select at least one folder」或「2 selected rows still need a decision」。兩列指向同一個資料夾或檔案時，加入也會被拒絕，什麼都不會動。
- 任何會移除或取代檔案的動作，都會先問你。
- 離開頁面時，你還沒完成的編輯會被儲存。

## 複製、移動或硬連結

**Settings > Media Management > Importing** 設定書庫匯入的預設方式：複製（預設）、移動或硬連結。每次匯入都可以另外選。

硬連結的書不會多佔磁碟空間，原本的檔案也會留在原地。硬連結需要預設根資料夾支援，而且要先檢查過。不然這個選項會變成灰色，並顯示原因。無法建立連結的檔案（例如在另一顆硬碟上的）會改用複製，絕對不會被移動。匯入完成時會告訴你有幾個是用複製的。

## 額外檔案

**Import Extra Files**（預設開啟）會把書的封面、筆記和其他非音訊檔案一起帶過來。它同時適用於書庫匯入、手動匯入和下載完成的檔案。打開 **Show Advanced** 後，**Preferred Cover** 可以選擇用對上的 Audible 封面（預設）或資料夾自己的封面。

## 很長的值

被刪節號截斷的朗讀者、書名或路徑，點一下就會完整展開，再點一次就收起來。用滑鼠的話，游標停在上面也會顯示完整內容。用鍵盤的話，把焦點移過去，再按 Enter 或空白鍵。

## 匯入以外的處理方式

一列也可以用 **keep library**（拒絕一本書庫裡已經有的書的副本）或 **remove empty**（拒絕一個沒有音訊、但還放著圖片和附屬檔案的資料夾）來處理。這些只會清掉那一列擁有的東西。**remove empty** 會拒絕刪除任何有音訊的東西。有設定資源回收筒的話，檔案會進回收筒，任務記錄也會列出每一個被移除的路徑。 **keep library** 的決定只對它所針對的那本書庫書籍有效：如果你選了一個詢問其他事情或另一本書庫書籍的配對，這一列會重新詢問。匯入執行時會再檢查一次，如果那時書庫中的副本已經沒有檔案 ("Your library has no copy of this book to keep")，或資料夾裡有你書庫中某本書的檔案 ("This folder holds files of a book in your library")，就不會刪除任何東西。不匯入、而是移除檔案的列，要等同一次加入裡的每個匯入都完成後才會執行；如果那時它的任何檔案屬於你書庫中的某本書，就會被拒絕。所以它們絕不會移除同一批裡剛被用來加入書的檔案。

## 每個資料夾的封面和額外檔案

檢查面板會把資料夾自己的封面和對上版本的封面並排顯示，各自標出像素尺寸。點一下就能換成另一個。下面的 **Extra files** 會列出其他所有檔案，並依照它們所對應的 Media Management 開關名稱分組。如果某個選擇跟設定不一樣，會用一個圓點標出來；**Apply this cover and these file choices to the N other selected** 可以把一個資料夾的選擇套用到其他選取的資料夾。如果某一列是把檔案加到書庫裡已經有的書，就不會有選擇器。
