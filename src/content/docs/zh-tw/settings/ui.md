---

**Settings > UI** 只影響顯示。

| 設定 | 選項 |
|---|---|
| First Day of Week | Sunday 或 Monday |
| Week Column Header | `Tue 3/25`、`Tue 25/3` 或 `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`、`25 Mar 2014`、`03/25/2014`、`25/03/2014`、`2014-03-25` |
| Long Date Format | 四種版面，可以選擇要不要顯示星期 |
| Time Format | 12 小時制或 24 小時制 |
| Show Relative Dates | 用「今天」和「昨天」取代日期 |
| Theme | Auto（跟著你的作業系統）、Light 或 Dark |
| Enable Color-Impaired Mode | 調整色彩標示，讓各種狀態更容易分辨 |

預設值在 App 裡。這些設定由使用這個執行個體的所有人共用。
