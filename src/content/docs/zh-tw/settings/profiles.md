**Settings > Profiles** 是一個分成三個區塊的頁面。它們回答的是關於一個發行版本的三個不同問題。

## 品質設定檔

品質設定檔是一個格式的階梯，最差的在最下面，最好的在最上面。每一階是一種格式（M4B、M4A、MP3、FLAC、OGG、Opus、AAC、WMA），分成單檔或多檔兩種形式。階可以分組，讓它們排名相同，也可以把某一階關掉。

| 設定 | 意思 |
|---|---|
| Upgrades Allowed | 關閉時，書一旦有了檔案，ABM 就不會再取代它 |
| Upgrade Until | 門檻。達到這個品質後，ABM 就不再升級 |
| Grab off-ladder formats | 抓取不在清單上的格式，而不是跳過這本書 |
| Default profile | 沒有更具體的設定檔時使用的設定檔 |

其中一個設定檔是預設的。一本書會依序使用：它自己的設定檔、主要系列的設定檔、主要作者的設定檔，最後才是預設設定檔。正在使用中的設定檔不能刪除。

新的版本只有在以下條件全部成立時，才會取代你現有的：設定檔允許升級、新的那一階在階梯上而且有啟用、書還沒達到門檻，而且新的那一階排名嚴格高於現有的。

如果你熟悉 Sonarr：這就是品質設定檔，只是品質是音訊格式和檔案結構，而不是解析度。沒有自訂格式。〈[發行設定檔](#發行設定檔)〉涵蓋了類似的功能。

這裡沒有位元率或檔案大小的分級：品質只看格式和檔案結構。對一個發行版本，ABM 會從索引器或標題取得格式，並從標題猜出檔案結構（沒有分段或音軌編號的 M4B 會算成單一檔案），等檔案匯入後再檢查一次。〈[Audible 設定](/zh-tw/settings/audible/)〉裡的 **Preferred Quality** 是另一回事：那是 Audible 下載下來的品質。

## 延遲設定檔

延遲設定檔會在抓取前先把發行版本壓著，給更好的版本一點時間出現。

| 設定 | 意思 |
|---|---|
| Enable Usenet / Enable Torrent | 允許從那個協定抓取 |
| Usenet Delay / Torrent Delay | 抓取那個協定的發行版本前要等幾分鐘 |
| Preferred Protocol | 兩種協定都找到符合的結果時，優先用哪一種 |
| Bypass if Highest Quality | 發行版本已經達到設定檔的門檻時，跳過延遲 |
| Tags | 這個設定檔只套用在有符合標籤的項目上 |

延遲設定檔以表格顯示，跟 Sonarr 一樣。

## 發行設定檔

發行設定檔會在品質之上再加一層規則。

| 欄位 | 意思 |
|---|---|
| Enable Profile | 開啟或關閉 |
| Must Contain | 發行版本至少要包含其中一個詞（不分大小寫） |
| Must Not Contain | 包含任何一個這些詞的發行版本會被拒絕 |
| Preferred | 會替發行版本加分或扣分的詞。寫成 `/regex/` 就能用正規表示式 |
| Narration language | 限制朗讀語言 |
| Indexer | 套用在某一個索引器，或任何索引器 |
| Tags | 只套用在有符合標籤的項目上 |

發行設定檔以表格顯示。

## 要注意的地方

- 設定檔永遠不會刪除檔案。它們只決定要抓什麼，以及什麼算升級。
- 延遲設定檔或發行設定檔上的標籤，會把它限制在帶有其中某個標籤的書上。
