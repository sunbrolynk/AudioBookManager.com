---
title: 在手機上使用
description: ABM 在寬度小於 768px 的螢幕上會怎麼呈現。
---

寬度小於 768px 時，ABM 會用手機版面。768px 到 1023px 之間，側邊欄會縮成只剩圖示；1024px 以上才會有完整的側邊欄。

## 導覽

手機版沒有側邊欄。底部有一條列，裡面有五個分頁：Library、Activity、Wanted、Settings 和 System。底下有好幾個頁面的分頁，會在上方打開一個小選單。Library 裡有 Books、Authors、Series、Add New、Library Import、Audible Library、Conversions 和 Discover 頁面。Activity 裡有 Queue、History、Calendar 和 Blocklist。點一下標誌就會回到 Dashboard。

## 頂端列

頁面上的動作都是圖示。放不下的會收在 **More actions** 裡，點了會打開一個選單。在 Indexers、Download Clients、Import Lists、Connect、Profiles 和 Tags 頁面上，新增是頂端列的加號按鈕。設定頁的 Save 會變成固定在螢幕底部的一條列。

在頁面頂端往下拉就能重新整理。

## 清單

- 標題列下方有一條工具列，裡面有 Sort、Filter 和檢視切換。啟用篩選時，Filter 會變成紫色，儲存過的篩選和自訂篩選都在它的選單裡。Queue、History 和 Discover 這類分頁的清單還可以設定每頁列數。
- Books 有 Table、Posters 和 Overview 三種檢視。Series 和 Authors 有 Posters 和 Overview。在 Table 和 Overview 裡，每本書是一列：封面、書名、作者和朗讀者、幾個小標籤、一個狀態圓點和評分。
- 海報大小決定欄數：小是 3 欄，中是 2 欄，大是 1 欄。
- 點一下那一列就會打開它。其他動作都在 **...** 按鈕後面，它會打開一個動作選單。
- A 到 Z 的字母列固定在右邊。螢幕很矮的時候（例如把手機橫著拿）會隱藏起來。
- 總數和狀態圖例放在清單的最後面。
- Queue 和 History 這類表格會把每一列顯示成一張卡片。

## 選取

在選取模式下，點一下列就會選取它。選取列會取代底部的分頁，按返回就會離開選取模式。

## 書、系列和作者頁面

書的頁面頂端有 Search、Interactive、Import（有檔案之後會變成 Convert）和 Refresh，旁邊還有 Edit 和一個 Actions 選單，下方則有 Overview、Files、Chapters 和 History 分頁。在系列頁面上，點一下你沒有的書會打開它的動作選單。

## 其他頁面

- Calendar 是一天一天排下去的清單。用檢視選擇器設定時間範圍。沒有 Agenda 檢視。
- Conversions 有 Queue 和 History 兩個分頁。
- Dashboard 的卡片會疊成一欄。
- 對話框會從螢幕底部以選單的方式滑出來。

## 設定

Settings 是一個分組清單：Library、Sources 和 App。每一列都是一個連結，標出頁面名稱和它的用途。下載用戶端、索引器和其他項目都是全寬的卡片。

## 匯入工作台（Import Workbench）

- 摘要卡片會顯示有幾個資料夾準備好了。點一下可以打開圖例並篩選清單。
- 底部列會顯示選了幾個，以及 Add 按鈕，如果 Add 無法使用，它也會告訴你原因。
