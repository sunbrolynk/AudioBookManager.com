---
title: 名詞解釋
description: 給新手，也給從 arr 系列轉過來的人的名詞說明。
---

**ASIN**：Audible 用來識別書的十個字元代碼。ABM 就是用它來認書。

**自動標籤（Auto tag）**：一條規則，會替符合條件的書加上標籤。

**封鎖清單（Blocklist）**：ABM 不會再抓的發行版本。

**Connect**：管理通知和媒體伺服器掛鉤的設定頁。Sonarr 也是這樣叫。

**封面鎖定（Cover lock）**：你自己選的封面，重新整理時不會被換掉。

**門檻（Cutoff）**：品質設定檔裡的「Upgrade Until」，也就是 ABM 停止找更好版本的那個品質。

**延遲設定檔（Delay profile）**：抓取前先等一段時間，依協定分別設定。

**探索（Discover）**：可以瀏覽的 Audible 目錄。

**硬連結（Hardlink）**：同一個檔案在同一個檔案系統上的第二個名字，不會多佔空間。

**匯入工作台（Import Workbench）**：書庫匯入背後的頁面名稱。掃描、比對、加入。

**索引器（Indexer）**：ABM 用來搜尋發行版本的網站。

**階梯（Ladder）**：品質設定檔裡排好順序的格式清單。

**Libex**：ABM 用來查詢書籍資料的中繼資料服務。

**已監控／未監控（Monitored / Unmonitored）**：ABM 會不會對這本書採取動作。

**M4B**：帶有章節的單檔有聲書格式。

**品質設定檔／發行設定檔（Quality profile / release profile）**：請看〈[設定檔](/zh-tw/settings/profiles/)〉。

**遠端路徑對應（Remote path mapping）**：把下載用戶端看到的路徑換成 ABM 看到的路徑。

**根資料夾（Root folder）**：ABM 存放書的目錄。

**附屬檔案（Sidecar）**：放在音訊旁邊的小檔案：封面、OPF、簡介、朗讀者、cue。

**再次驗證密碼（Step-up password）**：在做敏感變更之前，再問你一次密碼。

**想要（Wanted）**：已監控但還沒有檔案的書。

## 如果你熟悉 Sonarr

一集就是一本書。系列既是 Sonarr 的系列，也是一個書的目錄。品質是格式加上單檔或多檔。自訂格式變成發行設定檔。Activity、Wanted、Calendar 和 System 的用法都一樣。
