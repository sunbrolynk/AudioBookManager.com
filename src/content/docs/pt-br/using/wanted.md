**Wanted** tem duas páginas.

## Missing (faltando)

Livros monitorados sem arquivos. Em cada linha: **Auto Search**, **Interactive Search**, **Manual Import**, **Unmonitor**.

- Auto Search consulta todos os indexadores ativados e baixa a melhor release que os perfis permitem.
- Interactive Search lista as releases para você escolher. Uma escolha feita aqui conta como download manual.
- Manual Import aponta o ABM para arquivos que você já tem.

O ABM também procura os livros que faltam por conta própria. As releases ficam seguradas pelo perfil de atraso antes de serem baixadas. Veja [Perfis](/pt-br/settings/profiles/).

## Cutoff Unmet (abaixo do cutoff)

Livros baixados cuja qualidade ainda está abaixo do cutoff do perfil ("Upgrade Until"). **Search All Cutoff Unmet** procura por eles. Uma cópia melhor só substitui a antiga quando fica acima dela na escala.

**Media Management > Quality Upgrades** pode fazer essa busca por você: **Automatic Upgrade Search** (ligado por padrão) a cada **Upgrade Search Interval** (24 horas por padrão). Veja [Media Management](/pt-br/settings/media-management/).

Se você conhece o Sonarr: é a mesma ideia de Wanted > Cutoff Unmet, com uma escala de formatos (M4B, MP3 e assim por diante, em arquivo único ou vários arquivos) no lugar de resoluções.
