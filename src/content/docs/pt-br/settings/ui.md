description: Calendário, formatos de data, tema e opções de cor.
---

**Settings > UI** é só de exibição.

| Configuração | Opções |
|---|---|
| First Day of Week | Sunday ou Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` ou `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Quatro layouts, com ou sem o dia da semana |
| Time Format | 12-hour ou 24-hour |
| Show Relative Dates | Today e Yesterday em vez de datas |
| Theme | Auto (segue o seu sistema operacional), Light ou Dark |
| Enable Color-Impaired Mode | Muda o código de cores para os status ficarem mais fáceis de diferenciar |

Os padrões estão no app. Essas configurações são compartilhadas por todo mundo que usa a instância.
