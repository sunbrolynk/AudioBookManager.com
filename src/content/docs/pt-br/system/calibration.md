---
title: Calibração
description: Como o ABM aprende a estimar o tempo das conversões.
---

Cada conversão concluída registra quanto tempo levou em relação à duração do áudio. O ABM ajusta uma reta a essas amostras e usa ela para prever quanto tempo o próximo trabalho vai levar. **System > Calibration** mostra o que ele aprendeu para cada tipo de trabalho: converter, juntar, dividir e adicionar capítulos.

- **Samples for Full Confidence** é quantos trabalhos concluídos ele quer antes de confiar numa estimativa.
- Um botão recalcula todos os coeficientes. Use se as estimativas parecerem erradas depois de uma troca de hardware.

Nada aqui é uma configuração que você precise mexer.
