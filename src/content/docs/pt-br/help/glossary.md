**ASIN**: o identificador de livro da Audible, com dez caracteres. O ABM identifica os livros por ele.

**Auto tag**: uma regra que aplica tags aos livros que atendem a certas condições.

**Blocklist**: releases que o ABM não vai baixar de novo.

**Connect**: a página de configurações para notificações e integrações com servidores de mídia. O termo também é do Sonarr.

**Cover lock** (trava de capa): uma capa que você escolheu e que as atualizações não vão substituir.

**Cutoff**: num perfil de qualidade, o "Upgrade Until": a qualidade em que o ABM para de procurar algo melhor.

**Delay profile** (perfil de atraso): uma espera antes de baixar, por protocolo.

**Discover**: catálogos da Audible para navegar.

**Hardlink**: um segundo nome para o mesmo arquivo no mesmo sistema de arquivos. Não ocupa espaço extra.

**Import Workbench**: o nome da página por trás do Library Import. Varrer, associar, adicionar.

**Indexer** (indexador): um site em que o ABM procura releases.

**Ladder** (escala): a lista ordenada de formatos num perfil de qualidade.

**Libex**: o serviço de metadados a que o ABM pede os dados dos livros.

**Monitored / Unmonitored**: se o ABM age ou não sobre um livro.

**M4B**: um formato de audiolivro em arquivo único, com capítulos.

**Quality profile / release profile** (perfil de qualidade / perfil de release): veja [Perfis](/pt-br/settings/profiles/).

**Remote path mapping** (mapeamento de caminho remoto): traduz o caminho que o seu cliente de download enxerga para o caminho que o ABM enxerga.

**Root folder** (pasta raiz): um diretório em que o ABM guarda livros.

**Sidecar**: um arquivo pequeno ao lado do áudio: capa, OPF, descrição, narrador, cue.

**Step-up password**: pedir a sua senha de novo antes de uma alteração sensível.

**Wanted**: um livro monitorado que não tem arquivos.

## Se você conhece o Sonarr

Episódio é livro. Série é tanto a série do Sonarr quanto um catálogo de livros. Qualidade é formato mais arquivo único ou vários arquivos. Os custom formats viram perfis de release. Activity, Wanted, Calendar e System funcionam do mesmo jeito.
