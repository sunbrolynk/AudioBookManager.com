---
title: Gränssnitt
description: Kalender, datumformat, tema och färgalternativ.
---

**Settings > UI** handlar bara om visning.

| Inställning | Val |
|---|---|
| First Day of Week | Sunday eller Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` eller `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Fyra layouter, med eller utan veckodag |
| Time Format | 12-timmars eller 24-timmars |
| Show Relative Dates | Today och Yesterday i stället för datum |
| Theme | Auto (följer ditt operativsystem), Light eller Dark |
| Enable Color-Impaired Mode | Ändrar färgkodningen så att statusar blir lättare att skilja åt |

Standardvärdena finns i appen. De här inställningarna delas av alla som använder instansen.
