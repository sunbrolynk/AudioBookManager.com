**Calendar**는 ABM이 알고 있는 책의 출간일을 상태별 색으로 보여 줘요. 보기 방식은 월, 주, 예보(forecast), 일, 일정 목록(agenda)이 있어요. 주 시작 요일과 날짜 형식은 [UI 설정](/ko/settings/ui/)을 따라요.

## 옵션

**Calendar Options** 버튼에서 이런 걸 고를 수 있어요: 같은 날 나오는 여러 책을 하나로 접기, 이벤트 전체를 상태 색으로 칠하기, 작가와 시리즈 정보 보여 주기.

## iCal 피드

캘린더 앱에서 피드 URL로 구독하세요(URL을 복사하거나 **Subscribe in Calendar App**을 쓰면 돼요). 옵션은 이래요:

- **Include Unmonitored**: 모니터링하지 않는 책도 피드에 넣어요.
- **Show as All-Day Events**: 이벤트를 종일 일정으로 만들어요.
- 태그: 태그를 고르면 그중 하나 이상이 붙은 책만 피드에 들어가요.

피드는 ABM에서 제공되기 때문에, 내 네트워크 바깥에 있는 캘린더 앱이 쓰려면 ABM에 접근하고 인증할 방법이 있어야 해요. [보안과 로그인](/ko/settings/security/)을 보세요.
