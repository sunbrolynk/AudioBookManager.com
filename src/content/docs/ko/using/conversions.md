**Library > Conversions**는 라이브러리에 ffmpeg 작업을 돌려요. 종류는 네 가지예요:

| 작업 | 하는 일 |
|---|---|
| Convert Format | M4B, MP3, M4A, FLAC, Opus로 다시 인코딩해요 |
| Merge Parts | 여러 파일을 챕터가 있는 파일 하나로 합쳐요 |
| Split Chapters | 파일 하나를 챕터별 파일로 나눠요 |
| Ensure Chapters | 다시 인코딩하지 않고 챕터 마커를 추가하거나 고쳐요 |

모든 작업의 기본값은 [변환 설정](/ko/settings/conversions/)에서 와요. 작업마다 따로 바꿀 수 있어요.

## 큐

작업은 큐에서 기다리다가 한 번에 최대 **Concurrent Conversions**개씩 돌아가요(기본값 2). 끝난 작업은 History로 옮겨지고, 비울 수 있어요.

결과물은 개인 작업 폴더에 쓰고, 끝난 뒤에만 라이브러리에 놓아요. 파일마다 임시 이름으로 들어갔다가 제자리 이름으로 바뀌기 때문에, 반쯤 쓰인 책이 보이는 일은 없어요. 작업을 시작하기 전과 결과를 놓기 전에 남은 공간을 확인해요. 원본 파일은 절대 덮어쓰지 않아요.

파일을 이미 그 형식인 형식으로 변환하는 건 거부해요. 원본을 덮어쓰게 되니까요.

## 변환이 끝나면

ABM이 책의 파일 기록, 크기, 품질을 새로 고쳐서, 변환한 책에 새 품질이 보여요. **Delete Original**이 켜져 있으면, 변환용 휴지통이 켜져 있을 때 기존 파일을 그리로 보내요.

결과를 놓는 데 실패하면(예를 들어 라이브러리 폴더가 꽉 찼다면) 작업이 실패하고, 완성된 결과물은 작업 폴더에 남겨 둬요. 오류에 그 폴더 이름이 나와요. **Retry**는 작업을 처음부터 다시 시작하면서 남겨 둔 결과물을 버리기 때문에 먼저 물어봐요. **Clear history**는 아직 놓지 못한 결과물을 가진 작업은 남겨 둬요.

## 일시 정지와 재개

일시 정지는 두 종류가 있고, 둘 다 아무것도 취소하지 않아요:

- 실행 중인 작업 하나에서 **Pause**를 누르면 그 작업의 ffmpeg 프로세스가 그 자리에서 멈춰요. Resume을 누르면 같은 지점부터 이어서 해요.
- **Pause queue**(큐 맨 위, 휴대폰에서는 상단 바)는 새 작업이 시작되지 않게 하고, 실행 중인 작업을 모두 멈춰요.

내가 직접 멈춘 작업은 큐를 재개해도, 재시작해도 멈춘 상태로 남아요. ABM이 멈출 때 실행 중이던 작업은 일시 정지 상태로 돌아오고, 알아서 시작하지 않아요. 합치기, 나누기, 여러 파일 변환은 Resume하면 마지막으로 끝난 부분부터 이어서 해요. 단일 파일 변환은 그 파일을 처음부터 다시 해요.

6시간 실행 한도는 멈추지 않은 시간만 세요. 시작할 때 저장된 큐 상태를 읽을 수 없으면, 큐는 일시 정지 상태로 시작하고 그렇다고 알려 줘요. Resume queue를 누르면 다시 써요.

Sonarr를 써 봤다면: arr 앱에는 이런 게 없어요. 관리 앱 안에 들어 있는 작은 인코더 큐라고 생각하세요.

## 주의할 점

- Concurrent Conversions × Threads Per Job이 CPU 코어 수를 넘지 않게 하세요. Auto로 두면 남는 코어를 ABM이 동시에 실행되는 작업끼리 알아서 나눠 줘요.
- 변환한 파일은 크기와 수정 시간이 바뀌어서 Audiobookshelf가 다시 스캔해요.
- 시딩 중인 토렌트에 하드링크된 파일을 변환하면 새 파일이 생겨요. 시딩 중인 사본은 예전 데이터를 그대로 가져요.
