---
title: 새로 추가 (Add New)
description: 책을 검색해서 Wanted로 추가해요.
---

**Library > Add New**는 Libex에서 책을 검색하고 내가 고른 책을 추가해요. 제목, 작가, 시리즈, ASIN으로 검색할 수 있어요.

## 추가하면 일어나는 일

추가한 책은 내가 고른 루트 폴더와 품질 프로필로 **Wanted**가 되고, ABM이 모니터 설정에 따라 검색을 시작해요. 이미 라이브러리에 있는 책인지는 ASIN으로만 판단해요. 같은 제목이라도 판본이 다르면 ASIN이 달라요.

## 작가와 시리즈 검색

:::caution[다음 릴리스에서 추가돼요]
Author와 Series 검색 모드는 아직 정식 버전에 없어요.
:::

검색에 작가와 시리즈 자체를 찾는 모드 두 개가 생겨요. 기존 책 검색 모드는 "Books by author"와 "Books in series"로 이름이 바뀌어요. 작가나 시리즈를 추가하면 카탈로그를 만들고, **Monitor** 값에 따라 책을 Wanted로 추가해요:

| Monitor | 추가하는 것 |
|---|---|
| All | 아직 안 나온 책까지 모든 책 |
| Future | 지금부터 나오는 책만 |
| Missing(기본값) | 내가 갖고 있지 않은 책 |
| None | 카탈로그만 |

루트 폴더, 품질 프로필, 그리고 나중에 나오는 책도 추가할지 함께 골라요. 시리즈는 기본값이 켜짐이고 작가는 꺼짐이에요. 이미 라이브러리에 있는 작가나 시리즈에는 "In Library"가 표시되고 **Add missing books** 작업이 나와요.

추가는 백그라운드 작업으로 돌고, 진행 상황은 토스트 알림으로 보여 줘요.

## 검색 결과가 없을 때

메타데이터 소스에서 응답을 못 받은 검색은 빈 목록 대신 오류로 실패해요. [문제 해결](/ko/troubleshooting/#메타데이터-소스를-사용할-수-없어요)을 보세요.
