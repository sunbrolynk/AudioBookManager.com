title: 라이브러리 가져오기
description: Import Workbench로 기존 컬렉션을 ABM에 들여와요.
---

Library Import는 오디오북 폴더를 스캔하고, 폴더마다 메타데이터를 매칭한 다음, 책을 라이브러리에 추가해요. **Library > Library Import**를 누르면 "Import audiobooks you already have" 페이지가 열리고, 여기서 스캔할 폴더를 골라요. 스캔이 시작되면 ABM이 **Match Audiobooks**라는 제목의 매칭 페이지로 넘어가고, 거기서 매칭을 확인하고 책을 추가해요.

## 흐름

1. 폴더를 스캔해요. 오디오가 있는 폴더 하나가 한 줄이 돼요.
2. 매칭을 확인해요. 고칠 게 있으면 고쳐요.
3. 원하는 줄에 체크하고, 라이브러리에 추가하거나 삭제해요.

모든 옵션은 Media Management 기본값을 선택적으로 덮어쓰는 거예요.

## 매칭이 확정되는 경우

스캔은 파일이 확인해 줄 때만 매칭을 확정해요.

- 파일 자체 태그에 있는 ASIN으로 책을 찾거나,
- 책의 재생 시간이 파일과 3분 이내로 차이 나고, 시리즈 순번이나 제목이 파일과 맞을 때요.

파일과 어긋나는 저자나 시리즈 순번이 있으면 그 책은 제외돼요. 파일이 서로 다른 두 책이나 두 녹음에 똑같이 잘 맞으면 어느 쪽도 확정되지 않아요.

파일의 재생 시간은 책의 모든 파일을 읽을 수 있을 때만 셉니다. 하나라도 잴 수 없으면 그 행에는 재생 시간이 없어요. 그러면 ASIN만 일치를 확인할 수 있고, 그렇지 않으면 책은 **Needs a look**에서 기다립니다.

책을 두 형식으로 갖고 있으면 형식마다 따로 행이 되고 따로 재요. 서로 다른 형식의 파트로 나뉜 책은 자기 폴더가 있으면 한 행이 되고, 파트를 더해요.

재생 시간으로 받아들이는 건 영어판이나 목록에 언어가 없는 판뿐이에요. 다른 언어의 판은 파일 자체의 ASIN으로 찾았을 때만 받아들입니다. 실시간 조회 대신 [로컬 저장소](/ko/settings/metadata/)에서 답한 책은 직접 확인하기 전에는 절대 받아들이지 않아요.

행의 조회 중 하나가 실패하면 ASIN 일치만 받아들입니다. 저자 검색으로만 찾은 책은 재생 시간이 파일과 맞을 때만 제안돼요. 그래서 목록이 없는 책은 저자의 다른 책을 제안하는 대신 **Unmatched**로 표시됩니다.

그 밖의 매칭도 제안으로는 나오지만, 그 행은 **Needs a look**에 들어가고, 처음에 체크가 해제돼 있고, **Select All**도 그 행을 건너뛰어요. 매칭을 확인하거나 다른 매칭을 고를 때까지 그대로예요. 이미 라이브러리에 있는 책으로 매칭이 확정되면 **In library**에 들어가요. 제안이 라이브러리 책인 **Needs a look** 행은 그 일치를 확인해야 라이브러리 질문을 합니다. 그 전에는 체크하면 아직 결정이 필요한 행으로 Add를 막아요.

다른 책과 같은 폴더(저자 폴더나 스캔한 폴더 등)에 여러 개의 낱개 파일로 들어 있는 책은 모든 파트를 담은 한 행이 돼요. 책 번호나 권 번호가 다른 파일은 따로따로 행으로 남아요. 파트는 형식별로 묶여요. 옆에 있는 책 전체 파일은 따로 한 행이고, 파일 이름의 비트레이트(`128kbps` 등)는 파트 번호가 아닙니다.

한 책의 두 형식(`Book.mp3`와 `Book.m4b` 등)은 파일이 스캔한 폴더에 그냥 놓여 있든 책 전용 폴더에 들어 있든 따로따로 행이 돼요. 각 행은 자기 파일만 가져오고, 지우고, 재요. 이름이 같은 표지, cue 등 오디오가 아닌 파일은 책이 그곳에 한 형식으로만 있으면 책 파일과 함께 가고, 두 형식으로 있으면 그 자리에 남아요. 한 사본은 라이브러리로 옮기고 다른 사본은 같은 가져오기에서 지울 때도 마찬가지예요.

`Title: Series, Book 2` 형식의 태그는 제목, 시리즈, 순번으로 나눠서 읽어요.

`1-3`처럼 범위로 쓴 시리즈 위치는 그 안의 어떤 위치와도 일치해요. `1, 3`처럼 다른 방식으로 쓴 두 숫자는 위치가 없는 것으로 봅니다.

500자가 넘는 제목, 앨범, 시리즈, 시리즈 번호, 아티스트, 앨범 아티스트, 작곡가, 내레이터 태그는 무시돼요.

Library Import 페이지의 **Recent Import Sessions**는 스캔마다 매칭된 행 수(이미 라이브러리에 있는 책 포함)와 대기 중인 행 수(아직 매칭을 골라야 하는 행 포함)를 보여 줘요.

## 목록 읽는 법

- 요약에 찾은 폴더 수와 준비된 수가 나와요. 위쪽 바에 **Sort** (Folder name, Status, Title, Author, Series, Files)와 **Filter** (Ready, Needs a look, No audio, Unmatched, In library, Lookup failed, Needs a decision, Looking up, Deleted on add)가 있어요. 필터마다 개수가 표시되고, 그 개수는 요약과 맞아요. 직접 확인한 매칭은 Ready라고 불러요. 정렬과 필터는 이 기기에 기억돼요. 페이지 주소에는 남지 않아서, `?sort=`나 `?filter=`가 들어간 링크로는 넘어가지 않아요.
- 줄마다 표지, 제목, 작가와 시리즈, 그리고 매칭을 얼마나 확신하는지 "95% match"처럼 퍼센트로 보여 줘요. 각 줄은 제목, 작가, 시리즈 검색으로 찾은 매칭을 모두 간직해요. 폴더 상세 정보의 **Find a match**나 **Change match**로 직접 검색할 수 있어요. 검색은 입력한 내용에 대한 Libex의 베스트 매치를 먼저 보여 주고, 그다음 제목, 작가, 시리즈 검색으로 찾은 책을 한 권당 한 번씩, 50개씩 보여 줘요. 스크롤하거나 **Load more**를 누르면 더 없을 때까지 더 불러와요.
- 판본을 확인할 ASIN이나 재생 시간이 파일에 없으면 폴더 상세 정보에 그렇다고 나와요.
- **Rescan**은 스캔 뒤에 추가된 폴더를 찾아오고, 내가 고른 건 그대로 둬요.

주석이나 설명에서 찾은 ASIN은 단서일 뿐이에요. 제목도 폴더 이름과 맞을 때만 매칭으로 쳐요. 전용 ASIN 태그만 그것 하나로 매칭이 돼요.

## 합치기, 나누기, 추가하기

- 한 권이 여러 폴더로 나뉜 거라면 줄을 합치세요. 폴더 상세 정보에서 다시 나눌 수 있어요. 합친 행의 일치는 제안일 뿐이에요. 확인하거나 다른 것을 고를 때까지 **Needs a look**에 들어가고 체크가 해제된 채로 시작합니다. 재생 시간은 모든 파트에 재생 시간이 있을 때만 합계가 되고, ASIN은 모든 파트가 같은 것을 줄 때만 남아요. 합치기는 한 책의 파트에만 써요. 한 책의 두 형식은 따로 행으로 두세요. 합치면 두 재생 시간이 더해져요. 행을 합치거나 나눈 뒤에 끝난 조회도 제안일 뿐입니다.
- 행 세부 정보의 **Confirm match**는 **Needs a look** 행을 체크하고, **Undo confirmation**은 그 체크도 함께 되돌려요.
- Add를 누를 수 없을 땐 버튼 위에 "Select at least one folder"나 "2 selected rows still need a decision" 같은 이유가 나와요. 두 행이 같은 폴더나 파일을 가리키면 Add도 아무것도 건드리지 않고 거부돼요.
- 파일을 지우거나 바꾸는 작업은 먼저 물어봐요.
- 페이지를 나가면 아직 반영하지 않은 수정 내용이 저장돼요.

## 복사, 이동, 하드링크

**Settings > Media Management > Importing**에서 Library Import의 기본값을 정해요: 복사(기본값), 이동, 하드링크. 가져올 때마다 다른 걸 고를 수도 있어요.

하드링크로 가져온 책은 디스크 공간을 더 쓰지 않고, 원본은 제자리에 그대로 있어요. 하드링크를 쓰려면 기본 루트 폴더가 하드링크를 지원해야 하고, 먼저 확인을 거쳐야 해요. 그렇지 않으면 옵션이 회색으로 비활성화되고 이유가 나와요. 다른 드라이브에 있는 파일처럼 링크할 수 없는 파일은 복사하고, 절대 이동하지 않아요. 가져오기가 끝나면 몇 개를 복사했는지 알려 줘요.

## 추가 파일

**Import Extra Files**(기본값 켜짐)는 책의 표지, 노트, 그 밖의 오디오가 아닌 파일도 함께 가져와요. Library Import, Manual Import, 완료된 다운로드에 똑같이 적용돼요. **Show Advanced**를 켜면 **Preferred Cover**로 매칭된 Audible 표지(기본값)와 폴더 자체 표지 중에서 고를 수 있어요.

## 긴 값

말줄임표로 잘린 내레이터, 제목, 경로는 탭하거나 클릭하면 전체가 보여요. 다시 탭하거나 클릭하면 닫혀요. 마우스로는 위에 올려 두기만 해도 전체 값이 보여요. 키보드로는 포커스를 옮기고 Enter나 Space를 누르세요.

## 가져오기 말고 다른 답

줄에 **keep library**(라이브러리에 이미 있는 책의 사본을 거절해요)나 **remove empty**(오디오는 없고 아트워크와 사이드카만 남은 폴더를 거절해요)로 답할 수도 있어요. 이건 그 줄이 가진 것만 정리해요. **remove empty**는 오디오가 들어 있는 건 거부해요. 휴지통이 설정돼 있으면 파일은 휴지통으로 가고, 작업 로그에 지운 경로가 하나하나 나와요. **keep library** 결정은 그 결정이 가리킨 라이브러리 책에만 적용돼요. 다른 것을 묻거나 다른 라이브러리 책에 대해 묻는 일치를 고르면 행이 다시 묻습니다. 가져오기는 실행될 때 다시 확인하고, 그때 라이브러리 사본에 파일이 없거나 ("Your library has no copy of this book to keep") 폴더에 라이브러리 책의 파일이 들어 있으면 ("This folder holds files of a book in your library") 아무것도 지우지 않아요. 가져오는 대신 파일을 지우는 행은 같은 Add의 가져오기가 모두 끝난 뒤에야 실행되고, 그때 파일 중 하나라도 라이브러리 책의 것이면 거부돼요. 그래서 같은 묶음에서 방금 책을 추가한 파일을 지우는 일은 없어요.

## 폴더별 표지와 추가 파일

검사 패널에는 폴더 자체 표지와 매칭된 판본의 표지가 픽셀 크기와 함께 나란히 나와요. 클릭 한 번으로 다른 쪽을 고를 수 있어요. 그 아래 **Extra files**에는 나머지 파일이 모두, 따르는 Media Management 스위치 이름 아래에 나와요. 설정과 다르게 고른 항목엔 점이 찍히고, **Apply this cover and these file choices to the N other selected**로 한 폴더의 선택을 선택한 나머지 폴더에 복사할 수 있어요. 이미 라이브러리에 있는 책에 파일을 추가하는 줄에는 선택기가 없어요.

[라이브러리 옮겨 오기](/ko/guides/moving-a-library-in/)와 [미디어 관리](/ko/settings/media-management/)도 함께 보세요.
