Library Import는 오디오북 폴더를 스캔하고, 폴더마다 메타데이터를 매칭한 다음, 책을 라이브러리에 추가해요. 페이지 이름은 **Match Audiobooks**예요.

## 흐름

1. 폴더를 스캔해요. 오디오가 있는 폴더 하나가 한 줄이 돼요.
2. 매칭을 확인해요. 고칠 게 있으면 고쳐요.
3. 줄을 선택하고 라이브러리에 추가해요.

모든 옵션은 Media Management 기본값을 선택적으로 덮어쓰는 거예요. 그냥 스캔하고 추가하는 데는 클릭 두 번이면 충분해요.

## 목록 읽는 법

- 요약에 찾은 폴더 수와 매칭된 수가 나와요. All, Matched, Needs attention, Unmatched, In library, Failed lookup으로 목록을 거를 수 있어요. 필터는 페이지 주소에 남아요.
- 줄마다 표지, 제목, 작가와 시리즈, 그리고 매칭을 얼마나 확신하는지 "95% match"처럼 퍼센트로 보여 줘요. 폴더 상세 정보의 **Find a match**나 **Change match**로 직접 검색할 수 있어요.
- 판본을 확인할 ASIN이나 재생 시간이 파일에 없으면 폴더 상세 정보에 그렇다고 나와요.
- **Rescan**은 스캔 뒤에 추가된 폴더를 찾아오고, 내가 고른 건 그대로 둬요.

주석이나 설명에서 찾은 ASIN은 단서일 뿐이에요. 제목도 폴더 이름과 맞을 때만 매칭으로 쳐요. 전용 ASIN 태그만 그것 하나로 매칭이 돼요.

## 합치기, 나누기, 추가하기

- 한 권이 여러 폴더로 나뉜 거라면 줄을 합치세요. 폴더 상세 정보에서 다시 나눌 수 있어요.
- Add를 누를 수 없을 땐 버튼 위에 "Select at least one folder"나 "2 selected rows still need a decision" 같은 이유가 나와요.
- 파일을 지우거나 바꾸는 작업은 먼저 물어봐요.
- 페이지를 나가면 아직 반영하지 않은 수정 내용이 저장돼요.

## 복사, 이동, 하드링크

**Settings > Media Management > Importing**에서 Library Import의 기본값을 정해요: 복사(기본값), 이동, 하드링크. 가져올 때마다 다른 걸 고를 수도 있어요.

하드링크로 가져온 책은 디스크 공간을 더 쓰지 않고, 원본은 제자리에 그대로 있어요. 하드링크를 쓰려면 기본 루트 폴더가 하드링크를 지원해야 하고, 먼저 확인을 거쳐야 해요. 그렇지 않으면 옵션이 회색으로 비활성화되고 이유가 나와요. 다른 드라이브에 있는 파일처럼 링크할 수 없는 파일은 복사하고, 절대 이동하지 않아요. 가져오기가 끝나면 몇 개를 복사했는지 알려 줘요.

## 추가 파일

**Import Extra Files**(기본값 켜짐)는 책의 표지, 노트, 그 밖의 오디오가 아닌 파일도 함께 가져와요. Library Import, Manual Import, 완료된 다운로드에 똑같이 적용돼요. **Show Advanced**를 켜면 **Preferred Cover**로 매칭된 Audible 표지(기본값)와 폴더 자체 표지 중에서 고를 수 있어요.

## 긴 값

말줄임표로 잘린 내레이터, 제목, 경로는 탭하거나 Enter나 Space를 누르면 전체가 보여요. 다시 탭하면 닫혀요.

## 가져오기 말고 다른 답

줄에 **keep library**(라이브러리에 이미 있는 책의 사본을 거절해요)나 **remove empty**(오디오는 없고 아트워크와 사이드카만 남은 폴더를 거절해요)로 답할 수도 있어요. 이건 그 줄이 가진 것만 정리해요. 오디오가 들어 있는 건 거부해요. 휴지통이 설정돼 있으면 파일은 휴지통으로 가고, 작업 로그에 지운 경로가 하나하나 나와요.

## 폴더별 표지와 추가 파일

검사 패널에는 폴더 자체 표지와 매칭된 판본의 표지가 픽셀 크기와 함께 나란히 나와요. 클릭 한 번으로 다른 쪽을 고를 수 있어요. 그 아래 **Extra files**에는 나머지 파일이 모두, 따르는 Media Management 스위치 이름 아래에 나와요. 설정과 다르게 고른 항목엔 점이 찍히고, **Apply this cover and these file choices to the N other selected**로 한 폴더의 선택을 선택한 나머지 폴더에 복사할 수 있어요. 이미 라이브러리에 있는 책에 파일을 추가하는 줄에는 선택기가 없어요.

[라이브러리 옮겨 오기](/ko/guides/moving-a-library-in/)와 [미디어 관리](/ko/settings/media-management/)도 함께 보세요.
