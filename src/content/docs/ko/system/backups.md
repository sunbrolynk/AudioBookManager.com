**System > Backups**에서 백업을 만들고 복원해요. **Backup Now**를 누르면 하나 만들어요. 일정, 보관 기간, 내보내기 대상은 [일반](/ko/settings/general/)에 있어요.

## 백업에 들어 있는 것

데이터베이스의 일관된 사본(`database.db`), 설정(`settings.json`), 매니페스트가 담긴 암호화된 압축 파일이에요. 표지와 앱 비밀 파일 때문에 내 백업에도 `/config`를 꼭 넣으세요.

## 복원하기

목록에서 하나를 고르거나 백업 파일을 올리세요(최대 500 MiB). 먼저 현재 데이터베이스의 사본을 저장해 둬요. 복원은 되돌릴 수 없어요.

기본적으로 복원은 **보안 설정**(인증 방식, 자격 증명, 신뢰하는 네트워크)과 **외부 연결**을 되살리지 않아요. 지금 쓰는 설정을 그대로 두고, 결과에 그렇게 했다고 알려 줘요. 이것들도 복원하려면 업로드할 때 선택 항목에 체크하세요. 그래서 올린 압축 파일이 복원만으로 로그인을 꺼 버리는 일은 절대 없어요.

예전 버전에서 만든 백업이라면, 복원한 뒤 컨테이너를 재시작해서 마이그레이션이 돌게 하세요.

예상하지 못한 항목이 들어 있거나, 올바른 SQLite 데이터베이스가 아니거나, SQLite로 옮기기 전의 레거시 백업이면 아무것도 바꾸지 않고 거부해요.

## 내보내기 대상

SFTP, SCP, FTPS, FTP, S3, 또는 rclone 리모트예요. **Auto**로 표시한 대상은 백업마다 자동으로 받아요. rclone 리모트 이름에는 영문자, 숫자, `_`, `.`, `-`를 쓸 수 있어요.

## 주의할 점

- Docker 이미지와 compose 파일은 백업에 들어가지 않아요. compose 파일은 따로 챙겨 두세요.
- `APP_SECRET`을 설정했다면 따로 백업하세요. 이게 없으면 다른 호스트에서 복원한 뒤 저장된 자격 증명을 복호화할 수 없어요.
