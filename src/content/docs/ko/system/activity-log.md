ABM은 세 종류의 기록을 남겨요.

| 위치 | 무엇인지 |
|---|---|
| **System > Events**와 **System > Activity Log** | 활동 로그예요. 일어난 일을 데이터베이스에 목록으로 남겨요. Events는 심각도로 거른 보기예요. Activity Log(제목은 Activity History)는 카테고리로 거르고 메시지를 검색할 수 있고, 변경 전후 상태를 보여 줘요 |
| **System > Log Files** | 모든 세부 내용이 담긴 텍스트 로그 파일이에요. [로그](/ko/system/logs/)를 보세요 |
| **Activity > History** | 다운로드 기록만 있어요. [활동](/ko/using/activity/)을 보세요 |

## 기록되는 것

끝난 백그라운드 작업(작업마다 요약 한 줄), 클라이언트, 인덱서, 프로필, 태그, 알림, 루트 폴더 등에 대한 수동 변경, grab(누가 시작했는지), 변환, Audible 다운로드 실패, 백업, 로그인과 로그인 실패, 실패한 시작 단계.

카테고리: Books, Authors, Series, Downloads, Imports, Conversions, Files, Audible, Security, System.

## 개인 정보

항목에는 URL, 호스트, 사용자 이름, 비밀번호, 키, 토큰, 그리고 클라이언트나 서비스가 보낸 원본 오류 문구가 절대 들어가지 않아요. 대상은 내가 붙인 이름으로 불러요. 설정을 저장하면 어떤 설정이 바뀌었는지만 남기고 값은 남기지 않아요. 로그인은 IP 주소만 저장해요. 한 주소에서 15분 안에 실패한 로그인은 시도 횟수와 함께 한 줄로 합쳐요.

## 일부러 조용하게

아무 일도 하지 않은 예약 실행은 아무것도 남기지 않아요. 같은 실패가 반복되면 남기지 않지만, 복구되면 남겨요. 수동 실행은 항상 기록해요.

## 보관 기간

General의 **Activity Log Retention**은 기본값으로 90일이 지난 항목을 지워요. 0이면 계속 보관해요. 로그 파일은 보관 기간이 따로 있어서(30일), 항목에서 로그로 가는 링크가 로그보다 오래 남을 수 있어요.

## 로그 보기

:::caution[다음 릴리스에서 추가돼요]
항목에서 로그로 가는 링크는 아직 정식 버전에 없어요.
:::

항목은 자기가 나온 로그로 링크되고, 그 줄에서 로그를 열어 줘요. 로그가 없어졌으면 항목에 "Log no longer kept"라고 나와요.
