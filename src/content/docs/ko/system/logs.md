title: 로그

---

**System > Log Files**에 ABM의 텍스트 로그가 모여 있어요. 하나를 열어서 읽거나, 내려받거나, 지우거나, 전부 비울 수 있어요. 로그는 작업이 돌아가면서 생겨요.

- 작업(task)과 변환은 각자 로그를 따로 남겨요. Tasks 페이지에서 각 로그로 바로 갈 수 있어요.
- 메인 로그는 `app.log`예요. 시작할 때, 최소 한 시간마다, 그리고 10 MiB가 되면 새 파일로 넘어가요. 이전 파일은 **Log File Retention** 기간(기본 30일) 동안 보관해요.
- 별도의 보안 로그에는 로그인 시도마다 한 줄씩 남아서 fail2ban 같은 도구에 쓸 수 있어요.
- 레벨은 **Settings > General > Logging**에서 정해요.

## 문제 읽어 내기

실패한 작업의 로그 버튼부터 눌러 보세요. 작업의 시작 줄부터 끝 블록까지 보여 줘요. 비밀값은 가려지지만, 로그를 공개된 곳에 붙여 넣기 전에 한 번 확인하세요.

## 주의할 점

- SQL Logging과 Debug 레벨은 내용이 많아요. 다 봤으면 꺼 두세요.
- 로그를 지워도 그 로그를 가리키는 활동 항목은 남아요. 그런 항목엔 "Log no longer kept"라고 나와요.
