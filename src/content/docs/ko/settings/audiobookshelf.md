title: Audiobookshelf 연결
description: ABM을 Audiobookshelf 서버에 연결하세요.
---

Audiobookshelf(ABS)는 네가 듣는 서버야. **Settings > Audiobookshelf**에서 ABM을 연결해. 컴퓨터와 폰 모두에서 쓸 수 있어. 서버 주소와 ABS 사용자 한 명 앞으로 만든 API 키를 입력하면 돼.

## 연결

- **Enable:** ABM이 서버를 쓰게 해. 이 옵션을 켠 채로 저장하면 ABM이 먼저 서버를 확인하고, 오류 수준 검사가 실패하면 저장을 거부해. 이유는 페이지에 표시돼. 꺼진 채로 저장한 연결은 확인하지 않아.
- **Server address:** ABS 서버가 응답하는 주소야. 예: `http://192.168.1.20:13378`. ABS가 ABM과 같은 머신에서 돌면 그 머신의 LAN 주소를 써. 둘 다 Docker에서 돌면 컨테이너 이름이나 IP를 써.
- **API key:** ABS의 admin 사용자가 만든 API 키.
- **Verify TLS certificate:** 기본값은 켜짐이야. 서버가 직접 만든 인증 기관의 인증서를 쓴다면, 검증을 끄지 말고 **CA bundle path**에 그 CA 번들 경로를 넣어. 비워 두면 시스템 인증서를 써.
- **Test:** 화면에 입력된 내용으로 검사를 실행해. 아무것도 저장하지 않아.
- **Disconnect:** 확인을 물은 뒤 저장된 주소와 키를 삭제해.

## ABM이 ABS에 닿는 방법

ABM은 항상 ABS에 직접 연결해. [Network](/settings/network/)에서 고른 VPN이나 프록시는 거치지 않아. 주소는 저장하기 전에 확인하고, 안전하지 않은 주소는 거부해. ABM이 도는 머신 자신을 가리키는 주소, 링크 로컬 주소, 클라우드 메타데이터 주소는 거부하고, 이 중 하나로 풀리는 이름도 마찬가지야. 네 LAN 주소는 괜찮아. 그래서 같은 머신의 ABS에는 그 머신의 LAN 주소나 컨테이너 이름 또는 IP가 필요해.

## API 키

키는 암호화해서 저장하고 다시는 보여 주지 않아. 저장하거나 Test할 때 비워 두면 저장된 키를 그대로 써. 저장된 키는 저장할 때의 주소로만 보내지니까, 주소, Verify TLS, CA 번들 중 하나를 바꾸면 키를 다시 입력해. ABM이 저장된 키를 더 이상 읽지 못하면(암호화 키를 잃어버렸거나 바뀐 경우) 연결이 꺼져 있어도 페이지가 다시 입력하라고 알려 줘.

## 무엇을 검사하나

**버전.** ABM에는 ABS 2.37.0 이상이 필요하고 2.37.2에서 테스트했어. 더 오래된 서버나 ABM이 이해하는 버전을 알려 주지 않는 서버는 오류가 나. 더 새로운 서버는 ABM에서 테스트하지 않았으니 경고가 나.

**계정.** API 키는 ABS 사용자의 것이고, ABM은 그 사용자를 확인해.

- **고칠 때까지 오류:** 사용자는 admin이나 root여야 하고, Update 권한과 모든 라이브러리, 모든 태그, 성인 콘텐츠에 대한 접근이 있어야 해.
- **경고, 그래도 저장:** Upload가 꺼져 있음(ABM이 표지를 관리할 수 없음), 또는 Delete가 꺼져 있음(ABM에서 지운 책이 켤 때까지 ABS에 남음).

## 상태

Status 섹션에는 마지막 검사의 결과(Not connected, OK, Warning, Error), 서버 버전, 키의 주인인 사용자, ABM이 마지막으로 확인한 시각, 그리고 검사 항목이 표시돼. 실패한 검사는 이유가 나오고, 통과한 검사는 개수로 세어 줘.

연결이 켜져 있으면 [System > Status](/system/status/)에도 Audiobookshelf 행이 있어. 저장할 때와 6시간마다 도는 정기 상태 점검 때 갱신되니까, 페이지를 열 때마다 실시간으로 확인하는 건 아니야. ABM이 읽지 못하는 저장된 키는 다시 입력할 때까지 오류로 나와. 아직 확인하지 않은 연결은 경고로 나와. 꺼진 연결은 여기서 아무것도 표시하지 않아.

## ABM이 지우는 것

ABM이 ABS에서 지우는 건 항목 레코드뿐이야. 파일을 영구 삭제하지는 않아.
