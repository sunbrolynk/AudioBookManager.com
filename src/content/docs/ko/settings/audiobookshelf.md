이 설정 페이지는 아직 어떤 공개 버전에도 들어 있지 않아요. 연결은 이미 API로 저장하고, 테스트하고, 제거할 수 있지만 ABM의 다른 곳은 아직 이 연결을 쓰지 않아요.
:::

Audiobookshelf(ABS)는 네가 듣는 서버예요. ABM은 서버 URL과 ABS 사용자 한 명용으로 만든 API 키로 연결해요.

## 버전

ABM은 ABS 2.37.0 이상이 필요하고 2.37.2에서 테스트했어요. 더 오래된 서버는 거부돼요. 더 새로운 서버는 ABM이 테스트해 보지 않았으니 경고가 나와요.

## 계정

API 키는 ABS 사용자 한 명의 것이에요. 저장하거나 테스트할 때 ABM이 그 사용자를 확인해요.

- **고칠 때까지 거부돼요:** 사용자가 admin 또는 root여야 하고, Update 권한과 모든 라이브러리, 모든 태그, 성인 콘텐츠에 대한 접근 권한이 있어야 해요.
- **경고는 뜨지만 저장은 돼요:** Upload가 꺼져 있거나(ABM이 표지를 관리할 수 없어요) Delete가 꺼져 있을 때(ABM에서 지운 책이 켤 때까지 ABS에 남아요)예요.

## ABM이 ABS에 닿는 방법

ABM은 항상 ABS에 직접 연결해요. [Network](/settings/network/)에서 고른 VPN이나 프록시를 거치지 않아요. 서버 URL은 저장하기 전에 확인하고, 안전하지 않은 URL은 거부해요.

## API 키

키는 암호화해서 저장하고 다시는 보여 주지 않아요. 저장하거나 테스트할 때 비워 두면 저장된 키를 그대로 써요. 저장된 키는 저장할 때의 주소로만 보내지니까, URL이나 TLS 설정, CA 번들을 바꾸면 키를 다시 입력하세요.

## TLS 검증

인증서는 기본으로 검증해요. 서버가 직접 운영하는 인증 기관의 인증서를 쓴다면, 검증을 끄지 말고 그 CA 번들 경로를 지정하세요.

## Test와 Disconnect

**Test**는 저장하지 않고 서버를 확인해요. 버전, 사용자 권한, 라이브러리를 봐요. 켜진 연결을 저장하면 먼저 같은 확인을 하고, 오류 항목이 하나라도 실패하면 거부돼요. 꺼진 채로 저장한 연결은 확인하지 않아요. **Disconnect**는 저장된 연결과 키를 지워요.

## System Status

연결이 켜져 있으면 [System > Status](/system/status/)에 AudioBookShelf 줄이 생기고 마지막 확인 결과를 보여 줘요. 저장할 때와 6시간마다 도는 정기 상태 점검 때 갱신되니까, 페이지를 열 때마다 실시간으로 확인하는 건 아니에요.

## ABM이 지우는 것

ABM은 ABS에서 항목 기록만 지워요. 파일을 완전히 삭제하는 일은 절대 없어요.
