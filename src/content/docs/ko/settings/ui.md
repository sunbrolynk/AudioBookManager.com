**Settings > UI**는 화면 표시만 바꿔요.

| 설정 | 선택지 |
|---|---|
| First Day of Week | 일요일 또는 월요일 |
| Week Column Header | `Tue 3/25`, `Tue 25/3` 또는 `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | 요일 포함 여부에 따라 네 가지 레이아웃 |
| Time Format | 12시간제 또는 24시간제 |
| Show Relative Dates | 날짜 대신 오늘, 어제로 표시 |
| Theme | Auto(OS 설정을 따라감), Light 또는 Dark |
| Enable Color-Impaired Mode | 색 구분을 바꿔서 상태를 더 쉽게 구별할 수 있게 해요 |

기본값은 앱에서 볼 수 있어요. 이 설정은 인스턴스를 쓰는 모든 사람에게 똑같이 적용돼요.
