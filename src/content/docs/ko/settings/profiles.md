**Settings > Profiles**는 섹션이 세 개인 한 페이지예요. 각 섹션은 릴리스에 대한 서로 다른 질문 세 가지에 답해요.

## 품질 프로필

품질 프로필은 형식의 사다리예요. 가장 나쁜 게 아래, 가장 좋은 게 위에 있어요. 한 칸은 형식(M4B, M4A, MP3, FLAC, OGG, Opus, AAC, WMA) 하나를 단일 파일이나 여러 파일 형태로 나타내요. 칸끼리 묶어서 같은 순위로 만들 수 있고, 칸을 끌 수도 있어요.

| 설정 | 의미 |
|---|---|
| Upgrades Allowed | 끄면 책을 한 번 받은 뒤로는 ABM이 교체하지 않아요 |
| Upgrade Until | 기준이에요. 이 품질에 도달하면 ABM이 업그레이드를 멈춰요 |
| Grab off-ladder formats | 목록에 없는 형식이라도 책을 건너뛰지 않고 grab해요 |
| Default profile | 더 구체적인 프로필이 없을 때 쓰는 프로필 |

프로필 하나가 기본값이에요. 책은 이 순서로 프로필을 써요: 책 자체의 프로필, 대표 시리즈의 프로필, 대표 작가의 프로필, 그리고 기본값. 사용 중인 프로필은 지울 수 없어요.

새 사본이 기존 것을 교체하려면 이 조건을 모두 만족해야 해요: 프로필이 업그레이드를 허용하고, 새 칸이 사다리에 있고 켜져 있고, 책이 기준 아래에 있고, 새 칸이 확실히 더 높은 순위여야 해요.

Sonarr를 써 봤다면: 품질이 해상도가 아니라 오디오 형식과 파일 구성인 품질 프로필이에요. 커스텀 포맷은 없어요. 비슷한 일은 [릴리스 프로필](#릴리스-프로필)이 맡아요.

## 지연 프로필

지연 프로필은 더 좋은 릴리스가 나올 시간을 주려고 grab하기 전에 릴리스를 잠시 붙잡아 둬요.

| 설정 | 의미 |
|---|---|
| Enable Usenet / Enable Torrent | 해당 프로토콜로 grab하는 걸 허용해요 |
| Usenet Delay / Torrent Delay | 해당 프로토콜의 릴리스를 grab하기 전에 기다리는 분 |
| Preferred Protocol | 둘 다 찾았을 때 어느 쪽을 우선할지 |
| Bypass if Highest Quality | 릴리스가 이미 프로필 기준을 만족하면 지연을 건너뛰어요 |
| Tags | 태그가 일치하는 항목에만 프로필을 적용해요 |

지연 프로필은 Sonarr처럼 표로 보여요.

## 릴리스 프로필

릴리스 프로필은 품질 위에 규칙을 더해요.

| 필드 | 의미 |
|---|---|
| Enable Profile | 켜기 또는 끄기 |
| Must Contain | 릴리스에 이 단어 중 하나 이상이 들어 있어야 해요(대소문자 구분 없음) |
| Must Not Contain | 이 단어 중 하나라도 들어 있는 릴리스는 거부해요 |
| Preferred | 릴리스 점수를 올리거나 내리는 단어. 정규식을 쓰려면 `/regex/`로 쓰세요 |
| Narration language | 낭독 언어를 제한해요 |
| Indexer | 인덱서 하나에만, 또는 전부에 적용해요 |
| Tags | 태그가 일치하는 항목에만 적용해요 |

릴리스 프로필은 표로 보여요.

## 주의할 점

- 프로필은 파일을 절대 지우지 않아요. 무엇을 grab할지, 무엇을 업그레이드로 칠지만 정해요.
- 지연 프로필이나 릴리스 프로필에 태그를 붙이면, 그 태그 중 하나가 붙은 책에만 적용돼요.
