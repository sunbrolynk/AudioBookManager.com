---
title: 표지 잠금
description: 직접 고른 표지가 새로 고침 때 바뀌지 않는 이유예요.
---

이미지를 올리거나, URL을 붙여 넣거나, 표지 검색 결과에서 고르는 식으로 책 표지를 직접 정하면, ABM이 그 표지를 저장하고 **잠가요**. 어떤 메타데이터 새로 고침도 잠긴 표지를 바꾸지 않아요.

## 어떻게 알 수 있나요

잠긴 표지는 Audible 주소가 아니라 ABM 자체 저장소에서 제공돼요. ABM은 이걸로 직접 고른 표지와 자동 표지를 구별해요.

## 영향을 받는 것

- 메타데이터를 새로 고쳐도, Libex에 새 표지가 있더라도 표지는 그대로예요.
- `cover.jpg`를 쓰거나 아트를 파일에 넣을 때 내가 고른 표지를 써요.
- Library Import에서 책마다 표지를 고를 수 있어요. [라이브러리 가져오기](/ko/library-import/)를 보세요.

## 되돌리기

책 표지를 자동 표지로 초기화하면 잠금이 풀려요. 그다음부터는 새로 고침 때 다시 바뀔 수 있어요.

## 주의할 점

- 잠금은 표지에만 적용돼요. 제목, 작가 같은 나머지 정보는 계속 새로 고쳐져요.
- 표지는 외부 연결을 통해 받아 와요. 외부 연결이 선택되지 않았다면 새 표지는 내려받지 않지만, 캐시된 표지는 계속 보여 줘요.
