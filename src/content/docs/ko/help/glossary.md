---

**ASIN**: Audible이 쓰는 10자리 책 식별자예요. ABM은 이걸로 책을 구별해요.

**자동 태그(Auto tag)**: 조건에 맞는 책에 태그를 붙이는 규칙이에요.

**차단 목록(Blocklist)**: ABM이 다시 grab하지 않을 릴리스예요.

**Connect**: 알림과 미디어 서버 연동을 다루는 설정 페이지예요. Sonarr에서도 같은 이름을 써요.

**표지 잠금(Cover lock)**: 내가 직접 고른 표지예요. 새로 고침이 바꾸지 않아요.

**기준(Cutoff)**: 품질 프로필의 "Upgrade Until"이에요. ABM이 더 좋은 걸 찾는 걸 멈추는 품질이에요.

**지연 프로필(Delay profile)**: 프로토콜별로 grab하기 전에 기다리는 시간이에요.

**Discover**: 둘러볼 수 있는 Audible 카탈로그예요.

**하드링크(Hardlink)**: 같은 파일 시스템에서 같은 파일에 붙인 두 번째 이름이에요. 공간을 더 쓰지 않아요.

**Import Workbench**: Library Import 뒤에 있는 페이지 이름이에요. 스캔하고, 매칭하고, 추가해요.

**인덱서(Indexer)**: ABM이 릴리스를 검색하는 사이트예요.

**사다리(Ladder)**: 품질 프로필에서 순서대로 늘어선 형식 목록이에요.

**Libex**: ABM이 책 데이터를 물어보는 메타데이터 서비스예요.

**Monitored / Unmonitored**: ABM이 그 책에 대해 뭔가 할지 말지예요.

**M4B**: 챕터가 들어 있는 단일 파일 오디오북 형식이에요.

**품질 프로필 / 릴리스 프로필**: [프로필](/ko/settings/profiles/)을 보세요.

**원격 경로 매핑(Remote path mapping)**: 다운로드 클라이언트가 보는 경로를 ABM이 보는 경로로 바꿔 줘요.

**루트 폴더(Root folder)**: ABM이 책을 보관하는 디렉터리예요.

**사이드카(Sidecar)**: 오디오 옆에 두는 작은 파일이에요: 표지, OPF, 설명, 내레이터, cue.

**재확인 비밀번호(Step-up password)**: 민감한 변경 전에 비밀번호를 한 번 더 묻는 거예요.

**Wanted**: 파일이 없는 모니터링 중인 책이에요.

## Sonarr를 써 봤다면

에피소드가 책이에요. 시리즈는 Sonarr의 시리즈이면서 책 카탈로그이기도 해요. 품질은 형식에 단일 파일이냐 여러 파일이냐를 더한 거예요. 커스텀 포맷은 릴리스 프로필이 돼요. Activity, Wanted, Calendar, System은 똑같이 작동해요.
