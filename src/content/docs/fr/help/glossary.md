**ASIN** : l'identifiant de livre à dix caractères d'Audible. ABM identifie les livres avec.

**Tag automatique (Auto tag)** : une règle qui pose des tags sur les livres qui remplissent certaines conditions.

**Liste de blocage (Blocklist)** : les sorties qu'ABM ne récupérera plus.

**Connect** : la page de réglages des notifications et des hooks vers les serveurs multimédias. C'est aussi le terme de Sonarr.

**Verrouillage de couverture (Cover lock)** : une couverture que tu as choisie, que les rafraîchissements ne remplaceront pas.

**Seuil (Cutoff)** : dans un profil de qualité, « Upgrade Until » : la qualité à partir de laquelle ABM arrête de chercher mieux.

**Profil de délai (Delay profile)** : une attente avant la récupération, par protocole.

**Discover** : des catalogues Audible qu'on peut parcourir.

**Lien physique (Hardlink)** : un deuxième nom pour le même fichier sur le même système de fichiers. Aucun espace en plus.

**Import Workbench** : le nom de la page derrière Library Import. Scanner, faire correspondre, ajouter.

**Indexeur (Indexer)** : un site sur lequel ABM cherche des sorties.

**Échelle (Ladder)** : la liste ordonnée des formats dans un profil de qualité.

**Libex** : le service de métadonnées auquel ABM demande les données des livres.

**Surveillé / non surveillé (Monitored / Unmonitored)** : si ABM agit ou non sur un livre.

**M4B** : un format de livre audio en un seul fichier, avec des chapitres.

**Profil de qualité / profil de release (Quality profile / release profile)** : voir [Profils](/fr/settings/profiles/).

**Correspondance de chemin distant (Remote path mapping)** : traduit le chemin que voit ton client de téléchargement en chemin que voit ABM.

**Dossier racine (Root folder)** : un répertoire dans lequel ABM range des livres.

**Fichier annexe (Sidecar)** : un petit fichier à côté de l'audio : couverture, OPF, description, narrateur, cue.

**Mot de passe de confirmation (Step-up password)** : ABM redemande ton mot de passe avant un changement sensible.

**Wanted** : un livre surveillé qui n'a aucun fichier.

## Si tu connais Sonarr

L'épisode, c'est le livre. La série, c'est à la fois la série de Sonarr et un catalogue de livres. La qualité, c'est le format plus le fait d'être en un ou plusieurs fichiers. Les formats personnalisés deviennent des profils de release. Activity, Wanted, Calendar et System fonctionnent de la même façon.
