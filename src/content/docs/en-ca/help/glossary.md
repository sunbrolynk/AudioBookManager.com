title: Glossary
description: Terms, for new users and for people coming from the arrs.
---

**ASIN**: Audible's ten-character book identifier. ABM identifies books by it.

**Auto tag**: a rule that applies tags to books matching conditions.

**Blocklist**: releases ABM will not grab again.

**Connect**: Settings page for notifications and media-server hooks. Sonarr's term too.

**Cover lock**: a cover you chose, which refreshes will not replace.

**Cutoff**: in a quality profile, "Upgrade Until": the quality at which ABM stops looking for better.

**Delay profile**: a wait before grabbing, per protocol.

**Discover**: browseable Audible catalogues.

**Hardlink**: a second name for the same file on the same filesystem. No extra space.

**Import Workbench**: the page-name behind Library Import. Scan, match, add.

**Indexer**: a site ABM searches for releases.

**Ladder**: the ordered list of formats in a quality profile.

**Libex**: the metadata service ABM asks for book data.

**Monitored / Unmonitored**: whether ABM acts on a book.

**M4B**: a single-file audiobook format with chapters.

**Quality profile / release profile**: see [Profiles](/en-ca/settings/profiles/).

**Remote path mapping**: translates the path your download client sees into the path ABM sees.

**Root folder**: a directory ABM keeps books in.

**Sidecar**: a small file beside the audio: cover, OPF, description, narrator, cue.

**Step-up password**: asking for your password again before a sensitive change.

**Wanted**: a monitored book with no files.

## If you know Sonarr

Episode is book. Series is both Sonarr's series and a catalogue of books. Quality is format plus single or multi-file. Custom formats become release profiles. Activity, Wanted, Calendar and System work the same way.
