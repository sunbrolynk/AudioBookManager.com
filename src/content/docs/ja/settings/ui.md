---
title: UI
description: カレンダー、日付の形式、テーマ、色のオプション。
---

**Settings > UI** は表示に関する設定だけです。

| 設定 | 選択肢 |
|---|---|
| First Day of Week | 日曜日か月曜日 |
| Week Column Header | `Tue 3/25`、`Tue 25/3`、`Tue Mar 25` |
| Short Date Format | `Mar 25 2014`、`25 Mar 2014`、`03/25/2014`、`25/03/2014`、`2014-03-25` |
| Long Date Format | 4種類のレイアウト、曜日ありとなし |
| Time Format | 12時間制か24時間制 |
| Show Relative Dates | 日付の代わりに「今日」「昨日」と表示 |
| Theme | Auto（OS に合わせる）、Light、Dark |
| Enable Color-Impaired Mode | ステータスを見分けやすいように色分けを変える |

デフォルト値はアプリの中にあります。これらの設定は、そのインスタンスを使う全員で共通です。
