**Settings > Profiles** は3つのセクションがある1つのページです。それぞれが、リリースについての別々の問いに答えます。

## 品質プロファイル

品質プロファイルはフォーマットのランキングで、一番下が最低、一番上が最高です。各段はフォーマット（M4B、M4A、MP3、FLAC、OGG、Opus、AAC、WMA）で、単一ファイルか複数ファイルのどちらかの形です。段をグループにまとめて同じ順位にしたり、段をオフにしたりできます。

| 設定 | 意味 |
|---|---|
| Upgrades Allowed | オフだと、一度手に入れた本を ABM が置き換えることはない |
| Upgrade Until | カットオフ。この品質に達したら ABM はアップグレードをやめる |
| Grab off-ladder formats | 本をスキップするのではなく、一覧にないフォーマットでも取得する |
| Default profile | ほかに当てはまるものがないときに使うプロファイル |

プロファイルの1つがデフォルトです。本は、本自身のプロファイル、メインのシリーズのプロファイル、メインの著者のプロファイル、デフォルト、の順で使います。使用中のプロファイルは削除できません。

新しいコピーが今のものを置き換えるのは、プロファイルがアップグレードを許可していて、新しい段がランキングにあって有効で、本がカットオフに届いておらず、新しい段の順位がはっきり上の場合だけです。

Sonarr を知っているなら：これは品質プロファイルで、品質が解像度ではなく音声フォーマットとファイル構成になったものです。カスタムフォーマットはありません。似たことは[リリースプロファイル](#リリースプロファイル)でカバーしています。

## ディレイプロファイル

ディレイプロファイルは、取得の前にリリースを保留して、よりいいリリースが出てくる時間を作ります。

| 設定 | 意味 |
|---|---|
| Enable Usenet / Enable Torrent | そのプロトコルからの取得を許可する |
| Usenet Delay / Torrent Delay | そのプロトコルのリリースを取得するまで待つ分数 |
| Preferred Protocol | 両方で見つかったとき、どちらを優先するか |
| Bypass if Highest Quality | リリースがすでにプロファイルのカットオフを満たしていれば、待たずに取得する |
| Tags | 一致するタグを持つものにだけプロファイルを適用する |

ディレイプロファイルは Sonarr と同じく表で表示されます。

## リリースプロファイル

リリースプロファイルは、品質の上にさらにルールを足します。

| 項目 | 意味 |
|---|---|
| Enable Profile | オンかオフ |
| Must Contain | リリースに少なくとも1つの語が含まれている必要がある（大文字小文字は区別しない） |
| Must Not Contain | これらの語のどれかを含むリリースは拒否する |
| Preferred | リリースの点数を上げ下げする語。`/regex/` と書くと正規表現が使える |
| Narration language | 言語を限定する |
| Indexer | 1つのインデクサー、またはどれにでも適用する |
| Tags | 一致するタグを持つものにだけ適用する |

リリースプロファイルは表で表示されます。

## 注意点

- プロファイルがファイルを削除することはありません。プロファイルが決めるのは、何を取得するかと、何をアップグレードとみなすかです。
- ディレイプロファイルやリリースプロファイルにタグを付けると、そのタグのどれかを持つ本だけが対象になります。
