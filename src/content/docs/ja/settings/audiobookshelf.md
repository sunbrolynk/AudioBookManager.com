この設定ページは、まだ公開済みのバージョンには入っていません。接続の保存、テスト、削除は API ですでにできますが、ABM のほかの部分はまだこの接続を使いません。
:::

Audiobookshelf (ABS) は、あなたが聴くためのサーバーです。ABM は、サーバーの URL と ABS ユーザー用に作った API キーでつながります。

## バージョン

ABM には ABS 2.37.0 以降が必要で、2.37.2 でテストしています。それより古いサーバーは拒否されます。新しいサーバーは、ABM でテストしていないため警告が出ます。

## アカウント

API キーは ABS のユーザーのものです。保存やテストのときに、ABM はそのユーザーを確認します。

- **直すまで拒否されるもの:** ユーザーが admin か root であること。そして Update 権限、すべてのライブラリ、すべてのタグ、成人向けコンテンツへのアクセスがあること。
- **警告は出るが保存はされるもの:** Upload がオフ (ABM がカバーを管理できません)、または Delete がオフ (ABM で削除した本は、オンにするまで ABS に残ります)。

## ABM が ABS につなぐ方法

ABM は常に ABS へ直接つなぎます。[Network](/settings/network/) で選んだ VPN やプロキシは通しません。サーバーの URL は保存前に確認され、安全でないものは拒否されます。

## API キー

キーは暗号化して保存され、二度と表示されません。保存やテストのときに空欄にすると、保存済みのキーのままになります。保存済みのキーは、保存したときの宛先にしか送られないので、URL、TLS の設定、CA バンドルを変えたときはキーを入力し直してください。

## TLS を検証する

証明書は既定で検証されます。サーバーが自前の認証局の証明書を使っているなら、検証をオフにせず、その CA バンドルのパスを指定してください。

## Test と Disconnect

**Test** は、保存せずにサーバーを確認します。バージョン、ユーザーの権限、ライブラリを見ます。オンの接続を保存するときは、先に同じ確認を行い、エラーの項目が失敗すると拒否されます。オフで保存した接続は確認されません。**Disconnect** は、保存した接続とキーを削除します。

## System Status

接続がオンのとき、[System > Status](/system/status/) に AudioBookShelf の行が出て、直近の確認の結果を表示します。保存したときと、6 時間ごとに動く定期ヘルスチェックで更新されます。ページを開くたびにライブで確認するわけではありません。

## ABM が削除するもの

ABM が ABS から消すのは項目のレコードだけです。ファイルを完全に削除することはありません。
