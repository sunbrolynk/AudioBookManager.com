---
title: Audiobookshelf との接続
description: ABM をあなたの Audiobookshelf サーバーに接続します。
---

Audiobookshelf（ABS）は、あなたが聴くためのサーバーです。**Settings > Audiobookshelf** で ABM を接続します。パソコンでもスマホでも使えます。サーバーのアドレスと、ABS のユーザー1人分に作った API キーを入力します。

## 接続

- **Enable:** ABM がサーバーを使えるようにします。オンのまま保存すると、ABM はまずサーバーを確認し、エラーレベルのチェックが失敗すると保存を断ります。理由はページに表示されます。オフで保存した接続は確認されません。
- **Server address:** ABS サーバーが応答するアドレスです。例: `http://192.168.1.20:13378`。ABS が ABM と同じマシンで動いているときは、そのマシンの LAN アドレスを使います。両方が Docker で動いているなら、コンテナ名か IP を使います。
- **API key:** ABS の admin ユーザーの API キーです。
- **Verify TLS certificate:** 初期状態ではオンです。サーバーが自前の認証局の証明書を使っているなら、検証をオフにせず、**CA bundle path** にその CA バンドルのパスを入れてください。空のままにするとシステムの証明書を使います。
- **Test:** 画面に入力されている内容でチェックを実行します。何も保存しません。
- **Disconnect:** 確認を求めたあと、保存したアドレスとキーを削除します。

## ABM が ABS に届く仕組み

ABM はいつも ABS に直接つなぎます。[Network](/settings/network/) で選んだ VPN やプロキシは経由しません。アドレスは保存の前に確認され、安全でないものは断られます。ABM が動いているマシン自身を指すアドレス、リンクローカルアドレス、クラウドのメタデータアドレスは断られ、それらに解決される名前も同じです。あなたの LAN アドレスは問題ありません。そのため、同じマシン上の ABS には、そのマシンの LAN アドレスか、コンテナ名または IP が必要です。

## API キー

キーは暗号化して保存され、二度と表示されません。保存や Test のときに空欄にすると、保存済みのキーが使われます。保存済みのキーは、保存したときのアドレスにだけ送られます。そのため、アドレス、Verify TLS、CA バンドルのどれかを変えたら、キーをもう一度入力してください。保存済みのキーを ABM が読めなくなった場合（暗号化キーをなくした、または変わった）は、接続がオフでも、他の設定ページと同じ通知がこのページに出て、もう一度入力するよう知らせます。

## 何をチェックするか

**バージョン。** ABM には ABS 2.37.0 以降が必要で、2.37.2 でテストしています。それより古いサーバーや、ABM が理解できるバージョンを返さないサーバーはエラーになります。新しいサーバーは、ABM で試していないので警告になります。

**アカウント。** API キーは ABS のユーザーのもので、ABM はそのユーザーを確認します。

- **直るまでエラー:** ユーザーは admin または root で、Update 権限、すべてのライブラリ、すべてのタグ、成人向けコンテンツへのアクセスが必要です。
- **警告、それでも保存:** Upload がオフ（ABM がカバーを管理できません）、または Delete がオフ（ABM で削除した本は、オンにするまで ABS に残ります）。

## ステータス

Status セクションには、直近のチェックの結果（Not connected、OK、Warning、Error）、サーバーのバージョン、キーの持ち主のユーザー、ABM が最後に確認した時刻、そしてチェックそのものが表示されます。失敗したチェックは理由が表示され、通ったものは件数で数えられます。

接続がオンのときは、[System > Status](/system/status/) にも Audiobookshelf の行が出ます。保存したときと、6時間ごとに動く定期ヘルスチェックで更新されるので、ページを開くたびにリアルタイムで確認するわけではありません。オフの接続は、保存済みキーが読めなくなっていても、ここでは何も表示されません。接続がオンのときは、ABM が読めなくなった保存済みキーは入力し直すまでエラーとして表示され、まだ確認していない接続は警告になります。

## ABM が削除するもの

ABM が ABS から削除するのは、アイテムのレコードだけです。ファイルを完全に削除することはありません。
