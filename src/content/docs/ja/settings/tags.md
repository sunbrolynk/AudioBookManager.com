title: タグ
description: タグと自動タグ付けのルール。
---

**Settings > Tags** ではタグと **Auto Tagging** を管理します。

## タグ

タグは1語です。小文字、スペースなし、カンマなし、最大100文字。`Sci-Fi` と入力すると `sci-fi` になります。タグは本、著者、シリーズに付けられ、インデクサー、ディレイプロファイルとリリースプロファイル、インポートリスト、Connect のエージェント、カレンダーのフィードで照合されます。

Sonarr を知っているなら：タグの仕組みは同じです。タグが付いたプロファイルは、同じタグを持つものにだけ適用されます。

## 自動タグ

自動タグは、条件に合う本にタグを付けるルールです。

| 項目 | 効果 |
|---|---|
| Name | ラベル |
| Enable | オンかオフ |
| Remove Tags Automatically | 本が条件に合わなくなったらタグを外す |
| Tags | 付けるタグ |
| Conditions | 本が満たすべき条件。それぞれ否定にも必須にもできる |

条件の種類：Genre、Monitored、Language、Root Folder、Status、Tag、Year（範囲）、Series Type、Author（部分一致）、Narrator（部分一致）、Runtime（分、範囲）、Rating（範囲）。

**Apply** で選んだルールを今すぐ実行します。ルールは本が変更されたときにも実行されます。

## 注意点

- 削除されたタグやルートフォルダを参照しているルールは、付ける方向も外す方向も丸ごとスキップされます。なので、壊れたルールが間違ったタグを付けたり、タグをはがしたりすることはありません。
- Remove Tags Automatically が外すのは、そのルールが付けるタグだけです。
