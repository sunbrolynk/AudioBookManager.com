Library Import はオーディオブックのフォルダをスキャンし、フォルダごとにメタデータとマッチさせて、本をライブラリに追加します。**Library > Library Import** を開くと「Import audiobooks you already have」が表示されるので、スキャンするフォルダを選びます。スキャンが始まると、ABM は **Match Audiobooks** という見出しのマッチングページに移り、そこでマッチを確認して本を追加します。

## 流れ

1. フォルダをスキャンします。音声が入ったフォルダが1つずつ行になります。
2. マッチを確認します。直す必要があるものは直します。
3. 必要な行にチェックを入れて、ライブラリに追加するか削除します。

どのオプションも、Media Management にあるデフォルトを必要なときだけ上書きするものです。

## マッチが確定する条件

スキャンがマッチを確定するのは、ファイルがそれを裏付けるときだけです。

- ファイル自身のタグにある ASIN でその本が見つかる。または
- 本の再生時間がファイルとの差3分以内で、シリーズ内の巻数かタイトルがファイルと一致する。

ファイルと食い違う著者やシリーズ内の巻数があると、その本は候補から外れます。ファイルが別々の2冊、または別々の2つの録音に同じくらい合う場合は、どちらも確定しません。

ファイルの再生時間は、本のすべてのファイルを読み取れたときだけ数えられます。1つでも測れないファイルがあれば、その行には再生時間がありません。一致を確定できるのはその ASIN だけで、それ以外の場合、本は **Needs a look** で待ちます。

本を2つの形式で持っている場合、形式ごとに別の行になり、それぞれ別に測られます。異なる形式のパートに分かれた本は、専用のフォルダにあれば1行になり、パートが合計されます。

再生時間で受け入れられるのは、英語版か、リストに言語の記載がない版だけです。ほかの言語の版は、ファイル自身の ASIN で見つかったときだけ受け入れられます。ライブ検索ではなく[ローカルストレージ](/ja/settings/metadata/)から答えた本は、あなたの確認なしには受け入れられません。

行の検索のどれかが失敗すると、受け入れられるのは ASIN による一致だけです。著者検索だけで見つかった本は、再生時間がファイルと合うときだけ提案されます。そのため、リストのない本は著者の別の本を提案せず、**Unmatched** と表示されます。

それ以外のマッチも候補としては出ますが、その行は **Needs a look** に入り、最初はチェックが外れていて、**Select All** でも選ばれません。マッチを確認するか別のマッチを選ぶまでそのままです。ライブラリにもうある本へのマッチが確定した行は **In library** に入ります。 提案がライブラリの本である **Needs a look** の行は、その一致を確定して初めてライブラリについての質問をします。それまでは、チェックを入れると、まだ判断が必要な行として Add をブロックします。

ほかの本と同じフォルダ（著者フォルダやスキャンしたフォルダなど）に、複数のファイルとして置かれた本は、全パートをまとめた1行になります。本や巻の番号が違うファイルは、別々の行のままです。 パートは形式ごとにまとめられます。横にある本全体のファイルは別の行になり、ファイル名のビットレート（`128kbps` など）はパート番号として扱われません。

同じ本の2つの形式（`Book.mp3` と `Book.m4b` など）は、ファイルがスキャンしたフォルダに直接置かれていても、本専用のフォルダに入っていても、別々の行になります。各行がインポート、削除、測定するのは自分のファイルだけです。同じ名前のカバー、cue、その他の音声以外のファイルは、本がそこに1つの形式だけある場合は本のファイルと一緒に移り、2つの形式がある場合はそのまま残ります。片方のコピーをライブラリに移動し、もう片方を同じインポートで削除する場合も同じです。

`Title: Series, Book 2` の形のタグは、タイトル、シリーズ、巻数として読み取られます。

`1-3` のように範囲で書かれたシリーズ内の位置は、その範囲内のどの位置とも一致します。`1, 3` のようにそれ以外の書き方の2つの数字は、位置なしとして扱われます。

500 文字を超えるタイトル、アルバム、シリーズ、シリーズ番号、アーティスト、アルバムアーティスト、作曲者、ナレーターのタグは無視されます。

Library Import ページの **Recent Import Sessions** には、スキャンごとに、マッチ済みの行数（ライブラリにもうある本を含む）と、保留中の行数（まだマッチを選ぶ必要がある行を含む）が表示されます。

## 一覧の読み方

- サマリーには、見つかったフォルダの数と準備ができた数が表示されます。上部のバーには **Sort** (Folder name, Status, Title, Author, Series, Files) と **Filter** (Ready, Needs a look, No audio, Unmatched, In library, Lookup failed, Needs a decision, Looking up, Deleted on add) があります。各フィルターには件数が表示され、その件数はサマリーと一致します。確認済みのマッチは Ready と呼ばれます。並べ替えと絞り込みはこのデバイスに記憶されます。ページのアドレスには残らないので、`?sort=` や `?filter=` の付いたリンクでは引き継がれません。
- 各行には表紙、タイトル、著者、シリーズと、マッチの確かさがパーセンテージ（たとえば「95% match」）で表示されます。フォルダの詳細には、手で検索するための **Find a match** か **Change match** があります。
- ファイルに版を確かめるための ASIN や再生時間がない場合は、フォルダの詳細にそう表示されます。
- **Rescan** はスキャン後に追加されたフォルダを拾い、自分で選んだ内容はそのまま残します。

コメントや説明の中で見つかった ASIN はヒントでしかありません。マッチとして扱われるのは、タイトルもフォルダ名と一致する場合だけです。それだけでマッチになるのは、専用の ASIN タグだけです。

## 結合、分割、追加

- 1冊の本が複数のフォルダに分かれているなら、行を結合します。フォルダの詳細からまた分割できます。 結合した行の一致は提案にすぎません。確定するか別の一致を選ぶまで、**Needs a look** に数えられ、チェックは外れたままです。再生時間は、すべてのパートに再生時間があるときだけ合計になり、ASIN はすべてのパートが同じものを示すときだけ残ります。結合は1冊の本のパート専用です。1冊の本の2つの形式は別々の行のままにしてください。結合すると両方の再生時間が足されます。行を結合または分割したあとに終わった検索も、提案になるだけです。
- 行の詳細にある **Confirm match** は **Needs a look** の行にチェックを入れ、**Undo confirmation** はそのチェックも外します。
- Add がブロックされているときは、ボタンの上に「Select at least one folder」や「2 selected rows still need a decision」のような理由が表示されます。2つの行が同じフォルダやファイルを指している場合も、Add は何にも触れずに拒否されます。
- ファイルを削除したり置き換えたりする操作は、先に確認を求めます。
- ページを離れると、保留中の編集は保存されます。

## コピー、移動、ハードリンク

**Settings > Media Management > Importing** で、Library Import のデフォルトをコピー（デフォルト）、移動、ハードリンクから選びます。インポートごとに別のものを選ぶこともできます。

ハードリンクした本は余分なディスク容量を使わず、元のファイルもその場に残ります。ハードリンクを使うには、デフォルトのルートフォルダがハードリンクに対応していて、先にチェックされている必要があります。そうでなければ、このオプションは理由付きでグレーアウトされます。別のドライブにあるなど、リンクできないファイルはコピーされ、移動されることはありません。インポートが終わると、何件がコピーになったかが表示されます。

## 追加ファイル

**Import Extra Files**（デフォルトでオン）は、本の表紙、メモなど、音声以外のファイルも一緒に持ってきます。Library Import、Manual Import、完了したダウンロードのどれにも同じように適用されます。**Show Advanced** をオンにすると、**Preferred Cover** でマッチした Audible の表紙（デフォルト）かフォルダにある表紙かを選べます。

## 長い値

省略記号で切れているナレーター、タイトル、パスは、タップかクリックすると全体が表示されます。もう一度タップかクリックすると閉じます。マウスなら、カーソルを乗せるだけでも全体が見えます。キーボードでは、フォーカスを当てて Enter か Space を押します。

## インポート以外の答え

行には **keep library**（ライブラリにすでにある本のコピーを断る）や **remove empty**（音声がなく、アートワークやサイドカーだけが残っているフォルダを断る）とも答えられます。これらが片付けるのは、その行が持っているものだけです。**remove empty** は、音声が入っているものを拒否します。ゴミ箱が設定されていればファイルはそこに入り、削除したパスはタスクのログに1つずつ記録されます。 **keep library** の判断は、その対象だったライブラリの本にだけ有効です。別のことを尋ねる一致や、ライブラリの別の本についての一致を選ぶと、行はもう一度尋ねます。インポートは実行時にもう一度確認し、その時点でライブラリのコピーにファイルがない場合 ("Your library has no copy of this book to keep") や、フォルダにライブラリの本のファイルが含まれる場合 ("This folder holds files of a book in your library") は、何も削除しません。インポートせずにファイルを削除する行は、同じ Add のインポートがすべて終わってから実行されます。その時点でファイルのどれかがライブラリの本のものなら、その行は拒否されます。そのため、同じ回で本を追加したばかりのファイルを削除することはありません。

## フォルダごとの表紙と追加ファイル

インスペクターには、フォルダにある表紙とマッチした版の表紙が、それぞれのピクセルサイズ付きで並びます。ワンクリックでもう一方に切り替えられます。その下の **Extra files** には、ほかのファイルが全部、それぞれが従う Media Management のスイッチ名の下に並びます。設定と違う選択には点が付き、**Apply this cover and these file choices to the N other selected** で1つのフォルダの選択をほかの選択中のフォルダにコピーできます。ライブラリにすでにある本にファイルを追加する行には、選択欄がありません。

[ライブラリを移してくる](/ja/guides/moving-a-library-in/)と[メディア管理](/ja/settings/media-management/)も見てください。
