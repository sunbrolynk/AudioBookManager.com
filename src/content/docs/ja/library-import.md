Library Import はオーディオブックのフォルダをスキャンし、フォルダごとにメタデータとマッチさせて、本をライブラリに追加します。ページの名前は **Match Audiobooks** です。

## 流れ

1. フォルダをスキャンします。音声が入ったフォルダが1つずつ行になります。
2. マッチを確認します。直す必要があるものは直します。
3. 行を選んでライブラリに追加します。

どのオプションも、Media Management にあるデフォルトを必要なときだけ上書きするものです。普通にスキャンして追加するだけなら、2クリック以上かかることはありません。

## 一覧の読み方

- サマリーには、見つかったフォルダの数とマッチした数が表示されます。一覧は All、Matched、Needs attention、Unmatched、In library、Failed lookup で絞り込めます。絞り込みはページのアドレスに保存されます。
- 各行には表紙、タイトル、著者、シリーズと、マッチの確かさがパーセンテージ（たとえば「95% match」）で表示されます。フォルダの詳細には、手で検索するための **Find a match** か **Change match** があります。
- ファイルに版を確かめるための ASIN や再生時間がない場合は、フォルダの詳細にそう表示されます。
- **Rescan** はスキャン後に追加されたフォルダを拾い、自分で選んだ内容はそのまま残します。

コメントや説明の中で見つかった ASIN はヒントでしかありません。マッチとして扱われるのは、タイトルもフォルダ名と一致する場合だけです。それだけでマッチになるのは、専用の ASIN タグだけです。

## 結合、分割、追加

- 1冊の本が複数のフォルダに分かれているなら、行を結合します。フォルダの詳細からまた分割できます。
- Add がブロックされているときは、ボタンの上に「Select at least one folder」や「2 selected rows still need a decision」のような理由が表示されます。
- ファイルを削除したり置き換えたりする操作は、先に確認を求めます。
- ページを離れると、保留中の編集は保存されます。

## コピー、移動、ハードリンク

**Settings > Media Management > Importing** で、Library Import のデフォルトをコピー（デフォルト）、移動、ハードリンクから選びます。インポートごとに別のものを選ぶこともできます。

ハードリンクした本は余分なディスク容量を使わず、元のファイルもその場に残ります。ハードリンクを使うには、デフォルトのルートフォルダがハードリンクに対応していて、先にチェックされている必要があります。そうでなければ、このオプションは理由付きでグレーアウトされます。別のドライブにあるなど、リンクできないファイルはコピーされ、移動されることはありません。インポートが終わると、何件がコピーになったかが表示されます。

## 追加ファイル

**Import Extra Files**（デフォルトでオン）は、本の表紙、メモなど、音声以外のファイルも一緒に持ってきます。Library Import、Manual Import、完了したダウンロードのどれにも同じように適用されます。**Show Advanced** をオンにすると、**Preferred Cover** でマッチした Audible の表紙（デフォルト）かフォルダにある表紙かを選べます。

## 長い値

省略記号で切れているナレーター、タイトル、パスは、タップするか Enter か Space を押すと全体が表示されます。もう一度タップすると閉じます。

## インポート以外の答え

行には **keep library**（ライブラリにすでにある本のコピーを断る）や **remove empty**（音声がなく、アートワークやサイドカーだけが残っているフォルダを断る）とも答えられます。これらが片付けるのは、その行が持っているものだけです。音声が入っているものは拒否されます。ゴミ箱が設定されていればファイルはそこに入り、削除したパスはタスクのログに1つずつ記録されます。

## フォルダごとの表紙と追加ファイル

インスペクターには、フォルダにある表紙とマッチした版の表紙が、それぞれのピクセルサイズ付きで並びます。ワンクリックでもう一方に切り替えられます。その下の **Extra files** には、ほかのファイルが全部、それぞれが従う Media Management のスイッチ名の下に並びます。設定と違う選択には点が付き、**Apply this cover and these file choices to the N other selected** で1つのフォルダの選択をほかの選択中のフォルダにコピーできます。ライブラリにすでにある本にファイルを追加する行には、選択欄がありません。

[ライブラリを移してくる](/ja/guides/moving-a-library-in/)と[メディア管理](/ja/settings/media-management/)も見てください。
