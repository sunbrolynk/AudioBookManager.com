---
title: 初回セットアップ
description: 新規インストール時のセットアップウィザードを、ステップごとに説明します。
---

:::caution[今後のリリースで登場]
セットアップウィザードはまだリリース版には入っていません。リリース版は、最初のアクセスでログインを求めるだけです。
:::

新規インストールでは、最初にアクセスするとログインページの代わりにセットアップウィザードが開きます。ABM に必要なことを、一つずつ順番に案内してくれます。表示されるのは、アカウントがまだ存在しない間だけです。どの選択も、あとから **Settings** で変更できます。

上部に 8 つの輪をつなげた鎖が並びます。輪の一つひとつが 1 ステップで、今どこにいるかを鎖が教えてくれます。

- **Done**：そのステップは完了しています。
- **Current step**：いま画面に出ているステップです。
- **Not started**：まだ着いていないステップです。
- **Later**：完了させずに通り過ぎたステップです。保留のまま残り、**Settings** からいつでも仕上げられます。

**Back** は一つ前のステップに戻ります。**Continue** はステップを保存して先へ進みます。Audible、Download client、Indexer の 3 つのステップには **Skip for now** もあります。

## 1. アカウント（Account）

ログインを作成して、そのままサインインします。ユーザー名と 8 文字以上のパスワードを決め、パスワードは 2 回入力します。

| 設定 | デフォルト | 効果 |
|---|---|---|
| Authentication method | Forms (Login Page) | Forms はログインページを使います。Basic (Browser Popup) はブラウザ自身のサインイン画面を使います |
| Authentication required | Everywhere | Everywhere はどのアドレスからでもサインインを求めます。Skip on local network は、自宅やオフィスのネットワーク上の端末をサインインなしで通します |

[セキュリティとサインイン](/ja/settings/security/)と同じ設定です。アカウントは **Continue** を押したときに作成されます。作成後は、このステップは確認を表示するだけになります。

## 2. ネットワーク（Network）

Network はマスタースイッチです。ここでルートを選ぶまで、ABM が送るものは何もマシンの外に出ません。そのため Metadata と Audible のステップはこれに依存します。ルートが揃うまで **Continue** は押せません。ステップを飛ばせるのは、設定の読み込みに失敗したときだけです。その場合はエラーと **Retry**、**Back**、**Skip for now** が表示されます。ルートを選ぶまで、ABM は送信するものをすべてブロックし続け、Finish のステップでは Network が保留として表示されます。

| 選択肢 | ABM に渡すもの |
|---|---|
| Proxy | プロキシの種類、ホスト名、ポート。ユーザー名とパスワードは任意です。SOCKS4 には対応していません |
| WireGuard | VPN プロバイダーの `.conf` を、貼り付けるかドロップします。すでにトンネルが保存されていれば、それが使われます |
| Own VPN container | 入力するものはありません。ABM のすべての通信がすでに VPN またはプロキシのコンテナ経由で出ていることを、チェックボックスで示します。ABM にはこれを確認できません |
| Direct | 入力するものはありません。ABM が接続するすべてのサービスにあなたの IP アドレスが見えることを、チェックボックスで了承します |

**Continue** でルートを保存すると、**Public IP** のチェックが表示されます。何かがオンラインに出る前に、ルートが動いているか確かめられます。**Change route** で選び直せます。[Network](/ja/settings/network/)と同じ設定です。

## 3. メタデータ（Metadata）

ABM が本を調べる先を選びます。最初のフォルダースキャンがこれを使って本を照合するため、フォルダーより前に来ます。

| 選択肢 | 意味 |
|---|---|
| Built-in | Libex が ABM の内部で動きます。アカウントも追加のサービスも不要です。Network ステップのルートを使います |
| Hosted | libexdb.com の公開 Libex インスタンスに問い合わせます |
| Self-hosted | あなたの Libex サーバーに問い合わせます。**Server URL** を入力します。**Test** は保存せずに確認します |

**Local Storage** のチェックボックスもあります。ABM が調べた、検索した、追加した、インポートした、または Discover で見たすべての本について、永続的で暗号化されたローカルの記録を残します。3 つのどの取得元でも使えます。一度オンにすると、オフにできるのは **Settings > Metadata** だけです。

**Continue** で取得元を保存し、チェックを入れていれば Local Storage もオンにします。選んだ取得元がまだ外に出られない場合、たとえばルート未選択の Built-in では、ステップが理由を表示します。[メタデータの取得元を選ぶ](/ja/metadata/choosing-a-source/)を参照してください。ステップの設定の読み込みに失敗した場合は、エラーと **Retry**、**Back**、**Skip for now** が表示され、取得元はあとから **Settings > Metadata** で設定できます。

## 4. Audible（任意）

ABM がライブラリを読めるように、Audible アカウントにサインインします。通信は Network ステップで選んだルートを通ります。ルートが未選択の場合や、そのルートで Audible の通信がブロックされている場合は、ステップがそう表示し、**Back to Network** で戻れます。サインイン自体は[Audible](/ja/audible/)と同じです。サインインすると、ステップにアカウントが表示され、**Continue** が使えます。

**Skip for now** を選んで、あとで **Settings > Audible** から接続することもできます。

## 5. ルートフォルダ（Root folder）

ルートフォルダは、ABM が本を置く場所です。オーディオブックがあるフォルダ、または新しい本を入れたいフォルダを選びます。プレイヤー（たとえば Audiobookshelf）が読むのと同じフォルダにしてください。サーバー上のフォルダを参照でき、ブラウザ上で新しいフォルダも作れます。最初に追加したルートフォルダがデフォルトになります。このステップは飛ばせません。ルートはあとから **Settings > Media Management** で追加できます。

## 6. ダウンロードクライアント（任意）

対応しているクライアントを選びます。Usenet でも torrent でも構いません。Deluge、qBittorrent、Transmission、rTorrent、SABnzbd、NZBGet、Blackhole です。詳細を入力して **Test** を押し、**Save** を押します。クライアントはそのステップの中で追加されます。もう一つ追加でき、**Refresh** で一覧を再読み込みします。クライアントが一つ保存されると、このステップは完了とみなされます。

**Skip for now** を選んで、あとで **Settings > Download Clients** からクライアントを追加することもできます。[ダウンロードクライアント](/ja/settings/download-clients/)を参照してください。

## 7. インデクサー（任意）

インデクサーの種類かプリセットを選んで入力し、**Test** と **Save** を押します。ダウンロードクライアントと同じ流れです。インデクサーが一つ保存されると、このステップは完了とみなされます。**Skip for now** を選んで、あとで **Settings > Indexers** から追加することもできます。[インデクサー](/ja/settings/indexers/)を参照してください。

## 8. 完了（Finish）

設定した内容をステップごとにまとめて表示します。Network のルート（確認済みなら Public IP も）、メタデータの取得元、Audible アカウント、ルートフォルダ、追加したクライアントとインデクサーです。あとに回したステップは保留として表示されます。ダウンロードクライアントの一覧が読み込めないなど、ステップの状態を読み戻せない場合、その行には **Could not check** と表示され、**Retry** ボタンが出ます。保留がなければ、すべての輪が点灯していると表示されます。**Go to Library** でウィザードを閉じます。

飛ばしたものは、いつでも **Settings** から設定できます。次に進むなら、品質プロファイルと本の登録がおすすめです。[クイックスタート](/ja/getting-started/quick-start/)を参照してください。
