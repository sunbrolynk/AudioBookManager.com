title: バックアップ

**System > Backups** ではバックアップの作成と復元をします。**Backup Now** で1つ作成します。スケジュール、保持期間、エクスポート先は [General](/ja/settings/general/) にあります。

## バックアップの中身

暗号化されたアーカイブで、データベースの整合性のとれたコピー（`database.db`）、設定（`settings.json`）、マニフェストが入っています。表紙とアプリのシークレットファイルのために、自分のバックアップにも `/config` を含めておいてください。

## 復元する

一覧から1つ選ぶか、バックアップファイルをアップロードします（最大 500 MiB）。先に現在のデータベースのコピーが保存されます。復元は元に戻せません。

リストアは、デフォルトでは**セキュリティ設定**（認証モード、認証情報、信頼するネットワーク）を元に戻しません。今のものが保たれ、結果にもそう表示されます。ページにはこれを切り替えるスイッチがありません。`restore_security_settings=true` を付けて `restore-upload` を API で呼んだときだけ元に戻るので、アップロードしたアーカイブがリストアされただけでサインインを無効にすることはありません。

古いバージョンで作ったバックアップなら、復元したあとにコンテナを再起動してマイグレーションを走らせてください。

想定外の項目が入っている、正しい SQLite データベースではない、SQLite への移行前の古いバックアップである、といった場合は、何も変えずに復元が拒否されます。

## エクスポート先

SFTP、SCP、FTPS、FTP、S3、rclone リモート。**Auto** を付けたエクスポート先には、バックアップが毎回自動で送られます。rclone リモートの名前には英字、数字、`_`、`.`、`-` が使えます。

## 注意点

- Docker イメージと compose ファイルはバックアップに入りません。compose ファイルは手元に残しておいてください。
- `APP_SECRET` を設定しているなら、それは別にバックアップしてください。これがないと、別のホストで復元したときに保存された認証情報を復号できません。
