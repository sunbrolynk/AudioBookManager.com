title: ログ
description: ログファイル、ログレベル、保持期間、ローテーション。
---

**System > Log Files** には ABM のテキストログが並びます。開いて読む、ダウンロードする、削除する、全部まとめて消す、ができます。ログは処理が実行されると出てきます。

- タスクと変換はそれぞれ専用のログを書きます。Tasks ページから各ログに飛べます。
- メインのログは `app.log` です。起動時、少なくとも1時間ごと、10 MiB に達したときにローテーションします。古いファイルは **Log File Retention** の期間（デフォルトは30日）だけ残ります。
- 別にセキュリティログもあり、サインインの試行ごとに1行が記録されます。fail2ban などのツール向けです。
- ログレベルは **Settings > General > Logging** で設定します。

## 問題を読み解く

失敗したタスクのログボタンから始めてください。処理の開始行から終了ブロックまでが表示されます。シークレットは伏せ字になっていますが、ログを公開の場に貼る前には確認してください。

## 注意点

- SQL Logging と Debug レベルは出力が多いです。用が済んだらオフにしてください。
- ログを削除しても、そのログにリンクしているアクティビティの項目は残ります。その項目には「Log no longer kept」と表示されます。
