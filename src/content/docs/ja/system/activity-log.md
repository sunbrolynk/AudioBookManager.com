ABM は3種類の記録を持っています。

| 場所 | 中身 |
|---|---|
| **System > Events** と **System > Activity Log** | アクティビティログ：起きたことをデータベースに記録した一覧です。Events は重要度で絞り込んだ表示です。Activity Log（画面のタイトルは Activity History）はカテゴリで絞り込み、メッセージを検索でき、変更前と変更後の状態も表示します |
| **System > Log Files** | 細かいところまで全部入ったテキストのログファイル。[ログ](/ja/system/logs/)を見てください |
| **Activity > History** | ダウンロードの履歴だけ。[アクティビティ](/ja/using/activity/)を見てください |

## 記録されるもの

完了したバックグラウンドタスク（それぞれ1行のサマリー）、クライアント、インデクサー、プロファイル、タグ、通知、ルートフォルダなどへの手動の変更、取得（誰が始めたか）、変換、Audible のダウンロード失敗、バックアップ、サインインとサインインの失敗、失敗した起動処理のステップ。

カテゴリ：Books、Authors、Series、Downloads、Imports、Conversions、Files、Audible、Security、System。

## プライバシー

項目には、URL、ホスト、ユーザー名、パスワード、キー、トークン、クライアントやサービスからの生のエラーテキストは入りません。オブジェクトは自分で付けた名前で表示されます。設定の保存では、どの設定が変わったかは記録されますが、値は記録されません。サインインは IP アドレスだけを保存します。同じアドレスから15分以内に失敗したサインインは、試行回数付きの1行にまとめられます。

## わざと静かにしてある

何もしなかったスケジュール実行は何も書きません。同じ失敗の繰り返しも何も書きませんが、回復したときは書きます。手動の実行は必ず記録されます。

## 保持期間

General の **Activity Log Retention** で、デフォルトでは90日後に項目が削除されます。0 にすると残し続けます。ログファイルには別の保持期間（30日）があるので、項目からログへのリンクがログ本体より長生きすることがあります。

## ログを見る（View log）

:::caution[次のリリースで登場]
項目から View log でログに飛ぶリンクは、まだリリース版には入っていません。
:::

項目は記録元のログにリンクしていて、該当する行の位置で開きます。ログがもうない場合は「Log no longer kept」と表示されます。
