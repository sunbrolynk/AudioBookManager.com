**ASIN**：Audible が本に付けている10文字の識別子。ABM は本をこれで識別します。

**自動タグ（Auto tag）**：条件に合う本にタグを付けるルール。

**ブロックリスト（Blocklist）**：ABM が二度と取得しないリリース。

**Connect**：通知とメディアサーバー連携のための設定ページ。Sonarr でも同じ名前です。

**表紙のロック（Cover lock）**：自分で選んだ表紙。更新で置き換わりません。

**カットオフ（Cutoff）**：品質プロファイルの「Upgrade Until」。ABM がそれ以上いいものを探すのをやめる品質です。

**ディレイプロファイル（Delay profile）**：取得する前の待ち時間。プロトコルごとに設定します。

**ディスカバー（Discover）**：眺められる Audible のカタログ。

**ハードリンク（Hardlink）**：同じファイルシステム上の同じファイルに付けた2つ目の名前。余分な容量は使いません。

**インポートワークベンチ（Import Workbench）**：Library Import の裏にあるページ名。スキャンして、マッチさせて、追加します。

**インデクサー（Indexer）**：ABM がリリースを検索するサイト。

**ランキング（Ladder）**：品質プロファイルの中で順番に並べたフォーマットの一覧。

**Libex**：ABM が本のデータを問い合わせるメタデータサービス。

**監視中／監視外（Monitored / Unmonitored）**：ABM がその本に対して動くかどうか。

**M4B**：チャプター付きの単一ファイルのオーディオブック形式。

**品質プロファイル／リリースプロファイル（Quality profile / release profile）**：[プロファイル](/ja/settings/profiles/)を見てください。

**リモートパスマッピング（Remote path mapping）**：ダウンロードクライアントから見えるパスを、ABM から見えるパスに変換するもの。

**ルートフォルダ（Root folder）**：ABM が本を置くディレクトリ。

**サイドカー（Sidecar）**：音声ファイルの横に置く小さなファイル。表紙、OPF、説明、ナレーター、cue など。

**ステップアップパスワード（Step-up password）**：大事な変更の前に、もう一度パスワードを聞くこと。

**未入手（Wanted）**：ファイルがない監視中の本。

## Sonarr を知っているなら

エピソードは本です。シリーズは Sonarr のシリーズでもあり、本のカタログでもあります。品質はフォーマットと単一ファイルか複数ファイルかの組み合わせです。カスタムフォーマットはリリースプロファイルになります。Activity、Wanted、Calendar、System は同じように動きます。
