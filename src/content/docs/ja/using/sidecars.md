title: サイドカーファイル
description: ABM が本の横に書き込む表紙、OPF、説明、ナレーター、cue のファイル。
---

サイドカーは音声ファイルの横に置く小さなファイルです。Audiobookshelf などのプレーヤーがこれを読みます。ABM が書き込めるのは次のファイルです。

| ファイル | 中身 |
|---|---|
| `cover.jpg` | 本の表紙 |
| `.opf` | OPF 形式のメタデータで、Audiobookshelf が読めます。本の最初の音声ファイルにちなんだ名前になり（例：`Dune.opf`）、音声がない本では `title.opf` になります |
| `desc.txt` | 説明 |
| `reader.txt` | ナレーター |
| `.cue` | Libex から取得したチャプター（次のリリースで登場） |

## いつ書き込まれるか

**Settings > Metadata** の **Create on Book Add**、**Create on Import**、**Create on Refresh** でタイミングを選びます。デフォルトではインポート時だけ書き込みます。**Overwrite Existing** はオフなので、すでにあるファイルはそのまま残ります。編集ダイアログからも、1冊の本や、選んだシリーズや著者に対して書き込めます。[メタデータの設定](/ja/settings/metadata/)を見てください。

## 表紙は特別

自分で選んだ表紙はロックされます。[表紙のロック](/ja/metadata/cover-lock/)を見てください。

## インポート時

インポートでは、本にもともとある音声以外のファイルも持ってきます。これは **Media Management > Importing** で決まります。元のフォルダに `.opf`、説明、ナレーターのファイルがある場合、ABM はそれぞれ最大1つずつ取り込み、`desc.txt` と `reader.txt` という名前にします。移動先にすでにあるファイルは触らず、既存の `cover.*` の上に新しい表紙を書き込むこともありません。

## ハードリンク

ハードリンクでインポートした場合、元のファイルはそのままです。ABM がこれらのファイルを書き込むときは、その場で編集するのではなく新しいファイルを書くので、インポート元のファイルの中身は変わりません。

## 注意点

- `metadata.json` は、ABM 自身のブロックが入っている場合に ABM が扱います。ほかのツールの `metadata.json` は、Book info files のスイッチに従います。
- 複数の本で共有しているフォルダでは、その本の音声ファイルにちなんだ名前のファイルだけがその本のものになります。
- 本を削除すると、その本のファイルにちなんだ名前のサイドカーも削除されます。
