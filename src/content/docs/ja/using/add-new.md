---
title: 新しく追加する（Add New）
description: 本を検索して、未入手として追加する。
---

**Library > Add New** では Libex で本を検索して、選んだものを追加します。検索はタイトル、著者、シリーズ、ASIN にマッチします。

## 追加すると何が起きるか

追加した本は、選んだルートフォルダと品質プロファイルで **Wanted** になり、監視の設定に沿って ABM が検索を始めます。すでにライブラリにある本かどうかは ASIN だけで判定します。同じタイトルでも版が違えば ASIN も違います。

## 著者とシリーズの検索

:::caution[次のリリースで登場]
Author と Series の検索モードはまだリリース版には入っていません。
:::

検索に、著者やシリーズそのものを探す2つのモードが加わります。これまでの本のモードは「Books by author」と「Books in series」に名前が変わります。著者やシリーズを追加すると、そのカタログが作られ、**Monitor** に応じて本が未入手として追加されます。

| Monitor | 追加されるもの |
|---|---|
| All | まだ発売されていないものも含めて全部の本 |
| Future | これから発売される本だけ |
| Missing（デフォルト） | 持っていない本 |
| None | カタログだけ |

ルートフォルダ、品質プロファイル、あとから出てくる本も追加するかどうかも選びます。最後のものは、シリーズではデフォルトでオン、著者ではオフです。すでにライブラリにある著者やシリーズには「In Library」と表示され、**Add missing books** のアクションが出ます。

追加はバックグラウンドのタスクとして実行され、進捗がトーストで表示されます。

## 検索で何も出てこないとき

メタデータの取得元から応答がなかった検索は、空の一覧ではなくエラーとして失敗します。[トラブルシューティング](/ja/troubleshooting/#メタデータの取得元が使えない)を見てください。
