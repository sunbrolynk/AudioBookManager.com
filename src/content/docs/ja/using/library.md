**Library** メニューには **Books**、**Series**、**Authors** の3つの一覧があります。中身を入れるのは **Add New** と **Library Import** です。**Audible Library** と **Conversions** はそれぞれ専用のページで説明しています。

## 本

本は1冊ずつ、概要の行、ポスター、表の1行のどれかで表示されます（表示の切り替えはツールバーにあります）。本にはステータスがあります。

- **Wanted**：監視中で、まだファイルがありません。ABM が検索します。
- **Downloaded**：ファイルがディスクにあります。
- **Missing Files**：ダウンロードはしたけれど、ファイルが ABM の想定する場所にもうありません。
- **Unmonitored**：ABM は何もしません。

本を開くと詳細ページが表示されます。ファイル、メタデータ、履歴、ABM が測った品質、それに Refresh & Scan や編集ダイアログ（下を見てください）などのアクションがあります。[サイドカーファイル](/ja/using/sidecars/)を見てください。

Sonarr を知っているなら：本はエピソード、シリーズはシーズンと番組を1つにしたもの、著者は両方をまとめる単位です。違うのは、1冊の本が複数のシリーズに属せることです。どれか1つを選ぶ必要があるとき、ABM はメインのシリーズ（巻数が一番小さいもの）を使います。

## シリーズ

**Library > Series** にはすべてのシリーズが、所持数、未入手数、ファイルなしの数と一緒に、Overview か Posters で並びます。シリーズのページには、持っていない本も含めたカタログ全体が表示されます。All、In Library、Not in Library で絞り込めます。**Add Remaining** か **Select to Add** で足りない本を未入手として追加し、**Refresh Series** でカタログを取り直します。**Monitor New Books**（All か None）で、あとから出る本を未入手として追加するかどうかを決めます。[シリーズの追跡](/ja/using/series-tracking/)を見てください。

## 著者

**Library > Authors** には著者が Overview か Posters で並びます。著者のページには、その著者のカタログがシリーズごとにまとめて表示され、シリーズごとにダウンロード済みの数と全体の数が出ます。品質プロファイル、ジャンル、評価もあります。**Refresh Catalog** でカタログを取り直し、**Search Author** でその著者の未入手の本を検索します。**Monitor New Books** はシリーズと同じように動き、著者の場合は最初 None になっています。

ライブラリにまだ本が残っているシリーズや著者は削除できません。先に本を削除してください。

## 品質プロファイルの継承

本の品質プロファイルは、本自身の上書き設定、メインのシリーズ、メインの著者、デフォルトのプロファイル、の順で決まります。[プロファイル](/ja/settings/profiles/)を見てください。

## 編集ダイアログ

本の編集ダイアログで変えるのは、その本に対する ABM 自身の設定で、メタデータではありません。

- **Monitored**
- **Quality Profile**（複数を編集するときは No Change）
- **Path**（1冊のとき。再計算するボタン付き）、または選択したものに対しては **Root Folder**
- **Tags**
- **Write to Directories**：cover.jpg、desc.txt、reader.txt、OPF（チェックボックスの表示は「metadata.opf」ですが、ファイル名は本の最初の音声ファイルにちなんだもの、たとえば `Dune.opf` になり、音声がなければ `title.opf` になります）
- **Write to Audio Files**：メタデータのタグを書き込む

シリーズと著者でも同じダイアログが開き、それぞれに含まれる本すべてに適用されます。書き込みのオプションは保存したときに実行されます。

## タグ

本、著者、シリーズにはタグを付けられます。タグはインデクサー、通知、インポートリスト、プロファイルの振り分けに使われ、カレンダーのフィードの絞り込みにも使われます。[タグ](/ja/settings/tags/)を見てください。

## 選択

行を選ぶと、まとめて操作できます。監視、検索、タグ付け、リネーム、削除です。スマホについては[スマホで使う](/ja/phone/)を見てください。
