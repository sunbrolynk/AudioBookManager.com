---
title: スマホで使う
description: 幅 768px 未満の画面での ABM の動き。
---

幅 768px 未満では、ABM はスマホ用のレイアウトになります。768px から 1023px まではサイドバーがアイコンだけに縮み、1024px 以上ではサイドバーが全部表示されます。

## ナビゲーション

サイドバーはありません。画面下のバーに Library、Activity、Wanted、Settings、System の5つのタブがあります。複数のページを持つタブは、上に小さなメニューが開きます。Library には Books、Authors、Series、Add New、Library Import、Audible Library、Conversions と Discover のページがあります。Activity には Queue、History、Calendar、Blocklist があります。ロゴをタップすると Dashboard に行きます。

## 上部バー

ページのアクションはアイコンになっています。入りきらないものは **More actions** の中にあり、シートが開きます。Indexers、Download Clients、Import Lists、Connect、Profiles、Tags では、追加は上部バーのプラスボタンです。設定ページの Save は、画面の下に固定されたバーになります。

ページの一番上で下に引っぱると更新されます。

## 一覧

- ヘッダーの下の帯に、Sort、Filter、表示の切り替えがあります。フィルターが有効な間は Filter が紫になり、保存したフィルターやカスタムフィルターはそのメニューの中にあります。Queue、History、Discover のようなページ分けされた一覧には、1ページあたりの行数もあります。
- Books は Table、Posters、Overview から選べます。Series と Authors は Posters と Overview です。Table と Overview では本1冊が1行で、表紙、タイトル、著者とナレーター、チップがいくつか、ステータスの点、評価が並びます。
- ポスターのサイズで列数が決まります。小は3列、中は2列、大は1列です。
- 行をタップすると開きます。それ以外の操作は全部 **...** ボタンの中にあり、アクションシートが開きます。
- A から Z のバーは右側に残ります。スマホを横にしたときのように画面の高さがすごく低いと隠れます。
- 合計とステータスの凡例は一覧の最後にあります。
- Queue や History のような表は、1行ずつカードで表示されます。

## 選択

選択モードでは、行をタップするとその行が選択されます。選択バーが下のタブの代わりに表示され、戻ると選択モードが終わります。

## 本、シリーズ、著者のページ

本のページの上には Search、Interactive、Import（ファイルがあれば Convert）、Refresh があり、その隣に Edit と Actions シートがあります。下には Overview、Files、Chapters、History のタブがあります。シリーズのページで持っていない本をタップすると、その本のアクションが開きます。

## そのほかのページ

- Calendar は日ごとの一覧です。表示の選択で期間を決めます。Agenda はありません。
- Conversions には Queue と History のタブがあります。
- Dashboard のカードは1列に縦に並びます。
- ダイアログは画面の下からシートとして開きます。

## 設定

Settings はグループ分けされた一覧です（Library、Sources、App）。各行はリンクになっていて、ページ名とその用途が書いてあります。ダウンロードクライアント、インデクサーなどの項目は横幅いっぱいのカードで表示されます。

## インポートワークベンチ（Import Workbench）

- サマリーカードに、準備ができたフォルダの数が出ます。タップすると凡例が開き、一覧を絞り込めます。
- 下部バーには選択数と Add ボタンが表示され、Add が押せないときはその理由も表示されます。
