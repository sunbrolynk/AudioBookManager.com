---
title: ライブラリを移してくる
description: 今あるコレクションを安全に ABM に取り込む。
---

## 始める前に

1. コレクションをバックアップします。Library Import はデフォルトでコピーしますが、ミスは起きるものと考えておいてください。
2. ルートフォルダと品質プロファイルを用意して、メタデータの取得元に接続できることを確認します。
3. コピー、移動、ハードリンクのどれにするか決めます。一番安全なのはコピーです。ライブラリが元のファイルと同じファイルシステムにあるなら、ハードリンクで容量を節約できます。[メディア管理](/ja/settings/media-management/)を見てください。

## 手順

1. **Library > Library Import** でフォルダをスキャンします。
2. 一覧を読みます。マッチしたものにはパーセンテージが表示されます。**Needs attention** と **Unmatched** の行は **Find a match** で直すか、1冊の本が複数のフォルダに分かれているなら行を結合します。
3. デフォルトを変えたいときだけ、フォルダごとに表紙と追加ファイルを確認します。
4. 行を選んで追加します。デフォルトのままなら2クリックで済みます。
5. タスクを見守ります。サマリーに、ハードリンクではなくコピーになったファイルの数と、失敗したものが表示されます。

## コレクションがもう置きたい場所にあるなら

フォルダをルートフォルダとして追加しても、それだけでは本は1冊も追加されません。ABM のスキャンはすでに知っている本しかチェックしないので、中身を拾ってはくれません。本はやはり Library Import から取り込む必要があります。**Settings > Media Management** にあるそのルートの **Unmapped Folders** の数を押すと、そのルートの Library Import が開きます。

インポートすると、各本はデフォルトのルートフォルダの下に ABM の Author/Series/Book の構成で置かれます。ハードリンクを選べば、容量を増やさずに元のファイルをそのまま残せます。

## 注意点

- すでにライブラリにある本は、そうと表示されます。二重にインポートするのではなく、ライブラリ側を残す選択で重複を断ってください。
- 音声のないフォルダを断ると、その行が持っているものだけが削除され、有効ならゴミ箱に入ります。
- 説明文の中で見つかった ASIN はヒントであってマッチではありません。タイトルも一致した場合は別です。
- インポートしたあとは更新して最新のメタデータを取り込み、ABM の選択を Audiobookshelf に見せたいならサイドカーの書き込みをオンにしてください。[サイドカーファイル](/ja/using/sidecars/)を見てください。
