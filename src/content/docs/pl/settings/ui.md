title: Interfejs
description: Kalendarz, formaty dat, motyw i opcje kolorów.
---

**Settings > UI** dotyczy tylko wyświetlania.

| Ustawienie | Opcje |
|---|---|
| First Day of Week | Niedziela albo poniedziałek |
| Week Column Header | `Tue 3/25`, `Tue 25/3` albo `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Cztery układy, z dniem tygodnia albo bez |
| Time Format | 12-godzinny albo 24-godzinny |
| Show Relative Dates | Today i Yesterday zamiast dat |
| Theme | Auto (podąża za systemem), Light albo Dark |
| Enable Color-Impaired Mode | Zmienia kodowanie kolorami tak, żeby statusy łatwiej było odróżnić |

Wartości domyślne są w aplikacji. Te ustawienia są wspólne dla wszystkich, którzy korzystają z danej instancji.
