Jeśli używałeś Sonarra, Radarra albo Readarra, większość ABM jest tam, gdzie się spodziewasz.

## Tak samo

Wanted (Missing, Cutoff Unmet), Activity (Queue, History, Blocklist), Calendar z kanałem iCal, indeksery z RSS, wyszukiwanie automatyczne i interaktywne, profile jakości z progiem (cutoff) i ulepszeniami, profile opóźnień i wydań, tagi, Connect, mapowania zdalnych ścieżek, kosz, kopie zapasowe, Tasks i Status.

## Inaczej

| W arrach | W ABM |
|---|---|
| Jakości oparte na rozdzielczości | Drabinka formatów audio, jeden plik albo wiele plików |
| Custom formats | Profile wydań z Must Contain, Must Not Contain, Preferred |
| Pozycją jest odcinek, film albo książka | Książka, z serią i pozycją śledzonymi jako katalogi |
| Metadane z własnej usługi | Libex, z blokowanymi okładkami, zapisywanymi plikami sidecar i tagami |
| Jeden folder pobierania | To samo, plus import biblioteki dla istniejących kolekcji |
| Brak konwersji mediów | Kolejka konwersji: konwersja, scalanie, dzielenie, rozdziały |
| Formaty nazw | ABM sam wybiera nazwy folderów. Rename Files jest na listach |
| Listy importu wielu rodzajów | MAM i RSS |

## Czego nie ma w ABM

Flood nie jest klientem. Nie ma custom formats. Obsługa książek z Readarra nie jest częścią tego projektu. ABM jest tylko dla audiobooków.

## Przeprowadzka

Nie ma importera z Readarra. Skieruj ABM na swój istniejący folder z audiobookami przez [import biblioteki](/pl/library-import/) i zobacz [Przenoszenie biblioteki do ABM](/pl/guides/moving-a-library-in/).
