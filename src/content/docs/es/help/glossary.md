title: Glosario
description: Términos, para quien empieza y para quien viene de las arr.
---

**ASIN**: el identificador de libro de Audible, de diez caracteres. ABM identifica los libros por él.

**Auto tag** (etiqueta automática): una regla que pone etiquetas a los libros que cumplen unas condiciones.

**Blocklist** (lista de bloqueo): lanzamientos que ABM no volverá a descargar.

**Connect**: la página de ajustes para notificaciones y ganchos de servidores multimedia. También es el término de Sonarr.

**Cover lock** (bloqueo de portada): una portada que elegiste tú y que las actualizaciones no van a reemplazar.

**Cutoff** (límite): en un perfil de calidad, "Upgrade Until": la calidad a partir de la cual ABM deja de buscar algo mejor.

**Delay profile** (perfil de retraso): una espera antes de descargar, por protocolo.

**Discover**: catálogos de Audible para explorar.

**Hardlink** (enlace duro): un segundo nombre para el mismo archivo en el mismo sistema de archivos. No ocupa espacio extra.

**Import Workbench**: el nombre de la página que hay detrás de Library Import. Escanear, emparejar, añadir.

**Indexer** (indexador): un sitio en el que ABM busca lanzamientos.

**Ladder** (escala): la lista ordenada de formatos de un perfil de calidad.

**Libex**: el servicio de metadatos al que ABM le pide los datos de los libros.

**Monitored / Unmonitored** (monitorizado / sin monitorizar): si ABM actúa sobre un libro o no.

**M4B**: un formato de audiolibro de un solo archivo con capítulos.

**Quality profile / release profile** (perfil de calidad / perfil de lanzamiento): consulta [Perfiles](/es/settings/profiles/).

**Remote path mapping** (mapeo de rutas remotas): traduce la ruta que ve tu cliente de descarga a la ruta que ve ABM.

**Root folder** (carpeta raíz): un directorio donde ABM guarda libros.

**Sidecar** (archivo auxiliar): un archivo pequeño junto al audio: portada, OPF, descripción, narrador, cue.

**Step-up password** (contraseña de confirmación): volver a pedirte la contraseña antes de un cambio delicado.

**Wanted** (buscado): un libro monitorizado sin archivos.

## Si conoces Sonarr

El episodio es el libro. La serie es a la vez la serie de Sonarr y un catálogo de libros. La calidad es el formato más si es de un archivo o de varios. Los formatos personalizados pasan a ser perfiles de lanzamiento. Activity, Wanted, Calendar y System funcionan igual.
