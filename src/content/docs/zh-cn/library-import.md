title: 书库导入
description: 用 Import Workbench 把现有收藏导入 ABM。

书库导入会扫描一个有声书文件夹，为每个子文件夹匹配元数据，然后把书加进你的书库。这个页面叫 **Match Audiobooks**。

## 流程

1. 扫描一个文件夹。每个含有音频的文件夹会变成一行。
2. 检查匹配结果，修正需要修正的。
3. 选中这些行，把它们加入书库。

每个选项都只是对 Media Management 里默认值的可选覆盖。普通的“扫描然后添加”永远不会超过两次点击。

## 怎么看列表

- 摘要显示找到了多少个文件夹、匹配上了多少个。可以按 All、Matched、Needs attention、Unmatched、In library 或 Failed lookup 筛选列表，筛选条件会保留在页面地址里。
- 每一行显示封面、标题、作者和系列，以及匹配的把握程度（百分比），比如“95% match”。文件夹详情里有 **Find a match** 或 **Change match**，可以手动搜索。
- 当文件里没有 ASIN 或时长来确认版本时，文件夹详情会注明。
- **Rescan** 会找出扫描之后新加的文件夹，并保留你已经做的选择。

在注释或简介里找到的 ASIN 只是一个线索。只有标题也和文件夹名对得上时，才算匹配。只有专门的 ASIN 标签才能单独作数。

## 合并、拆分和添加

- 一本书被拆在好几个文件夹里时，可以把这些行合并。之后也能在文件夹详情里重新拆开。
- 添加被阻止时，按钮上方会显示原因，比如“Select at least one folder”或“2 selected rows still need a decision”。
- 任何会删除或替换文件的操作都会先问你。
- 离开页面时，未完成的修改会被保存。

## 复制、移动或硬链接

**Settings > Media Management > Importing** 设置书库导入的默认方式：复制（默认）、移动或硬链接。每次导入都可以另选。

硬链接的书不额外占用磁盘空间，原文件也留在原处。硬链接要求默认根文件夹支持它，并且先通过检查。否则这个选项会变灰，并显示原因。无法链接的文件（比如在另一块硬盘上的）会被复制，绝不会被移动。导入完成后会告诉你复制了多少个。

## 额外文件

**Import Extra Files**（默认开启）会把书的封面、说明和其他非音频文件一起带过来。它对书库导入、手动导入和已完成的下载都生效。打开 **Show Advanced** 后，**Preferred Cover** 可以选择用匹配到的 Audible 封面（默认）还是文件夹里自带的封面。

## 过长的内容

被省略号截断的讲述者、标题或路径，点一下、按 Enter 或空格就会完整显示。再点一下收起。

## 导入以外的处理方式

一行还可以选择 **keep library**（放弃这份副本，因为书库里已经有这本书）或 **remove empty**（放弃一个没有音频、但还留着封面图和附属文件的文件夹）。这两种只清理这一行自己拥有的内容，任何含有音频的东西都会被拒绝。如果设置了回收站，文件会进回收站，任务日志会列出每一个被删除的路径。

## 每个文件夹的封面和额外文件

检查器会把文件夹自带的封面和匹配版本的封面并排显示，各自标出像素尺寸，点一下就能换成另一个。下面的 **Extra files** 列出其他所有文件，按它们所遵循的 Media Management 开关名称分组。圆点表示这个选择和设置不同；**Apply this cover and these file choices to the N other selected** 会把一个文件夹的选择复制给其余选中的文件夹。如果一行是往书库里已有的书添加文件，就没有选择器。
