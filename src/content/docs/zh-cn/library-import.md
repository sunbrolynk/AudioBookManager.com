title: 书库导入

书库导入会扫描一个有声书文件夹，为每个子文件夹匹配元数据，然后把书加进你的书库。**Library > Library Import** 会打开 “Import audiobooks you already have”，在这里选一个要扫描的文件夹。扫描开始后，ABM 会跳到匹配页面，标题是 **Match Audiobooks**，你在那里检查匹配结果并添加书。

## 流程

1. 扫描一个文件夹。每个含有音频的文件夹会变成一行。
2. 检查匹配结果，修正需要修正的。
3. 勾选你要的行，然后把它们加入书库，或者删除。

每个选项都只是对 Media Management 里默认值的可选覆盖。

## 什么时候会确认匹配

只有文件本身能印证时，扫描才会确认一个匹配：

- 用文件自己标签里的 ASIN 找到了这本书，或者
- 这本书的时长和文件相差不超过三分钟，而且它在系列里的序号或书名和文件对得上。

作者或系列序号和文件矛盾的书会被排除。如果文件同样符合两本不同的书或两个不同的录音版本，哪个都不会确认。

只有本书的每个文件都能读取时，才会计算文件的时长。只要有一个无法测量，这一行就没有时长：此时只有它的 ASIN 能确认匹配，否则这本书会在 **Needs a look** 中等待。

按时长只会接受英文版，或条目没有标明语言的版本。其他语言的版本只有在文件自己的 ASIN 找到它时才会被接受。来自[本地存储](/zh-cn/settings/metadata/)而不是实时查询的书，不经你确认绝不会被接受。

一行的某个查询失败时，只接受 ASIN 匹配。只通过搜索作者找到的书，只有时长与文件相符时才会被建议，所以没有条目的书会显示 **Unmatched**，而不是建议这位作者的另一本书。

其他匹配仍然会作为建议给出，但这一行算在 **Needs a look** 里，一开始不勾选，**Select All** 也会跳过它，直到你确认这个匹配或选了别的。确认匹配到你库里已有的书时，这一行算在 **In library** 里。 建议为库中书籍的 **Needs a look** 行，只有在你确认该匹配后才会提出关于库的问题。在此之前，勾选它会作为仍需决定的行阻止 Add。

一本书分成好几个零散文件，和别的书放在同一个文件夹里（比如作者文件夹，或你扫描的文件夹），会合成一行，包含所有部分。书号或卷号不同的文件仍然是各自的行。 分段按格式归组：旁边的整本书文件单独成行，共享文件夹里同一本书的两种格式是不同的行，文件名里的码率（例如 `128kbps`）不算分段编号。

写成 `Title: Series, Book 2` 这种格式的标签，会被拆开读成书名、系列和序号。

写成范围的系列位置（例如 `1-3`）与其中任何位置都相符。用其他方式写的两个数字（例如 `1, 3`）视为没有位置。

超过 500 个字符的标题、专辑、系列、系列序号、艺术家、专辑艺术家、作曲者或朗读者标签会被忽略。

Library Import 页面上的 **Recent Import Sessions** 会显示每次扫描有多少行已匹配（包括库里已有的书），以及多少行待处理（包括还等你选匹配的行）。

## 怎么看列表

- 摘要显示找到了多少个文件夹、有多少个已经就绪。顶部栏有 **Sort** (Folder name, Status, Title, Author, Series, Files) 和 **Filter** (Ready, Needs a look, No audio, Unmatched, In library, Lookup failed, Needs a decision, Looking up, Deleted on add)。每个筛选都会显示数量，这些数量和摘要对得上。你确认过的匹配叫 Ready。排序和筛选会记在这台设备上。它们不会保留在页面地址里，所以带 `?sort=` 或 `?filter=` 的链接不会把它们带过去。
- 每一行显示封面、标题、作者和系列，以及匹配的把握程度（百分比），比如“95% match”。文件夹详情里有 **Find a match** 或 **Change match**，可以手动搜索。
- 当文件里没有 ASIN 或时长来确认版本时，文件夹详情会注明。
- **Rescan** 会找出扫描之后新加的文件夹，并保留你已经做的选择。

在注释或简介里找到的 ASIN 只是一个线索。只有标题也和文件夹名对得上时，才算匹配。只有专门的 ASIN 标签才能单独作数。

## 合并、拆分和添加

- 一本书被拆在好几个文件夹里时，可以把这些行合并。之后也能在文件夹详情里重新拆开。 合并后那一行的匹配只是建议：它计入 **Needs a look**，在你确认或另选之前保持未勾选。只有每个部分都有时长时，它的时长才是各部分之和；只有所有部分给出同一个 ASIN 时，它才保留 ASIN。在你合并或拆分某行之后才完成的查询，也只是建议。
- 行详情中的 **Confirm match** 会勾选 **Needs a look** 行，**Undo confirmation** 会连同勾选一起撤回。
- 添加被阻止时，按钮上方会显示原因，比如“Select at least one folder”或“2 selected rows still need a decision”。
- 任何会删除或替换文件的操作都会先问你。
- 离开页面时，未完成的修改会被保存。

## 复制、移动或硬链接

**Settings > Media Management > Importing** 设置书库导入的默认方式：复制（默认）、移动或硬链接。每次导入都可以另选。

硬链接的书不额外占用磁盘空间，原文件也留在原处。硬链接要求默认根文件夹支持它，并且先通过检查。否则这个选项会变灰，并显示原因。无法链接的文件（比如在另一块硬盘上的）会被复制，绝不会被移动。导入完成后会告诉你复制了多少个。

## 额外文件

**Import Extra Files**（默认开启）会把书的封面、说明和其他非音频文件一起带过来。它对书库导入、手动导入和已完成的下载都生效。打开 **Show Advanced** 后，**Preferred Cover** 可以选择用匹配到的 Audible 封面（默认）还是文件夹里自带的封面。

## 过长的内容

被省略号截断的讲述者、标题或路径，轻点或单击一下就会完整显示。再轻点或单击一下收起。用鼠标的话，悬停也能看到完整内容。用键盘的话，先把焦点移到它上面，再按 Enter 或空格。

## 导入以外的处理方式

一行还可以选择 **keep library**（放弃这份副本，因为书库里已经有这本书）或 **remove empty**（放弃一个没有音频、但还留着封面图和附属文件的文件夹）。这两种只清理这一行自己拥有的内容，任何含有音频的东西都会被拒绝。如果设置了回收站，文件会进回收站，任务日志会列出每一个被删除的路径。 **keep library** 的决定只对它所针对的那本库中书籍有效：如果你选了一个询问其他事情或另一本库中书籍的匹配，这一行会重新询问。导入运行时会再检查一次，如果那时库中的副本已没有文件 ("Your library has no copy of this book to keep")，或文件夹里有你库中某本书的文件 ("This folder holds files of a book in your library")，就不会删除任何东西。

## 每个文件夹的封面和额外文件

检查器会把文件夹自带的封面和匹配版本的封面并排显示，各自标出像素尺寸，点一下就能换成另一个。下面的 **Extra files** 列出其他所有文件，按它们所遵循的 Media Management 开关名称分组。圆点表示这个选择和设置不同；**Apply this cover and these file choices to the N other selected** 会把一个文件夹的选择复制给其余选中的文件夹。如果一行是往书库里已有的书添加文件，就没有选择器。
