title: 日志
description: 日志文件、级别、保留期限和轮转。
---

**System > Log Files** 列出 ABM 的文本日志。打开一个就能阅读、下载或删除，也可以一次清空全部。日志会随着操作运行而出现。

- 任务和转换会写各自的日志。Tasks 页面为每一个都提供了链接。
- 主日志是 `app.log`。它会在启动时、至少每小时一次以及达到 10 MiB 时轮转。旧文件按 **Log File Retention** 保留（默认 30 天）。
- 另有一个安全日志，每次登录尝试记一行，供 fail2ban 之类的工具使用。
- 日志级别在 **Settings > General > Logging** 里设置。

## 排查问题

从失败任务的日志按钮开始看。它会显示这次操作从开始那一行到结束那一段的全部内容。文本里的密钥已经被抹掉了，但在公开场合贴日志之前还是要检查一遍。

## 注意事项

- SQL Logging 和 Debug 级别的日志量很大。用完记得关掉。
- 删除日志后，链接到它的活动条目还在，会显示 “Log no longer kept”。
