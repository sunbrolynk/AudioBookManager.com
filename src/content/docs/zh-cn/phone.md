---
title: 手机使用
description: 在宽度小于 768px 的屏幕上，ABM 是怎么表现的。
---

宽度小于 768px 时，ABM 使用手机布局。768px 到 1023px 之间，侧边栏会缩成只有图标；1024px 及以上则显示完整的侧边栏。

## 导航

没有侧边栏。底部有一条栏，带五个标签：Library、Activity、Wanted、Settings 和 System。包含多个页面的标签会在上方弹出一个小菜单。Library 里有 Books、Authors、Series、Add New、Library Import、Audible Library、Conversions 和各个 Discover 页面。Activity 里有 Queue、History、Calendar 和 Blocklist。点 logo 可以打开 Dashboard。

## 顶栏

页面操作都是图标。放不下的收在 **More actions** 里，点开是一个面板。在 Indexers、Download Clients、Import Lists、Connect、Profiles 和 Tags 页面上，添加用顶栏里的加号按钮。设置页面的 Save 会变成一条固定在屏幕底部的栏。

在页面顶部往下拉就能刷新。

## 列表

- 标题栏下方有一条工具栏，放着 Sort、Filter 和视图切换。有筛选生效时，Filter 会变成紫色，保存的筛选和自定义筛选都在它的菜单里。Queue、History 和 Discover 这类分页列表还可以设置每页行数。
- Books 提供 Table、Posters 和 Overview。Series 和 Authors 提供 Posters 和 Overview。在 Table 和 Overview 里，每本书占一行：封面、标题、作者和讲述者、几个小标签、一个状态圆点和评分。
- 海报尺寸决定列数：small 是 3 列，medium 是 2 列，large 是 1 列。
- 点一行就能打开它。其他操作都藏在 **...** 按钮后面，点开是一个操作面板。
- A 到 Z 的字母栏一直在右侧。屏幕很矮时它会隐藏，比如手机横过来的时候。
- 总数和状态图例在列表的末尾。
- Queue 和 History 这类表格会把每一行显示成一张卡片。

## 选择

在选择模式下，点一行就是选中它。选择栏会替换底部的标签栏，按返回就退出选择模式。

## 书、系列和作者页面

书的页面顶部有 Search、Interactive、Import（有文件之后变成 Convert）和 Refresh，旁边是 Edit 和一个 Actions 面板，下面是 Overview、Files、Chapters 和 History 标签页。在系列页面上，点一本你没有的书会打开它的操作。

## 其他页面

- Calendar 是一个按天排列的列表。视图选择器决定显示的时间段。不提供 Agenda。
- Conversions 有 Queue 和 History 两个标签页。
- Dashboard 的卡片堆成一列。
- 对话框会以面板的形式从屏幕底部弹出。

## 设置

Settings 是一个分组列表：Library、Sources 和 App。每一行都是一个链接，写着页面名称和它是干什么的。下载客户端、索引器和其他条目都以全宽卡片显示。

## 导入工作台（Import Workbench）

:::caution[下个版本推出]
导入工作台的手机布局还没有出现在已发布的版本里。
:::

- 一张摘要卡片显示有多少个文件夹已经就绪。点它可以打开图例并筛选列表。
- 底栏显示选中了多少个，以及 Add 按钮。Add 被阻止时，它会说明原因。
