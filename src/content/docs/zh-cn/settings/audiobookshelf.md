Audiobookshelf（ABS）是你用来听书的服务器。ABM 通过服务器地址和为某个 ABS 用户生成的 API 密钥连接它。

## 版本

ABM 需要 ABS 2.37.0 或更高版本，并在 2.37.2 上测试过。更旧的服务器会被拒绝。更新的版本会给出警告，因为 ABM 没在它上面测试过。

## 账户

API 密钥属于某个 ABS 用户。保存或测试时，ABM 会检查这个用户。

- **修好之前会被拒绝：** 该用户必须是 admin 或 root，并且要有 Update 权限，以及访问所有库、所有标签和成人内容的权限。
- **会警告，但仍然保存：** Upload 关闭（ABM 无法管理封面），或 Delete 关闭（你在 ABM 里删除的书会留在 ABS，直到你打开它）。

## ABM 如何连到 ABS

ABM 始终直接连接 ABS，从不经过你在 [Network](/settings/network/) 里选的 VPN 或代理。服务器地址在保存前会被检查，不安全的地址会被拒绝。指回 ABM 所在机器的地址、链路本地地址和云元数据地址都会被拒绝，解析到其中任何一个的名称也一样。你自己的局域网地址没问题。

## API 密钥

密钥以加密方式存储，之后不会再显示。保存或测试时留空，就会沿用已保存的密钥。已保存的密钥只会发送到保存时对应的地址，所以如果你改了地址、TLS 设置或 CA 包，请重新输入密钥。

## 验证 TLS

证书默认会被验证。如果你的服务器用的是你自己的证书颁发机构签发的证书，请填它的 CA 包路径，而不是关掉验证。

## Test 和 Disconnect

**Test** 在不保存的情况下检查服务器：版本、用户权限和它的库。保存一个已开启的连接时，会先做同样的检查，只要有错误项失败就会被拒绝。保存为关闭的连接不会被检查。**Disconnect** 会移除已保存的连接和它的密钥。

## System Status

连接开启后，[System > Status](/system/status/) 会有一行 AudioBookShelf，显示上次检查的结果。它在保存时刷新，也由每 6 小时运行一次的定期健康检查刷新，所以不是每次打开页面都实时探测。ABM 不再能读取已保存的密钥（加密密钥丢失或改变了）时，会显示为错误，直到你重新输入。还没检查过的连接会显示为警告。

## ABM 会删除什么

ABM 只会在 ABS 里移除条目记录，绝不会彻底删除文件。
