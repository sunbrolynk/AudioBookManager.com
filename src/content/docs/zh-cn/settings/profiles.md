**Settings > Profiles** 是一个页面，分成三个部分。它们分别回答关于一个发布的三个不同问题。

## 质量配置

质量配置是一个格式阶梯，最差的在底部，最好的在顶部。每一级是一种格式（M4B、M4A、MP3、FLAC、OGG、Opus、AAC、WMA），分为单文件或多文件两种形式。几级可以编成一组，让它们排名相同；每一级也可以单独关掉。

| 设置 | 含义 |
|---|---|
| Upgrades Allowed | 关闭时，一本书一旦有了文件，ABM 就不会再替换它 |
| Upgrade Until | 截止质量。达到这个质量后，ABM 就不再升级 |
| Grab off-ladder formats | 遇到不在列表里的格式时也抓取，而不是跳过这本书 |
| Default profile | 没有更具体的配置适用时使用的配置 |

其中一个配置是默认的。一本书依次使用：它自己的配置、它主系列的配置、它主作者的配置，最后才是默认配置。正在使用中的配置不能删除。

新的副本只有在满足以下所有条件时才会替换你现有的：配置允许升级，新的那一级在阶梯上并且已启用，书还低于截止质量，而且新的那一级排名严格更高。

如果你用过 Sonarr：这就是一个质量配置，只不过质量是音频格式和文件布局，而不是分辨率。没有自定义格式，[发布配置](#发布配置) 覆盖了类似的功能。

没有码率或体积等级：质量只指格式和文件布局。对于一个发布，ABM 从索引器或标题里得到格式，再根据标题猜测文件布局（没有分卷或音轨编号的 M4B 算作单文件），等文件导入后再检查一遍。[Audible 设置](/zh-cn/settings/audible/) 里的 **Preferred Quality** 是另一回事：它指的是 Audible 下载的音质。

## 延迟配置

延迟配置会在抓取前先压一压，给更好的发布留出出现的时间。

| 设置 | 含义 |
|---|---|
| Enable Usenet / Enable Torrent | 允许从这个协议抓取 |
| Usenet Delay / Torrent Delay | 抓取这个协议的发布前要等多少分钟 |
| Preferred Protocol | 两个协议都找到匹配时，优先用哪个 |
| Bypass if Highest Quality | 发布已经达到配置的截止质量时，跳过等待 |
| Tags | 这个配置只对带有匹配标签的条目生效 |

延迟配置以表格显示，和 Sonarr 一样。

## 发布配置

发布配置在质量之外再加一层规则。

| 字段 | 含义 |
|---|---|
| Enable Profile | 开或关 |
| Must Contain | 发布必须至少包含其中一个词（不区分大小写） |
| Must Not Contain | 含有其中任何一个词的发布都会被拒绝 |
| Preferred | 给发布加分或减分的词。写成 `/regex/` 就能使用正则表达式 |
| Narration language | 限定讲述语言 |
| Indexer | 只用于某一个索引器，或者任意索引器 |
| Tags | 只对带有匹配标签的条目生效 |

发布配置以表格显示。

## 注意事项

- 配置永远不会删除文件。它们只决定抓取什么、什么算升级。
- 延迟配置或发布配置上的标签，会把它限定在带有其中某个标签的书上。
