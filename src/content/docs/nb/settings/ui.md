---
title: Grensesnitt
description: Kalender, datoformater, tema og fargevalg.
---

**Settings > UI** handler bare om visning.

| Innstilling | Valg |
|---|---|
| First Day of Week | Søndag eller mandag |
| Week Column Header | `Tue 3/25`, `Tue 25/3` eller `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Fire oppsett, med eller uten ukedag |
| Time Format | 12 eller 24 timer |
| Show Relative Dates | Today og Yesterday i stedet for datoer |
| Theme | Auto (følger operativsystemet), Light eller Dark |
| Enable Color-Impaired Mode | Endrer fargekodene så det er lettere å skille statuser fra hverandre |

Standardene ligger i appen. Disse innstillingene deles av alle som bruker instansen.
