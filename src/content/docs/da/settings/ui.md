---
title: Brugerflade
description: Kalender, datoformater, tema og farvevalg.
---

**Settings > UI** handler kun om visning.

| Indstilling | Valg |
|---|---|
| First Day of Week | Søndag eller mandag |
| Week Column Header | `Tue 3/25`, `Tue 25/3` eller `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Fire layouts, med eller uden ugedag |
| Time Format | 12 timer eller 24 timer |
| Show Relative Dates | I dag og I går i stedet for datoer |
| Theme | Auto (følger dit styresystem), Light eller Dark |
| Enable Color-Impaired Mode | Ændrer farvekoderne, så status er nemmere at skelne |

Standarderne står i appen. Disse indstillinger deles af alle, der bruger instansen.
