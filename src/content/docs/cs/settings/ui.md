---

**Settings > UI** se týká jen zobrazení.

| Nastavení | Možnosti |
|---|---|
| First Day of Week | Neděle, nebo pondělí |
| Week Column Header | `Tue 3/25`, `Tue 25/3` nebo `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Čtyři rozložení, se dnem v týdnu nebo bez něj |
| Time Format | 12hodinový, nebo 24hodinový |
| Show Relative Dates | Today a Yesterday místo dat |
| Theme | Auto (řídí se tvým systémem), Light nebo Dark |
| Enable Color-Impaired Mode | Upraví barevné rozlišení, aby se stavy líp rozeznávaly |

Výchozí hodnoty jsou v aplikaci. Tahle nastavení sdílí všichni, kdo instanci používají.
