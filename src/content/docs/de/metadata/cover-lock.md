---
title: Die Cover-Sperre
description: Warum ein Cover, das du ausgewählt hast, beim Aktualisieren nicht ersetzt wird.
---

Wenn du das Cover eines Buchs selbst festlegst, indem du ein Bild hochlädst, eine URL einfügst oder ein Ergebnis aus der Cover-Suche wählst, speichert ABM es und **sperrt** es. Keine Metadaten-Aktualisierung ersetzt ein gesperrtes Cover.

## Woran du es erkennst

Ein gesperrtes Cover wird aus ABMs eigenem Speicher ausgeliefert, nicht von einer Audible-Adresse. Daran unterscheidet ABM ein eigenes Cover von einem automatischen.

## Was es beeinflusst

- Eine Metadaten-Aktualisierung behält das Cover, auch wenn Libex ein neues hat.
- Beim Schreiben von `cover.jpg` und beim Einbetten von Artwork wird das Cover genutzt, das du ausgewählt hast.
- Der Bibliotheksimport kann das Cover pro Buch auswählen. Siehe [Bibliotheksimport](/de/library-import/).

## Rückgängig machen

Das Cover eines Buchs lässt sich auf das automatische zurücksetzen, womit es entsperrt ist. Danach kann eine Aktualisierung es wieder ersetzen.

## Stolperfallen

- Die Sperre gilt nur für das Cover. Titel, Autor und der Rest werden weiter aktualisiert.
- Cover werden über deinen Proxy geholt, wenn du unter **Settings > General > Proxy** einen eingestellt hast.
