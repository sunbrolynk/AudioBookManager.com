title: Oberfläche
description: Kalender, Datumsformate, Theme und Farboptionen.
---

**Settings > UI** betrifft nur die Anzeige.

| Einstellung | Optionen |
|---|---|
| First Day of Week | Sunday oder Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` oder `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Vier Layouts, mit oder ohne Wochentag |
| Time Format | 12-hour oder 24-hour |
| Show Relative Dates | Today und Yesterday statt Datumsangaben |
| Theme | Auto (folgt deinem Betriebssystem), Light oder Dark |
| Enable Color-Impaired Mode | Ändert die Farbcodierung, damit sich die Status leichter unterscheiden lassen |

Die Standards stehen in der App. Diese Einstellungen gelten für alle, die die Instanz nutzen.
