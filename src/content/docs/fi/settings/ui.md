---
title: Käyttöliittymä
description: Kalenteri, päivämäärämuodot, teema ja värivalinnat.
---

**Settings > UI** koskee vain näyttöä.

| Asetus | Vaihtoehdot |
|---|---|
| First Day of Week | Sunday tai Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` tai `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Neljä asettelua, viikonpäivän kanssa tai ilman |
| Time Format | 12 tai 24 tunnin kello |
| Show Relative Dates | Today ja Yesterday päivämäärien sijaan |
| Theme | Auto (seuraa käyttöjärjestelmääsi), Light tai Dark |
| Enable Color-Impaired Mode | Muuttaa värikoodausta niin, että tilat on helpompi erottaa toisistaan |

Oletukset ovat sovelluksessa. Nämä asetukset ovat yhteiset kaikille instanssin käyttäjille.
