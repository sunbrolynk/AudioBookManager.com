---
title: Interfaccia (UI)
description: Calendario, formati delle date, tema e opzioni dei colori.
---

**Settings > UI** riguarda solo la visualizzazione.

| Impostazione | Scelte |
|---|---|
| First Day of Week | Sunday o Monday |
| Week Column Header | `Tue 3/25`, `Tue 25/3` o `Tue Mar 25` |
| Short Date Format | `Mar 25 2014`, `25 Mar 2014`, `03/25/2014`, `25/03/2014`, `2014-03-25` |
| Long Date Format | Quattro layout, con o senza il giorno della settimana |
| Time Format | 12 ore o 24 ore |
| Show Relative Dates | Today e Yesterday al posto delle date |
| Theme | Auto (segue il tuo sistema operativo), Light o Dark |
| Enable Color-Impaired Mode | Cambia i colori così gli stati si distinguono più facilmente |

I valori predefiniti sono nell'app. Queste impostazioni valgono per tutti quelli che usano l'istanza.
