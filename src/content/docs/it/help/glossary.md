**ASIN**: l'identificativo di dieci caratteri che Audible dà ai libri. ABM identifica i libri con questo.

**Auto tag**: una regola che applica dei tag ai libri che soddisfano certe condizioni.

**Blocklist**: le release che ABM non prenderà più.

**Connect**: la pagina delle impostazioni per notifiche e hook dei media server. È anche il termine di Sonarr.

**Cover lock**: una copertina che hai scelto tu e che gli aggiornamenti non sostituiscono.

**Cutoff**: in un profilo di qualità, "Upgrade Until": la qualità a cui ABM smette di cercare di meglio.

**Delay profile**: un'attesa prima di prendere una release, per protocollo.

**Discover**: cataloghi Audible da sfogliare.

**Hardlink**: un secondo nome per lo stesso file sullo stesso filesystem. Nessuno spazio in più.

**Import Workbench**: il nome della pagina dietro Library Import. Scansiona, abbina, aggiungi.

**Indexer**: un sito in cui ABM cerca le release.

**Ladder**: la scala, cioè l'elenco ordinato dei formati in un profilo di qualità.

**Libex**: il servizio di metadati a cui ABM chiede i dati dei libri.

**Monitored / Unmonitored**: se ABM agisce o no su un libro.

**M4B**: un formato di audiolibro a file singolo, con capitoli.

**Quality profile / release profile**: vedi [Profili](/it/settings/profiles/).

**Remote path mapping**: traduce il percorso che vede il tuo client di download nel percorso che vede ABM.

**Root folder**: una cartella in cui ABM tiene i libri.

**Sidecar**: un piccolo file accanto all'audio: copertina, OPF, descrizione, narratore, cue.

**Step-up password**: ABM ti richiede la password prima di una modifica delicata.

**Wanted**: un libro monitorato senza file.

## Se conosci Sonarr

L'episodio è il libro. La serie è sia la serie di Sonarr sia un catalogo di libri. La qualità è il formato più file singolo o multiplo. I custom format diventano profili di release. Activity, Wanted, Calendar e System funzionano allo stesso modo.
