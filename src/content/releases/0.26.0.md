### Added

- **Connect ABM to your Audiobookshelf server.** A new Audiobookshelf page under Settings, on desktop and phone, takes your server address and API key, tests them before saving, and can disconnect. ABM checks that the server is 2.37.0 or newer and that the key belongs to an admin with Update, all libraries, all tags and explicit content, shows which checks failed and why, and warns when Upload or Delete is off. It reaches the server directly, never through the VPN or proxy, and stores the key encrypted and never shows it again. System Status shows the server's health. The same connection can be managed through `/api/settings/abs`. This release saves and checks the connection only; ABM doesn't send anything to Audiobookshelf yet.

- **A new Dashboard.** Your library's totals (books, hours of audio, space on disk, authors, series and missing books) each open the page behind them. Below them are your newest imports, with Manual Import and Add New (an empty library with a root folder offers Library Import instead), your newest wanted books, the next 14 days of releases from your authors and series, the books still missing with a Search button on each, and your series by how complete they are, as many as the column fits. On a phone it fits one screen, with New, Wanted and Coming tabs. Library, Series and Calendar links from the Dashboard open already sorted or filtered to what you clicked.

- **Back returns lists to where you left them.** Going back from a book, series or author page brings Library, Series, Authors and Audible Library back to the item you opened, in every view and on the phone. Opening a page from the menu or reloading still starts at the top, and Ctrl+H / Ctrl+E scroll the Library list itself.

### Changed

- **A custom notification cover address must be a public one.** A cover URL that points into your own network is refused, the same as every other address ABM fetches. A cover address already saved on a message stays as it is until the message is edited; until then, notifications ABM fetches the cover for are sent without it.

- **One confirmation dialog everywhere.** Confirmations across the app, such as deleting an indexer, a download client or a profile, restarting the server or regenerating the API key, now all use the same dialog, and on a phone they open as a bottom sheet. A long name in a confirmation, such as a backup's filename, wraps instead of running off the edge.

- **Preview Rename asks like every other confirmation.** It uses the same dialog on desktop and phone, and Confirm Rename stays off when nothing needs renaming.

- **Safer confirmations.** Restoring a backup now asks the same way as a delete and opens on Cancel. Clearing the blocklist asks the same way. Regenerate API Key also opens on Cancel. While a confirmation is working, Cancel and Escape wait for it to finish.

### Fixed

- **Coming soon is faster and shows each book once.** The upcoming list loads in a fraction of the time, covers exactly the number of days asked for, and shows a book once even when it has several editions, picking your library copy or the edition in your preferred language. Books in every language still show.

- **Series filters now match the footer counts.** Complete, One short and Incomplete on the Series page list the same series the footer's Complete and Missing Books counts add up to, instead of a separate tally that could disagree with them.

- **Read-only values on settings pages start on the same line as their labels.** Proxy in use, Tunnel status and Next Scheduled Backup sat a little above their labels.

- **The Authors page always shows the same publisher first, and book search returns its results in the same order.** An author's publisher could change after every restart, and a book search could list its results, or cut them off, differently each time. An author's publishers now come most books first, and a search lists books whose title matches before books that only match by author.

- **A series always shows the same author first.** The Series page could show a different author for the same series after every restart, and the publisher and narrator lists could reshuffle too. A series now lists the author on the most of its books first, and on a tie the book's main author, and orders its publishers and narrators the same way each time.
