### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Check that SABnzbd has ABM's download category.** After you update, a SABnzbd client whose category (ABM's default is `audiobooks`) doesn't exist in SABnzbd fails its Test, is shown as unhealthy, and ABM won't send it grabs. Add the category in SABnzbd under Config > Categories, or change the category on the client in ABM to one SABnzbd already has. Downloads from other categories no longer show in ABM's queue.
- **Check for duplicate remote path mappings.** If two of your mappings have the same host and remote path, only the older one is used; delete the one you don't want. Adding or editing a mapping into a duplicate through the API now returns 409.

### Added

- **One book in two formats in one folder.** When Library Import finds the same book in a shared folder as, say, an M4B and an MP3, it shows the copy the book's quality profile ranks highest and hides the rest under a new Hidden status. A book not in the library yet uses the default profile, and with no profile at all M4B comes first, then M4A, MP3 and FLAC. When two copies rank the same, the higher bitrate wins, then the bigger copy. The ranking follows the profile as it is now, so changing it before you import changes which copy is kept. Hidden copies are never added, and you can delete them from the Hidden filter. Delete the kept copy and the next best one comes back.

- **Pick which format to import.** When Library Import hides a copy of a book behind a better format, you can pick that copy instead. The one you pick is kept through a rescan, a profile change and deleting another copy, and the rest are hidden behind it.

- **Delete a book's other copies after adding it.** When Library Import adds a book whose other formats were hidden, it asks whether to delete those copies or keep their files. Delete counts books, every copy of one book as one, and lists each file it will delete. Add won't run while two folders are matched to the same edition, and names both so you can pick one.

- **Rescan ranks every copy of a book again.** When a rescan finds a better format of a book you already had in Library Import, the copy you had is hidden behind it, and the rescan's message tells you how many were hidden. Join and Split wait until the rescan finishes. If a change can't be saved, Library Import tells you why instead of only saying it couldn't save.

- **Library Import count bar.** The counts above the list are now buttons that filter it, the same as the Filter menu.

### Fixed

- **Finished SABnzbd and NZBGet downloads get imported.** ABM only ever looked at failed jobs in the Usenet clients' history, so a download that finished never reached the import. It now reads the whole history: a finished job is imported from the folder the client says it ended up in, with remote path mappings applied, and removed from the client's history afterwards when that's turned on. A job still being repaired, unpacked or moved shows as downloading until it's done. Only downloads in the client's category are read, so ABM no longer picks up, blocklists or removes other apps' downloads.

- **A finished download ABM couldn't reach imports by itself once the path is fixed.** It's checked again every cycle, so fixing the volume or permissions is enough, not just a path mapping change. Import Now and Manual Import show for it again on the Queue, and the completed download check says when it skipped something because the path isn't reachable. The download client Test checks the folder the client really saves to, with your remote path mappings applied, reads the client's own save path when Directory is blank (qBittorrent, Deluge, Transmission, rTorrent), and offers its suggested mapping with an Add this mapping button. A mapping for /data no longer also catches /data2.

- **SABnzbd without ABM's category is caught instead of losing downloads.** If SABnzbd has no category with the name set in ABM, the client's Test now fails and says so, grabs to it are refused, and it shows as unhealthy until you add the category in SABnzbd under Config > Categories. Stock SABnzbd doesn't have an `audiobooks` category. Before, SABnzbd quietly filed those downloads under its default category, where ABM never saw them finish. A wrong API key now fails the Test as an authentication error too.

- **A Usenet download reported at a shared folder is skipped instead of imported from that whole folder.** For SABnzbd, ABM reads SABnzbd's own complete folder and category folders, including categories whose path ends in `*`. A download it reports at one of those folders, at ABM's Directory or at a drive root is skipped with a message, and nothing else in that folder is scanned or moved. SABnzbd categories also match whatever their case.

- **A download that is a single non-audio file no longer imports another book's audio.** When a download client reported one file that isn't audio, such as an `.epub`, ABM looked beside it for audio with a similar name and could import a different book's file from the same folder. ABM now looks beside a download only when nothing by the reported name exists.

- **A second remote path mapping for the same host and remote path is refused.** It used to be saved as a copy that never applied; now you're told to edit the one you have. Queue's path-mapping suggestion is no longer offered for a download a mapping already covers, and an rTorrent error reply is no longer read as its save folder.

- **Editing a remote path mapping no longer saves a blank host or path.** Editing a mapping, or bulk-editing several, now refuses a blank host, remote path or local path with "All fields are required", the same as adding one.

- **Deluge's Test shows the Deluge version.** It said "Connected to Deluge unknown" because Deluge 2 doesn't answer the version call ABM made.
