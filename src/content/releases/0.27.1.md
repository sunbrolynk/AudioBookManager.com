### Changed

- **Faster library scans.** MP3 files are now measured straight from their headers instead of a full tag read, and M4B/M4A chapters stored as a QuickTime chapter track are read in-process instead of starting ffprobe for each file. Durations, bitrates and chapters come out the same as before; anything unusual still goes through the full read.

### Fixed

- **New folder in the folder browser won't create a folder directly in `/` or inside a system folder** such as `/etc` or `/var`, including through a link that points there, and says why.

- **Select picks the path typed or pasted into the folder browser.** Before, Select could hand back the folder listed below the path box instead, so a pasted path in Library Import scanned `/`. A typed or pasted path is now also applied when you click away from the box, and a path that doesn't open keeps the browser open with the reason.
- **A scan of `/` or a system folder is refused with a clear message** instead of walking the whole filesystem.
- **A failed New folder says which folder and which user can't write to it**, or that the disk is full, read-only or the folder is gone.

- **Sidebar counts show on collapsed sections.** When Activity or System is collapsed in the desktop sidebar, its row now shows the queue count or the health issue count, like Sonarr and Radarr. When you expand the section, the count moves to Queue or Status. Screen readers now announce what each count means, such as "2 health issues".
