### Added

- **Custom filter value lists:** the value box of a custom filter lists the values already in the library for Author, Narrator, Series, Publisher, Language, Genres, Tags, Keywords, Quality Profile, Format and Plans, on Library, Series, Audible Library and the Calendar. It narrows as you type; pick a value, or keep whatever you typed. On a phone the list opens as a bottom sheet. Yes/No fields use a Yes/No picker.

- **Phone Overview card.** A new phone Overview card for books, authors and series: a header over a blurred copy of the cover, a strip of key facts, the narrator, a short description, genres and labelled actions. It's used on Library, Authors, Series, Audible Library, Discover and Add Book.
- **Phone Table.** The phone Table is now a dense list of about thirteen rows per screen, and the value on the right follows the current sort. Authors and Series get a Table view on the phone too.
- **Library sorts.** Library can sort by Size on Disk and by Length.
- **Generated cover art.** Books and authors without a cover or photo get generated gradient art instead of a flat colour, and a book keeps the same art on every page. A cover that fails to load shows the art instead of a broken image.

### Changed

- **Multi-value filter fields:** Genres, Tags, Keywords and Plans now match each value on its own, so "is" on one genre finds a book that has several. "Is not" and "does not contain" leave out a book when any one of its values matches. A saved filter whose value has a comma still matches the joined list as before.

- **Phone Table rows have no action buttons.** Phone Table rows no longer carry their own action buttons. Tapping a row opens it, and select mode has the bulk actions.
- **Series positions.** Series positions read the same everywhere. Where a book has no position, only the series name shows.

- **Series custom filters now look at the books in each series.** A book field such as Genres, Narrator or Upgradable matches a series when any of its books match, and "is not" or "does not contain" matches only when none of them do. Before, those fields never matched a series at all.
- **The filter value box lists every value and takes typed text.** The list is no longer cut off, stays quick with thousands of values, and whatever you type is kept as the value.

- **GitHub links** in the header, System → Status and the update check use the repository's new name, `sunbrolynk/AudioBook-Manager`.
