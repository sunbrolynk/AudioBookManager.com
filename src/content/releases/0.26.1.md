### Changed

- **The book page splits into columns from 768 px wide instead of 1024.** Between 768 and 1023 px the cover used to fill the width of the window and push the title and details far down the page. The cover now sits in its own column beside the details, the way it does on a wider screen, and the status badge in the side card wraps under its label when the card is too narrow for both.

### Fixed

- **Searching the library by title or author works again.** The book search returned an error for any book it found. It now returns the matching books, title matches first and each group in library title order, with the same narrators, tags, file count and quality profile the book page shows.

- **Import list notifications send again when one of them is limited to tags.** When an import list added a book, a notification limited to certain tags failed, and every notification after it was skipped. Each one now checks the new book's tags and sends or skips on its own.

- **Page header buttons that don't fit fold into a More menu** instead of running off the screen at tablet width.

- **Manual import errors name the real file.** The Tasks page, the operation log, a book's History and the Activity Log now name the file that was actually imported or refused, not the label the request gave it. A long path in a notification wraps instead of running off the edge. When Move Automatically finds the files but can't start the import, it says "Could not start the import" instead of "Could not scan the folder".

### Security

- **Manual import only takes audio files from your own folders.** `POST /api/manual-import/execute` and `/execute-to-book` passed every file row straight to the import task, so a request could move or copy any file the app could read, including its own database and key file, into a book folder. Each row is now checked against a fixed schema: unknown keys, relative paths and an empty `files` list get a 422. The source has to be an audio file that isn't in a system folder (such as `/etc`, `/usr`, `/var` or `/root`), directly in a top-level folder like `/tmp` or `/mnt`, or in one of the app's own folders (config, database, backups, logs, covers, recycle bin, temp, and the SSL certificate and key folders), with symlinks followed. A refused file gets a 400 naming it, and nothing is queued. The import task checks every row again right before it moves the file. If your downloads sit under one of those folders, import them from somewhere else.

- **Moving the recycle bin only moves the bin that's in use.** A recycle bin move now refuses to run unless the folder it moves from is the recycle bin currently set in Media Management.
