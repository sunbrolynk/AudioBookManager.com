### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Sign in again to Audible accounts on the old device registration.** After you update, Settings > Audible marks any account still on the old registration. ABM won't download from it, and the Audible mirror skips its titles, until you sign in to it again there. Signing in again keeps the account's library, its downloaded and imported books, and its library links.

- **A folder linked inside the cover folder is no longer used.** The MediaCover folder itself can still be a link to another disk. If you linked a folder inside it instead, such as `MediaCover/books`, ABM ignores that folder and logs a warning. Those covers show placeholder art until the nightly cover cache run, then load from the cover host instead of a saved copy until you link MediaCover itself or move the folder back. Once you do, ABM saves them again within the hour.

- **Going back to 0.28.0.** From a container still running 0.29.0, run `alembic downgrade d5f1a8c3b627`, then switch the image tag back to 0.28.0. Going back removes your Audiobookshelf pairings.

### Added

- **Pair each root folder with an Audiobookshelf library folder.** A new Libraries section on Settings → Audiobookshelf, on desktop and phone, has a row per root folder where you pick the Audiobookshelf library folder that is the same folder on disk. When you save, ABM looks up a few of that root folder's books in the chosen folder and refuses the pairing, with the reason under its row, unless every one is there. A root folder with no books yet saves without being checked. Changing the server address, TLS setting or CA bundle checks every pairing again. A folder already paired with another root folder, or one that can't be paired, is listed but can't be picked. Disconnecting removes the pairings, and so does removing a root folder. Through the API, `/api/settings/abs` takes and returns them in a new `pairings` field (leave it out to keep the saved pairings, send `[]` to remove them all), a refused save says which root folder it is about in `root_folder_id`, and the connection test marks each folder `pairable`. ABM only reads from Audiobookshelf; it still doesn't change anything there.

- **Pairing checks are quick on large libraries.** ABM finds a root folder's sample books by searching Audiobookshelf for each one's ASIN or title, and the book's ASIN and title are sent to your Audiobookshelf server; file paths never are. A book the search can't find is looked for in the library's full list. One save's checks get up to two minutes in total; if that runs out, ABM says so and asks you to save again.
- **Only audiobook libraries can be paired.** Podcast libraries are not listed.
- **A pairing can be removed while Audiobookshelf is turned off.** Adding or changing one still needs it turned on.

- **Book Naming on Media Management, and Organize for books, series and authors.** A new Book Naming section sets how books, series and folders are named, with live examples built from a real book, and it saves with the page's Save. Books, series and authors get an Organize that previews the names and folders the current scheme gives, then moves and renames the selected books to match. When a book's new folder sits inside its current one, Organize creates the subfolder and moves only that book's own files and sidecars into it, leaving everything else where it was; the preview (up to 20 files, with a total count) and the result list what stays. Moving a book's folder from the book editor into a subfolder of itself does the same. Organize leaves alone any file that belongs to another book in the same folder, including one named after that book's audio. When the Standard Book Format would give two files the same name, for example `{Original Filename}` with `CD1/01.mp3` and `CD2/01.mp3`, the import is refused with a message naming the file, before any file is copied or moved, and Organize skips the book and says why. A file downloaded from Audible with `{Original Filename}` as the format is named after the book's title. Organize won't nest a book into a folder that already holds audio that isn't the book's, and says why. A book with no author but a translator is named after its first translator.

- **Book Naming refuses formats that would write unusable names.** A format can't contain characters Windows and SMB shares refuse in a file name (`\ / : * ? " < > |`) outside its tokens, so `{Book Title}: {part:00}` is refused when you save rather than failing later on the share. When every book in an Organize run fails, the result lists each book and why.
- **Standard Book Format always applies.** Even with Rename Books off it names Audible downloads, extra parts of a book and files whose names would clash, so it is always shown and checked.

### Changed

- **API calls that take a list of book, series or author ids refuse an id of 0 or below with a 422.**

- **New imports get slightly different default names.** A standalone book's folder, and a series book with no position, now start with the year (`2004 - Title`). File names leave out the year when it isn't known, instead of writing `(Unknown)`. A title that matches a Windows reserved name like `CON` is kept as it is in the file name. Books already in your library keep their names until you run Organize on them.

- **Imports never replace a file that isn't the book's own.** When a file is already sitting at the name an import or an Audible download would use, and it isn't one of that book's tracked files, the file is left alone and the import reports what it skipped, instead of moving the old file to the recycle bin or replacing it. Files added to a book with parts get the next free part numbers, and an upgrade or re-download still replaces the book's own copy. An Audible download also never replaces a broken link at that name, and keeps the book's own copy until the new file is in place.

- **Library Import lookups through the API and the Import Workbench are faster.** A scan started through the API with `search_unmatched` on looks up three folders at a time instead of one after another, and resolves its folders' ASINs in batched requests instead of one request per book. Each folder gets the same match it got before, and a book one folder already matched is still not offered to a later folder. The Import Workbench's own lookups also resolve an ASIN found only in a folder or file name in their batched requests.

- **Manual Import API changed.** `POST /api/manual-import/execute-to-book` names each file from your Book Naming settings and ignores `destination_filename`. `POST /api/manual-import/check-conflicts` takes `source_paths` (absolute, at most 5,000; unknown fields are refused, so a request still sending `destination_filenames` gets a 422) and returns the names it would use; `other_conflicts` and `has_other_conflicts` are gone, and `own_conflicts` is always present, listing the conflicting names that are the book's own files, which the import replaces. Any other conflicting name is skipped.

- **Manual Import says when nothing was imported.** An import where every file was refused or failed now ends as failed and names each file with its reason, instead of finishing as complete without a word. Before you import, the conflict check shows which files at the same names are the book's own, which are replaced, and which belong to something else, which are skipped. A queued download refused for the same reason now says the name is already there and isn't one of the book's files.

- **Library Scan and Add to Library are faster on large libraries.** A Library Scan saves its changes in batches of books instead of one book at a time, and on large imports Add to Library reads each file's disc and track tags ahead of the import on several CPU cores at once. It also reads your settings and root folders once per run, and skips the notification step when no notification is turned on for imports. A book that fails still fails on its own; if saving a whole batch fails, every book in it is reported.

- **Files ABM writes follow the system's permission mask.** New covers and the files written beside a book (description, reader, OPF, NFO, metadata.json) are created with the permissions your system's umask gives, where they were always created as 0644. With the usual umask nothing changes. A file that is replaced keeps the permissions it had.

### Fixed

- **Audible downloads that failed as throttled now say why and how to fix it.** Accounts added before the newer sign-in still use an old device registration, and Audible refuses download licences to those. A download on one of these accounts now says so and asks you to sign in to the account again on Settings > Audible. Signing in again registers it afresh and keeps the account's Audible library, its downloaded and imported books, and its library links, so you no longer have to delete the account and add it back. Waiting doesn't fix it, so ABM no longer holds the account for 48 hours. When an up-to-date account is throttled, the message says to try again later instead of promising a 24-48 hour wait.
- **Audible licence requests go one at a time.** Queueing several Audible downloads no longer sends all their licence requests to Audible at once. Each account asks for one licence at a time, with a short pause between them, while the audio still downloads in parallel. A download waiting its turn says so on the Tasks page. If Audible refuses the first request, the downloads still waiting stop without asking again.
- **An Audible title counts as downloaded when its book has files.** ABM no longer keeps a separate downloaded mark that deleting an account and adding it back could lose. An account still on its old device registration is skipped for downloads until you sign in to it again, so ABM no longer queues downloads for it that can only fail.
- **The Audible mirror leaves alone books you have unmonitored or excluded.** It used to download them again. The Audible sync's message now says how many it left out. You can still download any of these titles yourself.

- **Books show their bitrate.** Every import, download and conversion now sets the book's bitrate, a library scan fills it in for books that were missing it, and a book of several files shows their duration-weighted average.

- **Covers show whole on the book page and the Dashboard.** Each cover keeps its own shape, so square and tall covers are no longer cropped or zoomed in.

- **Saved covers are never read, written or deleted through a link that leads outside the cover folder**, so a linked folder can no longer lose files that aren't covers.

- **A cover that changes while an older download of it is still running no longer ends up showing the old image.**

- **Your own cover always shows.** After you upload or pick a cover for a book, the Library, the book page and every other page show it, instead of the automatic cover ABM saved before. Reverting brings the automatic cover back, and when a refresh finds a new automatic cover, the old one is no longer shown in its place.

- **Dashboard shows real covers.** The Dashboard, Missing, Cutoff Unmet, Calendar and Conversions pages now use the same saved covers as the Library, instead of placeholder art when the cover host can't be reached.

- **New books no longer pick up a deleted book's cover.** Deleting a book or author now removes its saved covers too, so a book added later can't show the old cover or have it written into its audio files.

- **Deleting a book with its files removes only its own files when its folder holds anything of another book**: another book's files or folder, audio not imported yet (loose beside it or in a folder beneath it), or another book's description, reader or metadata file. A book recorded at a root folder never has the root's other contents removed.
- **Adding files to a book already in the library fails when none of them could be added**, instead of reporting success and marking the book imported; the book is left as it was.

- **A book with more than one author is put in the author folder Organize expects when it's added.** If one of its authors was already in the library, it could land under the other author's folder, and Organize would then offer to move it.

- **The Queue page and imports no longer stop until you test a download client.** After a completed-download check hit an import error, the Queue page could start failing to load and every later check failed too, so finished downloads stopped importing until you pressed Test on a download client. They now keep working on their own.

- **History shows upgrades.** Upgraded books now appear under Imported in History, and failed post-add and post-import steps appear under Failed.

- **Library Import says why it can't add missing files to a book that has no folder**, such as one added while another book held its folder, and leaves the files where they are.

- **Library Import brings in a book that already sits in its library folder under its library name when other audio is beside it.** It used to fail, saying the file already exists; the book now stays where it is.

- **Manual Import no longer skips a file whose new name matches another's in the same import**, such as `CD1/01.mp3` and `CD2/01.mp3`, which both came out as Part 1; files are now numbered by position. The conflict check also catches a file already in the folder whose name differs only in case.

- **Audible badges no longer cover the book's icons.** On small and medium posters the origin badge sits in the same row as the Virtual Voice and Plus icons and wraps above them when the cover is too narrow, the overview cover wraps its badges instead of cutting the last one off, and on desktop overview the badges sit above the status label instead of over it.

- **Books that share a series position sort by release date.** On the Library, Audible Library, series and author pages, and when you sort by series on Wanted, Discover, History and Blocklist, books at the same position come in release-date order instead of in no particular order or by title. When two books share a series' first position, the series cover and path come from the older release.

- **Library Import brings in every book from an author folder that holds one loose audio file beside other book folders.** The loose book is moved into its own folder.
- **A book whose folder is an author folder no longer blocks that author's other books.** When such a book holds only its own loose files, completed downloads, Manual Import, Library Import, the library scan and Add Book all work for the book folders beneath it.
- **Rescanning a book whose folder is an author folder no longer picks up the audio of the author's other books in the folders beneath it.**

- **After a restart, View logs on a re-run task opens the new run's log.**

### Security

- **soupsieve updated to 4.1**, fixing four published advisories in the CSS selector library that Beautiful Soup pulls in: crafted HTML or a crafted selector could make matching or compiling take very long or recurse without limit. ABM never runs a CSS selector, so it was never exposed.
