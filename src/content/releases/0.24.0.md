### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Scripts that queue tasks through `POST /api/tasks` need a look.** It now accepts only `backup_export` and answers 403 for every other task type. Move manual imports to the `/api/manual-import/` endpoints and library scans to `POST /api/library/scan`. The web interface needs no changes.

### Fixed

- **Background tasks start right away.** A queued scan, import, search or refresh used to wait up to a second before it began, and the next one in line waited again after each finished. Tasks now start as soon as they are queued or a slot frees up.

### Security

- **The task queue endpoint only takes the backup export.** `POST /api/tasks` accepted any task type with any settings, so an API key could start internal tasks the interface never offers, with settings of the caller's choosing. It now queues only `backup_export`, the one task the web interface sends it, and checks its settings. Every other type gets a 403 and bad settings get a 422. The server now sets the priority and item count itself and ignores `priority` and `total_items` in the request. `manual_import` and `library_scan`, which the API reference listed for this endpoint, are refused here; use the Manual Import endpoints under `/api/manual-import/` and `POST /api/library/scan` instead.
