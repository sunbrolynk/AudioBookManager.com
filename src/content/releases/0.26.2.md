### Changed

- **Joining rows in Library Import always adds their runtimes together.** A join is for the parts of one book, so the joined row's runtime is now the total of every row in it. Rows that looked like the same book in two formats used to keep only the longest runtime instead.

- **Library Scan is faster on network and Windows drives.** When a library sits on a slow drive, Library Scan now checks several book folders at once instead of one after another, so a scan that looked at each folder in turn finishes in a fraction of the time. Libraries on local disks scan the same as before.

### Fixed

- **Fewer metadata lookups fail when a proxy drops a connection.** If the proxy dropped a connection before it reached Audible, the metadata lookup failed straight away. It now tries once more after a short pause, so a single dropped connection no longer fails the lookup. If the second try fails too, the lookup reports an error as before.

- **A download holding the same book twice imports the copy your quality profile prefers.** When a completed download held one book in more than one format, such as an M4B and an MP3 copy, every copy was imported and the runtime was measured at double, which could keep the download from matching its book. Only the copy the book's quality profile ranks highest is imported now. Formats the profile ranks the same, or doesn't rank, go by a fixed format order: M4B, then M4A, then MP3, and so on. The other copies stay in the download, and the book keeps its cover and extras.

- **Tablet sidebar submenus open again.** At tablet width, tapping Library, Settings or another section in the icon rail now shows its submenu instead of nothing, so pages like Series and Authors can be reached. Escape closes the submenu.

- **Damaged MP3s get a real length and codec.** A broken .mp3 whose bytes happened to look like a few frames of audio could be listed with a made-up length and an MP1 or MP2 codec. ABM now leaves those files to ffprobe, so they show what ffprobe finds in them.

- **Adding a book from your Audible library uses the root folder you pick.** The Add dialog's root folder choice was ignored, so the book always went to the default root folder. Both adding and adding with a download follow this choice.
