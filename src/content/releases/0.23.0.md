### Added

- **A setup wizard for a new install.** The first visit now walks you through
  everything ABM needs, one step at a time, with a chain across the top that
  shows which steps are done, which one you're on and which are waiting. It
  starts with your account, then how ABM reaches the internet (a proxy,
  WireGuard, your own VPN container or Direct, with a Public IP check once it's
  saved), then where ABM looks books up (Built-in, Hosted or your own Libex
  server, with an optional Local Storage record). After that comes an optional
  Audible sign-in, your root folder, a download client and an indexer. Clients
  and indexers are added and tested right in the step. Audible, the client and
  the indexer can be left for later, and the last step shows what's set up and
  what's still waiting. Every choice can be changed afterwards in Settings.

### Changed

- **The folder browser opens a folder you just created.** Creating a folder
  in the browser now takes you into it, instead of reloading the folder you
  were in, so Select Folder picks the new one.

### Fixed

- **Moving books between root folders and placing extra files refuse a broken symlink at the destination.** Moving books to another root folder failed with a generic error, and an import or extra file replaced the link. Each now reports that the destination already exists and leaves the link and the original in place.

- **Renaming a file or moving a book's folder onto a name held by a symlink is refused.** A broken symlink at the new name used to be treated as free: the file or folder was moved to the link's target and the link stayed. It now reports that the name already exists.

- **The Local Storage page opens even when the backup folder cannot be read.** It used to fail with an error. The backup, recycle, log and cover folders also follow the config path you set instead of always pointing at `/config`.

### Removed

- **Two tracker presets that could never work are gone.** Both were set up as
  Torznab at the site root, and neither site has a Torznab API, so picking one
  could never work. They're removed from Settings › Indexers and the setup
  wizard. Jackett and Prowlarr remain presets. Indexers you already saved are
  untouched.
