### Changed

- **Every menu entry has its own icon.** Pages that shared an icon (Queue and Tasks, History and Events, Library Import and Backups, Updates and the Settings gear, and others) now each have one that fits.

### Fixed

- **Imports never overwrite a file they can't identify.** An import now stops
  and reports a clash instead of overwriting a file it can't check, or one that
  differs from an existing file only by upper or lower case on a
  case-insensitive drive such as an SMB share. Renaming a file to the same
  name in different case now works on those drives too.

- **Retention days are checked by the server.** The log, activity, history,
  release and security log retention settings now only accept 0 to 365 days
  through the API too, instead of only in the Settings page. Log cleanup reads
  them the same way the page does, so an out-of-range stored value is shown and
  used as the default. The security log is the exception: it is never pruned
  on a setting that can't be read or that is above 365 days.
