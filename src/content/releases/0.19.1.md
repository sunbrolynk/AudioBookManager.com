### Fixed

- **A full or unwritable config volume now stops startup with a clear message instead of a crash loop.** The message gives the free space, the free inodes, who owns the folder and which database files exist, and Health warns when the config volume is low on space. The write-ahead log is also capped so it shrinks after checkpoints.

- **Letter rail:** the highlighted letter no longer spills out past the left edge of the A to Z bar; only the letter itself grows.

- **Signing in from a remote address no longer ends on a blank page.** A client on the trusted network that the server refuses the API key now goes to the login page, and a missing `/initialize.json` says the reverse proxy must pass it to ABM.
