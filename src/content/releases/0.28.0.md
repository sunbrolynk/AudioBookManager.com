### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Author rows that were really role-tagged credits are removed on upgrade.** Illustrators, translators, introductions, narrators saved as authors and similar entries (a name with a role stuck on it) are deleted, along with their monitoring and profile settings and the list of their books ABM had fetched. Your books stay, and translators among them become translator credits. A book whose only author was one of these is left with no author; the upgrade log lists those books by ID in a warning. Refreshing one fetches its authors again, unless the metadata source itself lists only role credits for it. Back up before you upgrade. If you need to go back, do not just put the old image tag back: from a container still running the 0.28.0 image, run `alembic downgrade a2c5e81d4f37`, then switch the tag back to 0.27.1. Going back drops the translator credits, and it does not bring back the removed authors. Restoring your backup is the only way to get those back.

### Added

- **Translators show as a book credit.** A translator listed for a book is kept as its own credit, shown next to the narrators, instead of being counted as an author. The `.opf` file ABM writes for Audiobookshelf lists them as translators.
- **Translators, illustrators and other role-tagged contributors from Audible don't become authors.** A credit like `Ann Lee - translator` goes to the book's translators, and `Ivy Draw - illustrator` and other roles are dropped.
- **A credit in an author tag isn't taken as an author.** `Jane Doe - translator`, `Jane Doe (translator)`, `Jane Doe (Narrator)` and `Rosa Cortland (cover illustration)` name no author, so `Jiaxin Lu; Kai Lun - translator` gives only Jiaxin Lu. `Jane Doe narrated by John Roe` and `Jane Doe - read by Bob Smith` give Jane Doe. `Ann Roe; Performed by Ruth Hale` and `Ann Roe & Ruth Hale.Translator` give only Ann Roe, `Leo Bortnik, Louise Hartle - Translator` keeps the names without the role, and `Anne Tamm, Recorded Hours` gives Anne Tamm.

### Fixed

- **Folder and file names with "(Read by ...)" now match.** A folder like `The Ashen Court (Read by Tobias Quill)` is read as the book The Ashen Court, read by Tobias Quill, instead of a book by someone called "Tobias Quill)" that no search could find. `(Narrated by ...)` and square brackets work the same way, and a title with its own "by", like `Bound by Salt by Maren Ashcombe`, keeps it.
- **Naming a book's narrator or translator where its author goes no longer counts against a match.** If a folder or tag gives the narrator or translator as the author, Library Import, the other-editions list and completed-download matching treat it as that person rather than a wrong author.
