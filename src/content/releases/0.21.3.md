### Fixed

- **Adding an author or series now searches the books it found already in the library.** If an add was cut short, or you added the same author again, the books it had already put in the library as wanted were skipped and never searched. Those that are still wanted and not already downloading are now included in the search.

- **Automatic searches skip a book that is already downloading.** A search for a selected list of books, or for a single book, used to run even when a grab for that book was already in flight, so a second release could be sent to the download client. They now skip those books.

- **A restart no longer re-runs a task it interrupted.** A task that was running when ABM restarted used to go straight back on the queue and start over from zero, so a delete, a conversion, an import, a download or a grab could happen twice. Every task type now says whether it is safe to repeat. Only the safe ones (scans, refreshes, syncs, cleanups, cover caching) are requeued; the rest are marked failed with "Interrupted by an application restart" and an Activity Log entry naming the task, so you can check what got done and start it again yourself.

### Security

- **Indexer keys in `r=` stay out of the logs.** Some indexers put the API key
  in an `r=` query parameter, for example on RSS feed URLs. Logs now mask it
  like `apikey=`, and only when `r` is a whole parameter name.
