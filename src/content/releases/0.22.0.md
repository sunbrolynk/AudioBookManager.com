### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Back up first, and know the way back.** This release adds a column to your
  files and corrects stored bitrates. If you need to go back, do not just put
  the old image tag back: from a container still running the new image, run
  `alembic downgrade d5f1a8c3e270`, then switch the tag back. Going back
  drops the marker for files with no readable audio. The bitrate
  correction is not undone, because its downgrade changes nothing.

### Changed

- **Faster scans.** Library Scan and Library Import read audio details in
  the app itself instead of starting ffprobe for every file, and a rescan
  skips books whose files haven't changed. On a 13,000-file test library an
  unchanged rescan now takes well under a second.

### Fixed

- **Audio details are filled in for every file.** Finished downloads and
  Audible downloads now record codec, bitrate, duration and chapters, a
  rescan fills them in for files that were missing them, and bitrates that
  were stored 1000 times too high are corrected on upgrade.

- **A file refresh that can't read the audio now says so.** Refreshing a file
  whose audio can't be read, because it is unreadable, holds no audio or
  ffprobe can't run, reports a failed read instead of "No changes detected".
