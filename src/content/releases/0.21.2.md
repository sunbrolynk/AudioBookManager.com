### Fixed

- **Adding missing files to a book ABM already has through Library Import now treats each file by where it sits.** A file already inside one of your root folders is moved into the book's folder and renamed there, never copied, whatever the import mode. A file from outside every root folder follows the import mode (copy, move or hardlink). A row with both kinds is split file by file. Adding files to an existing book sends no On Import notification.

- **Library Import now sends the On Import notification for each book it imports from a folder or drive outside your root folders, and books already inside a root folder are no longer copied.** A book in a root folder that ABM didn't know yet is added where it is and its files are renamed in place, so copy mode no longer leaves a duplicate in the default root folder. A loose file at the top level of a root is moved into its own folder inside that same root. If an in-place import can't finish, that book fails and is removed rather than left half-added. Importing a root folder itself as one book is refused; import the books inside it. Adding books already in a root folder never sends a notification.

- **Notification messages no longer show an empty line such as "Quality:" or "Series:" when that value is missing, including lines in your own custom messages.**

- **Reduced motion turns off colour and size transitions.** With your system set to reduce motion, buttons, chips and other controls now change state instantly instead of fading between colours.

### Security

- **minimatch updated to 11.0.1** for the copy the TypeScript lint parser pulls in, fixing
  a published advisory where a crafted glob pattern could blow up into a long CPU and
  memory spike. It's only part of the frontend's lint tooling, so the app itself was
  never exposed.
