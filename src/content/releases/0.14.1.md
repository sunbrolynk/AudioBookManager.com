### Fixed

- the Library Import results screen never showed a publication year, for
  any folder, anywhere on the page. The frontend was reading a `year` field
  the backend has never sent — the parser emits `release_year` — so both
  the manual-search dropdown and the "Matched Audiobook" column came up
  blank. It was broken on the backend side too, independently: that column
  is populated automatically for every scanned folder as soon as the page
  loads, and none of the three ways a match gets built for it — ASIN,
  title search, series search — was copying `release_year` into the match
  data at all. Both are fixed.
- a folder matched by ASIN never got cover art on the Library Import
  results screen. That lookup used Libex's raw response directly instead
  of parsing it first, so the cover image field came back empty every
  time; title-search and series-search matches were unaffected. It's now
  parsed the same way manual search already did.
