### Upgrade notes

Read these before you update. Each one is described in full under Added, Changed, Fixed, Removed or Security below.

- **Reload Library Import after updating.** A Library Import page left open from the previous version can't save its changes until you reload it.

### Changed

- **Saving an import session no longer takes `libex_matches`.** ABM keeps each row's Libex matches itself, so a `PUT /api/library-import/session/{id}` or `PATCH .../choices` row that sends `libex_matches` is refused with 422 naming the field. Leave it out of rows you save back. `POST /api/library-import/retry-match` takes an optional `session_id` and stores the matches it finds in that session. `GET /api/metadata/search` takes `search_type=phrase` for Libex's best matches for a query, and returns one page of up to 50 results, where it used to return 10 without `limit`. It takes `page` (0 to 9) and adds `page` and `has_more` to the response so you can fetch the rest; `limit` (1 to 50) still trims a page.

### Fixed

- **Searches no longer stop at a handful of results.** Library Import kept only its top 5 matches, the manual match search in the Import Workbench stopped at 50 title results and 10 author or series results, and Add Book stopped at 40. Add Book shows Libex's best matches for what you typed at the top, then the first 50 title results, and loads the next 50 as you scroll, or with Load more, until Libex has nothing left. The manual match search pages the same way. Library Import keeps every match its title, author and series searches find instead of the top 5.
