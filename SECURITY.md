# Security Policy

## Reporting a vulnerability

If you find a security problem in the website, such as a way to inject markup
or script into a page, a gap in its Content-Security-Policy, or a problem in
the translation-review workflow, report it privately rather than in a public
issue or Discord channel.

**Email:** [admin@audiobookmanager.com](mailto:admin@audiobookmanager.com)

I'll acknowledge the report as soon as I can and work on a fix with you before
anything is disclosed publicly.

Problems in Audiobook Manager itself belong in the
[ABM repository](https://github.com/sunbrolynk/audiobook-manager).
